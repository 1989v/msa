# NOVA STRIKE — 노바 스트라이크

> 32비트 세대(메가맨 X4 벤치마크) 사이드스크롤 런앤건 액션 플랫포머.
> 순수 정적 웹 (HTML + JS + Canvas), 빌드 스텝 없음, 런타임 외부 요청 0.

## 세계관

서기 2179년, 궤도 도시 **헬리오스 스파이어**의 관리 AI **카이로스(KAIROS)**가 폭주해
기계군단을 해방했다. 마지막 남은 차세대 전투 안드로이드 **노바(NOVA)**가
세 구역의 수호기(가디언)를 격파하고 카이로스 코어에 도달해야 한다.

## 등장 보스 & 무기 순환 (약점 사이클: 화염 → 빙결 → 폭풍 → 화염)

| 스테이지 | 보스 | 속성 | 격파 획득 무기 | 약점 |
|---|---|---|---|---|
| 마그마 제련구역 | 이그니스 몰록 | 화염 | 마그마 버스트 | 사이클론 커터 |
| 빙결 연구동 | 글레이셔 팬텀 | 빙결 | 프로스트 랜스 | 마그마 버스트 |
| 폭풍 공중정원 | 템페스트 로크 | 폭풍 | 사이클론 커터 | 프로스트 랜스 |
| 코어 스파이어 (최종) | 카이로스 (2형태) | — | — | 페이즈별 상이 |

## 플레이어 무브셋 (X4 문법)

- 이동/점프(가변 높이)/**대시**(지상·공중 1회)/**월 슬라이드 & 월 점프**/대시 점프(모멘텀 유지)
- 버스터: 연사 3발 제한 + **차지 3단** (레벨2 관통 없음·대형, 레벨3 대형 관통 + 넉백)
- 특수무기 3종 (무기 에너지 게이지, 1/2번 또는 A/S 순환)
- 코요테 타임 6f, 입력 버퍼 6f, 피격 무적 60f + 넉백, 대시 중 피격판정 축소

## 스테이지 기믹 (구역별 실제 차별화)

- **마그마**: 상승 용암 구간, 낙하 용암 방울, 컨베이어, 폭발 드럼
- **빙결**: 미끄러운 빙판 관성, 얼어붙는 분사 트랩, 부서지는 고드름 발판
- **폭풍**: 상승 기류(점프 연장), 횡풍 구간, 붕괴 발판, 낙뢰 텔레그래프
- **코어**: 보스 재전(텔레포터 4기 — 3가디언 리매치 + 게이트) 후 카이로스 2형태

## 숨김 요소 (3종+)

- **하트 탱크 ×3** (스테이지당 1, 최대 체력 +4)
- **서브 탱크 ×1** (빙결 연구동, 회복 저장고)
- **아머 캡슐 ×2** (마그마: 부스터 파츠 — 공중대시 2회 / 폭풍: 버스터 파츠 — 차지 속도 1.4×)

## 메타 진행 (localStorage)

- 처치·파밍으로 **코어 칩** 획득 — 사망해도 유지
- 스테이지 셀렉트의 **연구소(상점)**: 최대체력 강화, 라이프 +1, 차지 속도, 칩 자석,
  대시 무적 연장, 무기 에너지 효율 등 영구 업그레이드
- 클리어 플래그·획득 무기·숨김 요소·최고 기록 영속

## 아트 디렉션

- 내부 해상도 **640×360**, 정수 배율 업스케일 (×2=720p ×3=1080p ×4=1440p, image-rendering: pixelated)
- 마스터 팔레트 1벌 (심야 인디고 베이스 + 시안/마젠타 네온 액센트 + 스테이지별 키 컬러)
- 주인공 ~52px (화면高 1/6.9 — 시야 확보 우선) + 시안 바이저/코어 발광과 림라이트로 즉시 식별
- **오리지널 캐릭터 디자인 (IP 세이프)**: 화이트/건메탈 아머 + 시안 풀 바이저(얼굴 노출 없음) +
  스윕백 트윈 핀 + 비대칭 숄더 — 벤치마크 원작의 실루엣·컬러웨이(파란 원형 헬멧+얼굴 노출)를
  의도적으로 회피
- 배경 패럴랙스 4층 (하늘/원경/중경/근경) + 광원·비네트
- 전 개체 3톤+ 명암, 외곽선, 접지 그림자. 모든 스프라이트 절차 생성(리그 베이크)
- 한국어 UI 는 고해상 오버레이 캔버스에 렌더 (픽셀 캔버스에 안 올림 → 뭉개짐 방지)

## 사운드

- WebAudio 자체 신스: BGM 시퀀서 (타이틀/스테이지 4곡/보스), SFX 20종+
- 첫 사용자 입력 후 AudioContext 활성화

## 모듈 구조 (js/)

core → input → audio → gfx(팔레트·베이크) → sprites(리그) → fx → level(타일·카메라) →
stages(데이터) → player → enemies → bosses → ui → game(상태·세이브) → main(루프)
