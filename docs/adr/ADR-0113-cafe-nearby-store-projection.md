# ADR-0113 — Ranking 소유 카페 매장 투영본과 일회 위치 비교

- 상태: 초안, 사용자 승인 P2 구현에 반영 (2026-10-21). 운영 공개는 별도 검증 게이트.
- 관련: ADR-0081, ADR-0083, ADR-0093, ADR-0112

## 맥락과 결정

사용자의 최신 명시 요구는 주변 비교를 P2 핵심으로 구현하고, place의 강남 스타벅스 조회가 비어 있으므로
ranking이 공공 원천을 직접 배치 수집하는 것이다. 기존 플랜의 place 원천 SSOT 제안과 지도 제외 제안을
이 결정으로 대체한다. 서비스 간 DB 공유·요청 시 place 호출은 없다.

`ranking/ingest/src/cafe_stores.py`가 소상공인시장진흥공단 상가정보를 전국 업종별 페이지로 읽는다.
공식 소분류 목록에서 카페·커피·제과·빵·도넛 후보 업종을 확인하고 모든 페이지의 totalCount·행 수·키
중복을 검사한다. API 키·실패·쿼터·빈/부분 페이지 문제는 새 스냅샷을 보내지 않는다. 모든 매장 원천
필드는 `raw_json`, 브랜드 매핑·ruleVersion은 별도 컬럼/메타에 둔다. 샘플은 운영 대체 원천이 아니다.

V5는 ranking 전용 DB에 cafe_store/cafe_store_snapshot/cafe_store_area를 만든다. 전체 교체와 메타
공개는 하나의 `rankingTransactionManager` 트랜잭션이다. 행 잠금·버전 재시도 멱등성·수집 시각 순서·
전회 대비 70~150% 행 수 게이트를 적용한다. 게이트 밖 변화는 원천 조사 후 별도 정책 검토 대상이다.
누락 1회는 유지, 서로 다른 완전 수집 2회 누락 뒤 비활성화하며 원문은 남긴다. 재등장은 누락 횟수 0.
사용자 위치는 어떤 테이블에도 저장하지 않는다. 운영자 매핑 교정 UI/이력은 후속 어드민 범위다.

지역 대체 중심점은 기상청 단기예보의 2026-10-19 공식 활용가이드 위경도 열에서 가져온다.
격자 X/Y를 좌표로 쓰지 않으며 매장 평균을 계산하지 않는다. 시도/시군구 상위 표준 코드만 사용한다.
읍면동 행정동 코드·GeoNames ID는 쓰지 않는다. 0,0인 이어도 예보 전용 행은 제외한다.
현재 SOHO signguCd에 실제 존재하고 부모가 있는 지역만 공개한다. 예보 대표 중심점이므로
시군구청 위치라고 부르지 않고 '선택 지역 중심 기준'이라고 표시한다. 서로 다른 원천 개정 시점으로
코드가 다르면 해당 지역은 노출하지 않는다. 원문·파일 SHA256·출처는 ingest의 provenance JSON에 보존한다.

## 위치와 지도

좌표는 명시 버튼 이후 getCurrentPosition 1회로만 얻고, 메모리와 POST 본문으로만 전달한다.
취소·화면 이탈·pagehide 시 위치/결과를 버리고 늦게 도착한 콜백·요청 응답을 무시한다.
요청 DTO는 좌표를 출력하는 data class가 아니며 전용 예외 처리기가 파서 원인·본문을 로그/응답에 싣지
않는다. gateway는 해당 경로의 query를 로그에서 제거하고 모든 응답에 no-store를 설정한다.
현재 ranking-public 경로는 `/api/v1/ranking/**`만 content에 전달하고 internal은 공개하지 않는다.

DB의 경계 상자 후보 5,001행 이후 순수 도메인 haversine으로 반경을 판정한다. 5,000 초과는 LIMITED,
총수 null이다. 음료 변형은 전체 후보에서 선택·정렬 후 페이지 처리한다. 여러 변형은 사용자 선택 전
영양 값을 자동 선정하지 않는다. 한 변형만 있으면 자동 선택임을 표시한다. 매장 메뉴 판매는 항상 미확인.

지도의 최신 요구는 기존 place의 Google Maps JS 키/로더·markerclusterer 재사용이다. 주변 화면에서
사용자가 지도 보기를 선택할 때만 SDK를 읽는다. Google에는 공개 매장 좌표만 전달한다.
백엔드 조회의 외부 API 호출은 0회지만, 사용자가 여는 지도에는 Google 네트워크 호출이 있다.
따라서 플랜 P2-4의 지도 타일 호출 0회는 이 요구로 대체된다. 새 지도 SDK·타일 서버·상시 파드는 없다.
Google 길찾기는 목적지만, Naver 검색은 브랜드/지점 이름만 링크에 넣는다.

## 공개와 한계

`ranking.cafe.nearby-verified=false`가 기본이다. 원천·지역이 준비돼도 P2-2 정밀도(브랜드별 최대30건,
98% 이상), P2-3 독립 표본 포함률, P2-5 운영 전 계층 좌표 표식 비검출, P2-7 동시5요청10분 부하 검증
전에는 true로 바꾸지 않는다. 수집기 스스로 검증 상태를 켜지 않는다. CronJob도 suspend=true다.
45일 초과 STALE, 90일 초과 비공개다. 원천 기준일 미제공은 null로 유지하며 수집일과 구분한다.
기준일이 없을 때만 마지막 성공 수집일로 보수적 만료를 계산하며 원천 최신성 보장은 하지 않는다.
운영 데이터·실제 지도·APM·ingress 로그·성능 검증은 이 코드 변경으로 확인했다고 주장하지 않는다.
