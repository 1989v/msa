# ADR-0115 도메인 전문가의 프롬프트 공유와 동료 평가

<!-- source: docs/adr/ADR-0072-blog-platform.md, docs/adr/ADR-0081-ranking-leaderboard-platform.md, portal-fe/src/pages/rank/RankPage.tsx -->

## 맥락

랭킹 도메인의 기존 보드는 수집한 사실 데이터로 순위 스냅샷을 만든다. 프롬프트에는 작성자, 본문, 작성자 삭제, 평가자별 단일 서면 평가가 필요하다. 블로그의 기존 게시 권한과 익명 평점은 이 사용 사례와 다르다.

## 결정

랭킹 호스트에 목록과 공유 가능한 상세 페이지를 둔다. content의 blog 모듈이 기존 회원 프로필 식별을 재사용해 프롬프트와 리뷰를 별도 테이블에 저장한다. 한 회원의 한 프롬프트에 대한 리뷰는 데이터베이스에서도 유일해야 한다. 공개 조회와 회원 쓰기는 기존 게이트웨이의 권한 경계를 사용한다. 두 서비스 사이에 테이블을 공유하지 않는다.

첫 출시에는 한 도메인 안에서 동료 평가가 세 건 이상인 글을 평점과 평가 수로 비교한다. 평가 수와 평가 본문을 함께 공개하고 초기 평가 단계의 글도 탐색할 수 있게 한다. 세 건은 전문성 인증이나 통계적 보증이 아니라 초기 표시 기준이다. 도메인과 역할은 평가자가 직접 밝힌 사용 맥락이다.

## 운영상 영향

배포는 blog DB에 신규 테이블 두 개를 추가하고 content와 portal-fe 이미지를 갱신한다. 문제가 생기면 이전 애플리케이션 이미지로 되돌릴 수 있도록 기존 테이블을 유지한다. 프롬프트와 입력 예시는 일반 텍스트로 취급하며 플랫폼에서 실행하지 않는다.
