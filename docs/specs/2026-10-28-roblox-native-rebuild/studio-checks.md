# 실제 엔진 확인표 — 아직 실행하지 않음

코드·XML·도달 가능성 검사는 아래 플레이 결과를 보증하지 않는다. 현재 Studio/브라우저 컴퓨터 사용 접근이 거절되어 실행하지 않았다. 검사자는 실행 날짜·기기·결과·Output 오류를 각 항목 옆에 남긴다.

## 처음 열었을 때

- `roblox/infinity-step/dist/InfinityStep.rbxlx`를 열면 건물·출입구·창·계단·배관·조경과 등반 목표가 보인다. Terrain 등 실행 시 생성 요소는 프로젝트 README와 비교한다.
- Play 후 기본 Roblox 아바타가 안전한 출발 지점에 생긴다. 편집 화면과 실제 플레이를 구분한다.
- 추가 클릭 점프 버튼·Run/Grab 버튼·고정 웹 키 설명이 없고, HUD가 기본 터치 이동·점프 영역을 가리지 않는다.

## 기본 조작과 재미

- 기본 이동·점프·카메라 회전·줌이 정상이고, 캐릭터 애니메이션이 작동한다.
- 착지 직후와 충전 후 점프의 차이가 체감된다. 한 번의 기본 점프로 중복 도약하지 않는다. 빠른 재도약도 가능하다.
- 출발 광장에서 첫 건물, 외벽, 옥상까지 실제 플레이한다. 다음 착지면이 읽히고 머리·벽 충돌로 도달 불가능해지지 않는다.
- 사다리 등반·스태미나 소모·회복·이탈을 확인한다. 공중이나 사다리 재접촉만으로 힘/스태미나를 무한 회복하지 않는다.
- 7개 구간을 플레이해 동선·장애물·실루엣 차이를 확인한다. 부품 수나 테마 이름만으로 합격 처리하지 않는다.
- 아래로 떨어졌을 때 건물/착지면 충돌이 사라지지 않고 다시 도전할 수 있다. 스트리밍 중 안전한 발판을 잃지 않는다.
- PC, 터치 시뮬레이터, 게임패드에서 기본 입력을 각각 검사한다. 시뮬레이터 결과와 실제 기기 결과는 구분한다.

## 진행과 부활

- 추락 후 무료 계속하기와 선택적 테스트 부활이 모두 가능하다.
- 부활은 구역 입구가 아니라 **떨어지기 직전 마지막 안정 발판**으로 간다. 아래층 착지가 복귀 대상을 바꾸지 않는다.
- 같은 추락의 중복 요청은 한 번만 소비한다. 거절/보유량 없음은 소비하지 않는다.
- 차감 직후 끊김·사망·캐릭터 교체·재접속에서 미전달 권리가 보존되는지 확인한다.
- 현재 진행과 최고 기록이 구분되고, 재접속만으로 무료 최고 지점 복귀가 되지 않는다.
- 상품 ID가 0인 현재 구성에서 실제 구매창·결제는 열리지 않는다. Studio 재고는 운영 잔액과 분리한다.

## 공개 전 별도 검사

비공개 테스트 경험에서 DataStore 저장·실영수증 중복/지연·멀티플레이·실기기 성능을 확인한다. 경험/상품 생성·게시·실제 결제는 현재 로컬 개발 범위에 포함하지 않는다.
