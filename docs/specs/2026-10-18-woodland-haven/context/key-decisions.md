# Decisions

## 2026-10-18 — 독립 정적 샘플
- 위치: `portal-fe/public/games/woodland-haven/`. 공유 레지스트리와 기존 게임은 변경하지 않는다.
- 순수 모델(`model.mjs`) → Canvas 렌더러/입력(`game.mjs`) 분리. 버전 1 저장 스키마를 엄격 검증한다.
- UI 토큰은 루트 DESIGN.md §12 아케이드(송연·기와·한지·황토·연지)를 지역 palette 파일에 이름으로 보존한다. 게임 아트는 `palette.mjs`의 별도 숲/물/목재/인물 팔레트를 사용한다. 소비 코드에 색상 리터럴을 넣지 않는다.
- 실제 벽/건축물 발밑에 충돌을 두고 y 순서로 그린다. 나무 잎은 가까이 있는 캐릭터를 가리면 반투명해진다.
- 저장은 이 브라우저의 한 슬롯. 손상된 저장을 자동으로 덮지 않으며 명시적 초기화 후 다시 저장한다.
- 컴퓨터 사용은 승인 전 금지. 모델/빌드 검증과 시각 검증을 구분해서 보고한다.

## 2026-10-18 — 승인된 맵/건축/모험 확장
- 기존 노드 생성 크기를 상수로 고정하고 새 영역 노드만 뒤에 추가한다. v1 좌표·ID 유지.
- 상태 v2: health, camp, discoveries, defeated, relic, returned, 건물별 보관함 items. v1은 안전 기본값으로 이동.
- 적의 현재 추격 위치/공격 대기는 런타임이고 처치 여부는 영구 저장한다. 시작 지역 안에는 적을 만들지 않는다.
- 유적은 수호자 3마리를 처치해야 열리는 일회성 보물. 자원과 유물을 주며 쉼터 캠프에 돌아오면 목표 완수.
- 모닥불 자동 체력 회복, 쉼터 R로 캠프 지정·휴식, 보관함 R로 별도 작은 입출고 창을 연다.
- UI 검증은 부모가 승인 범위에서 수행한다. 구현 에이전트는 여전히 UI 도구 미사용.

## 2026-10-18 — 지도 탐험 안개
- explored는 80단위 40×30 격자의 공개된 칸 인덱스 배열(최대 1200개). 정렬·중복 없는 정수 배열로 저장 검증.
- 반경 160 안의 칸 중심을 탐험 처리하며 영구 누적한다. 기존 v1/v2는 player/camp 주변만 초기 공개.
- 저장 버전은 2 유지, explored가 없는 기록만 마이그레이션한다. 존재하지만 잘못된 기록은 저장 손상으로 처리한다.
- 지도는 불투명 fog 토큰으로 먼저 칠하고 탐험한 셀에만 지형과 마커/이름을 클립한다. 장소는 discoveries와 explored를 모두 만족해야 표시한다.

## 2026-10-18 — 채집 모션
- 순수 타이밍/대상 방향 헬퍼를 두고 성공한 harvest 결과만 300ms 런타임 모션으로 변환한다. 저장 스키마/모델 규칙은 변경하지 않는다.
- 준비 25%, 타격 33%, 회수 42%. 도끼/곡괭이/손, 나무 조각/돌 조각/잎을 기존 팔레트로 그린다. 이동 입력을 잠그지 않는다.
- 마지막 채집 노드는 준비 구간만 기존 모습으로 남겨 타격 시 소진 모습으로 전환한다. reduced-motion은 고정 자세/표식만 사용한다.

## 2026-10-18 — 채집 시선/방향 버그 수정
- 원인: 우측/정면 스프라이트 동일, 좌우 비반전 스윙, 75ms 효과와 약156ms 도구 정렬 불일치, 마지막 나무 타격 앵커 18px 차이, 시작 위치에 고정된 조준. Node 재현 후 부모가 최소 수정을 승인했다.
- 투영/방향은 geometry.mjs로 공유한다. 방향별 캐릭터는 동일 의상/팔레트를 유지하며 정면/등/반전 프로필을 구분한다.
- 채집의 현재 플레이어 위치·방향별 어깨·대상 표면 접촉점을 매 프레임 계산한다. 모션 중 몸 bob 대신 작게 기울이고 다리 이동은 유지해 어깨/도구 좌표가 일치한다.
- 타격은150ms, 준비25%·스윙25%·회수50%의 궤적으로 도구가 공통 앵커에 닿는 시점에 효과를 시작한다. 소진 전/후의 효과 앵커는 동일하며 소진 모습은 contacted 이후에만 표시한다.
- 도구 레이어는 북쪽만 몸 뒤, 나머지는 몸 앞. reduced-motion은 현재 타깃을 향한 고정 자세/공통 앵커 강조.

## 2026-10-18 — 승인 생활 시스템
- 모델의 생활 함수는 life.mjs로 분리하고 외부 콜백으로 세계 충돌을 받는다. 모델↔생활 모듈 순환 의존 금지.
- 원래 WORLD 자원 ID 유지, 수집물은100000대·심은 나무는200000대 숫자ID로 기존 모션 파편 계산을 보존한다.
- 심은 성목 마지막 벌목은 묘목1을 주고 식재 기록을 삭제한다(부모 확인). 원래 나무만300초 자동 재생. 마지막 노드는 런타임 모션으로 타격 순간까지 유지한다.
- 씨앗 없는 초기 상태는 손 수집 풀에서 시작한다. 빈 밭R 파종→R 물→성숙E/R 수확. 음식/닭장 관리는 생활창과 상황 R로 제공한다.
- 먹이는100/180씩 초당 감소, 30 이상인 시간만 산란90초에 누적. 오버플로우 없이 먹이40이 모두 들어갈 때만 한 개 소비한다.
- v3 저장으로 도구/생활 상태를 명시하고 v1/v2는 새 물품0/도구없음/생물없음 기본값과 기존 그루터기 재생 대기를 채운다. 시간은 state.elapsed만 사용한다.

## 2026-10-18 — 식물 관리와 통합 회귀
- 물·병충해 관리는 성장량 누적 방식으로 추가했다. 나무120/밀90 성장량, 건강·수분40 이상1.5/건조.6/해충×.5, 수분 초당.7. 밀은 첫 물 전 성장0. ID%3=0은 주기35초에 한 번 발생한다.
- R은 관리창을 열고 물·치료·회수/수확을 명시적으로 선택한다. 상태는 v3에 저장하고 부분 누락/불가능한 성장량·수분·발생 플래그를 거부한다.
- 어린 나무의 물리 반경은 성숙 전3으로 유지한다. 청년 단계 외형 변화로 반경이 커져 플레이어를 가두지 않으며 성숙 반경11은 빈자리 확인 후 적용한다.
- 저장 복원은 이미 존재하는 식물/밭/닭장에 새 설치용 캠프 여유 공간을 다시 강제하지 않는다. 쉼터로 캠프를 옮긴 뒤에도 합법적인 상태를 복원한다.
- 제작/수리/관리 실패 메시지는 모달 내부 role=status에 남기고 재렌더 이후 가능한 버튼 초점을 유지한다. 한글 자판 지원은 keydown/keyup 물리 code를 공통 정규화한다. UI 입력 불확실성의 원인을 IME로 단정하지 않는다.
- 산란90초 누적의 부동소수 경계는1e-8 허용으로 처리해 먹이30 직전89.999999999996에서 영구 멈추지 않게 한다. 실제 작은 dt 반복 회귀 테스트로 검증했다.
