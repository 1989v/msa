# 직접 검색·콘솔 현황

2026-10-12 약 23:16~23:36 KST, 사용자에게 **조회만** 사전 승인받은 뒤 Chrome에서 확인했다. 현재 결과는 이번 본문 보완 커밋의 배포 전이다.

## 실제 검색

각 검색어의 **첫 페이지**를 확인했다. 순위 밖인 결과의 정확한 전체 순위는 확인하지 않았고, 검색 피처·광고·관련 문서를 일반 결과 순위에 합산하지 않았다.

Google 한국어는 `hl=ko&gl=kr&pws=0`, 하단에 맞춤설정되지 않은 결과와 대한민국/IP 기반 위치가 표시됐다. 영어는 `hl=en&gl=us&pws=0`, 영어 화면과 비개인화 결과를 확인했으나 하단 위치는 **Unknown / Can't determine location**이었다. 미국 현지 사용자 환경을 재현한 것으로 주장하지 않는다. 영어 검색은 한국 체류 외국인의 검색도 고려해야 한다.

네이버 브랜드 검색의 AI 설명은 82종을 말하지만 홈 관련 문서의 스니펫에는 48종이 남아 있다. 문서마다 검색 반영 시점이 다른 표본이며 CDN 캐시의 증거로 보지 않는다. 이전 네이버 10페이지 검사의 범위와 이번 첫 페이지 확인을 구분한다.

영어 관광 일반 결과에는 관광청, 예약 플랫폼, 방문지 선정 이유·여행 팁을 담은 글이 보인다. 실용적인 영문 편집 콘텐츠가 필요하다는 판단의 참고이며, 특정 경쟁자의 신뢰 점수·백링크·체류 시간을 측정한 것은 아니다.

## Google 색인

보고서 최종 업데이트는 2026-10-09이고 **각 서비스 sitemap.xml 필터**로 조회했다. 전체 속성 보고서나 이전 다른 필터의 숫자와 직접 비교하지 않는다.

| 항목 | game sitemap | place sitemap |
|---|---:|---:|
| 색인 생성됨 | 14 | 83 |
| noindex 제외 | 6 | 9 |
| 발견됨 - 현재 색인이 생성되지 않음 | 87 | 59,645 |
| 크롤링됨 - 현재 색인이 생성되지 않음 | 57 | 589 |
| Soft 404 | 18 | 51 |
| 적절한 표준 태그가 포함된 대체 페이지 | 해당 행 없음 | 1,288 |
| 사용자가 선택한 표준이 없는 중복 페이지 | 해당 행 없음 | 942 |

게임 Soft 404 재검증은 시작됨을 유지하고 noindex 6개에는 아직 ‘수정 결과 확인’ 버튼이 있다. 이번 승인에는 제출이 없어 누르지 않았다. 발견됨 수만으로 콘텐츠 품질, 서버 과부하 또는 크롤링 차단을 단정하지 않는다.

Google의 스마트폰 렌더 화면에서 영문 서울 제목·소개·395개 목록 수량·자치구 링크를 확인했다. 현재 실제 URL 테스트 결과와 과거 저장 판정은 다르며, 실제 테스트 통과는 최종 색인·순위 보장이 아니다. 영문 서울의 저장 검사에 나온 sitemap 일시 처리 오류만으로 실제 sitemap 장애를 판정하지 않는다.

## Google 검색 실적

최신 28일은 **2026-09-13~2026-10-10**, 검색 유형 웹이다. 기존 CSV 기간(09/11~10/08)과 달라 전후 개선 비교로 쓰지 않는다.

| 페이지 필터 | 클릭 | 노출 | 기간 평균 게재 순위 |
|---|---:|---:|---|
| 포함 `https://game.1989v.com/` | 0 | 0 | 없음. 화면의 0은 검색 0위가 아님 |
| 포함 `https://place.1989v.com/en` | 0 | 43 | 16.3. 개별 넓은 검색어의 순위가 아님 |

영문 URL의 공개 검색어는 제주 행정구역명·지도, `where to visit in jeju`, `tourism korea`, 스페인어 `seo gu corea del sur`를 포함한다. 페이지 표에는 13개 행이 있고 제주 지역 노출은 6회다. 국가 표에서 캐나다 3회·한국 2회·멕시코/말레이시아/네덜란드 각 1회만 보였으며 합계 8회는 총 노출 43회와 다르다. 페이지 필터 적용 시 총계·표가 부분적으로 표시될 수 있다는 화면 안내가 있어 이를 전체 영어 국가 비중으로 환산하지 않는다.

## 네이버 콘솔과 승인 범위

Search Advisor의 웹마스터 도구는 현재 Chrome 시크릿 창에서 NAVER 로그인 화면으로 전환됐다. 자격 증명을 입력하거나 로그인 절차를 진행하지 않았으므로 두 사이트의 최신 콘솔 수집·색인·실적은 조회하지 못했다. 기존 게임 CSV·사용자 제공 자료는 별도 시점의 근거로만 사용한다.

수행한 승인 작업: Chrome 관련 탭 확인, 위 12개 검색, Search Console의 서비스별 색인 및 게임·관광 영문 페이지/검색어/국가 실적, 관광 URL 2개 저장 검사와 서울 1개 실제 진단·렌더 화면, Search Advisor 접근 가능 여부 확인. 변경한 상태는 조회용 탭·보고서 필터·진단 화면이며 **색인 요청·재검증 제출·사이트 설정 변경은 하지 않았다**. 승인된 진단 조회가 끝난 상태에서 추가 컴퓨터 유즈를 자동 확장하지 않는다. 네이버 인증이 준비되면 동일 미완료 조회의 재개 범위를 확인한다.
