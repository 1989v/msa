# 결정

### 2026-10-12 검색 언어와 1차 유지보수
- Decision: 게임 Google·네이버 목표를 유지하고 관광 Google 영어 검색을 독립 목표로 추가한다. 영어는 전 세계 사용자를 대상으로 한다.
- Reason: 사용자의 명시적 요구. 관광 영문 URL은 실제 노출이 있으나 기존 28일 자료의 클릭은 0회다.
- Evidence: `docs/plans/2026-10-12-search-growth-ko-en.md`의 원본 CSV 집계와 운영 HTTP 표본.
- Impact: 1차는 기존 홈·지역 본문 공유와 완전한 소개·선택 안내(L2). 타이틀·URL·canonical·색인 정책·백엔드 변경 없음.

### 2026-10-12 승인과 검증 경계
- Decision: 알려진 gpt-6.1-sol 구현 에이전트 1명에게 확정된 본문과 검증을 위임한다. 컴퓨터 유즈는 사용자의 ‘이 조회 범위 승인’ 이후 승인된 검색·콘솔 읽기와 URL 진단만 수행했다.
- Reason: 사용자 AGENTS의 모델 분담·컴퓨터 유즈 규칙. 유지보수 구현은 검색 보완 요청 범위에 포함되지만 배포는 검토 가능한 결과 이후 승인받는다.
- Impact: worker는 브라우저·앱 UI 도구를 사용하지 않고 변경 파일만 커밋한다. push·운영 배포·콘솔 제출은 하지 않는다.

### 2026-10-12 실제 조회에 따른 진단
- Decision: 영문 홈·서울을 색인 우선 대상으로 보고, 영문 방문 가이드는 다음 콘텐츠 단계로 둔다. 최신 관광 색인 83·게임 14와 실제 검색 첫 페이지 미노출을 별도로 기록한다.
- Reason: 영문 홈은 최근 10/11 크롤 후 미색인, 서울은 9/14 Soft 404가 남았지만 현재 Google 실제 진단은 정상이다. 개선 코드·현행 수집 가능과 검색 반영은 다르다.
- Evidence: `search-audit.md`. 현재 영어 검색 위치는 Unknown이며 미국 현지 순위로 쓰지 않는다. 국가 표의 부분 집계도 전체 영어 수요로 환산하지 않는다.
- Impact: 배포 이후 명시적으로 승인받은 URL 색인/재검증만 요청한다. 네이버 로그인·콘솔 최신 조회, 전체 관광 Soft 404 해소는 미완료다.
