## 재색인 후 확인 명령

```bash
for id in 77 12933 11199 12975 7545 11295 4811 13354 2961 16151 17693 49399 2786 50108 65340 \
          62502 8190 10745 62392 62524 6253 62399 7861 53069 34067 65461 65532 62527 65482 62109; do
  curl -s -m 20 "https://place.1989v.com/api/search/attractions/$id" \
  | jq -c --arg id "$id" '.data | {id: $id, title, useFee: (.useFee // null),
      feeText: ((.feeText // null) | if . then .[0:40] else . end),
      attrAdmission, closedWeekdays, attrParking}'
done
TZ=Asia/Seoul date '+측정 %Y-%m-%d %H:%M:%S KST'
```

판정: 1절 11곳 `feeText` 가 null 이 아니고 기대 첫머리와 같다 · 2절 `attrAdmission` 이 기대 열과 같다 · 3절 77 은 `["MON"]`, 4811 은 null · 4절은 지금 값 그대로. `feeText` 키가 응답에 아예 없으면 재색인 또는 앱 배포가 아직이다 — 그 측정은 버린다.
