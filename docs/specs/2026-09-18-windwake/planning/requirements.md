# Requirements
User requests an original, complete-feeling open-world action adventure with three-dimensional play, real jumping/gravity/falling, camera-relative direct control, meaningful combat/combos/AI, environmental puzzles and rewards. Vanilla JS/CSS/Canvas without build system or engine. Procedural Web Audio and all original assets. Deterministic stepping API and actual Chrome input/playtesting are mandatory. Iterate after first success; fix observed issues, rerun and report measured evidence. Higgsfield prohibited. Game scope and routine choices delegated to developer. Acceptance details: ../spec.md.
