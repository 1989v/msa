# 귀야행 척준경 — PRD (2026-09-13)

**한 줄**: 고려 무장 척준경이 지하 귀굴을 오르내리며 혼백을 모아 귀장(鬼將)을 봉인하는
2D 픽셀 탐험 액션. 목표 판은 클로드 디자인 `artboards/01-target-screen-v2.html` (승인 2026-09-13).

## 서사
고려 예종 대. 여진 정벌에서 돌아온 척준경이 개경 북쪽 산성 아래에서 삼국 시대부터 봉인돼 있던
귀굴(鬼窟)이 열린 것을 알게 된다. 봉인 부적은 찢어졌고, 원귀와 도깨비가 층층이 올라온다.
척준경은 갈고리 밧줄과 장검 하나로 아홉 층을 내려가 흩어진 혼백을 거두고 귀장을 다시 봉인한다.
(사료: 척준경의 여진 정벌 선봉·단기 돌입은 『고려사』 열전. 표준영정 없음 — 초상 창작.)

## 시스템

- **혼백**: 층마다 22개. 층의 봉인문(보스 방)은 혼백 22/22 + 부적 조각 3/3 이면 열린다.
- **魂 게이지**: 타격·혼백 획득으로 참. 검기 파동 50 · 회선참 30. 낙하 베기는 무료.
- **되돌아 오르기**: 층마다 발판을 꿰뚫는 밧줄로 위로 되돌아갈 수 있어야 한다 (`tools/reach.mjs` 막다른 곳 0 이 게이트). 달리기 점프로만 건너는 틈을 층마다 둔다.
- **부적**: 최대 5. 옹기·원귀 처치에서 드롭. 원귀는 부적에만 확정 경직.
- **체력 8칸**, 장승에서 회복·저장. 층주 처치 시 최대 체력 +1.
- **능력 해금 6** (층주 보상): 이단 점프 → 갈고리 밧줄 발사(벽·천장 고리에 매달림) → 낙하 베기 → 검기 강화 → 벽 차기 → 부적 결계(잠시 무적 방벽).
- **적 25종 이상** (층마다 신규 2~3종, 스탯만 올린 재탕 금지): 도깨비(잡졸·창·방망이 투척) · 원귀(부유·돌진·비명) · 두억시니(중간 보스형) · 어둑시니(빛 없는 곳에서만) · 그슨대 · 물귀신(구덩이) · 달걀귀신 · 이무기(층주) 등. 각 적은 **예고 → 공격** 구조.
- **첫 판부터 어렵다**: 1층부터 도깨비 2기 동시 + 원귀 원거리. 튜토리얼 없음. 화면을 읽을 2~3초만.
