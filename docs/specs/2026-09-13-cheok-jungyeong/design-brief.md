# 척준경 — 아트 시안 브리프 (클로드 디자인용)

고려 무장 **척준경**이 삼국·통일신라 시대부터 떠도는 원귀·도깨비 무리를 베어 없애는
2D 횡스크롤 액션. 이 문서는 클로드 디자인이 **목표 화면 1장**을 그리기 위한 스펙이다.
코드는 아직 없다 — 이 그림이 스펙이 되고, 구현은 그림을 따라간다.

---

## 붙여넣을 프롬프트

> 고려 무장 척준경이 고대의 귀신·도깨비 무리를 베어 없애는 2D 횡스크롤 액션 게임의
> **실제 플레이 화면 프레임 1장**을 그려줘. 스타일은 디테일한 레트로 픽셀 아트(16비트,
> SNES·메가드라이브급) — 깔끔한 실루엣, 조화로운 색감, 테마·색·피사체를 게임 느낌으로.
> 이미지는 **세로형**이고 게임 전체 화면이 다 보여야 해. 상단에 전형적인 HUD 를 두고,
> 이 그림에서 영감을 받은 재미있고 독창적인 **한글 게임 제목**을 넣어줘. 캐릭터·환경·
> 분명한 액션이나 목표가 보이는 실제 게임 속 한 장면처럼. 모든 요소가 반드시 게임
> 화면 안에 들어가야 해. 규격·인물·적·HUD·팔레트 조건은 README 를 따라.
> 결과는 `artboards/01-target-screen.html` 로 저장해.

## 1. 규격

| 항목 | 값 |
|---|---|
| 방향 | **세로** 3:4 |
| 네이티브 픽셀 격자 | **360 × 480** |
| 확대 | 정수 3배 → **1080 × 1440** (보간 없음, `image-rendering: pixelated`) |
| 주인공 키 | 네이티브 **약 48px** = 화면 짧은 변의 1/7.5 |
| 화면 안 적 | 2~3종, 4~6마리 |
| 색 수 | 화면 전체 48색 이내 (16비트 감각) |
| HUD 높이 | 네이티브 약 56px (상단) |

픽셀은 격자에 맞춘다. 반픽셀·안티앨리어싱·그라데이션 없음. 디더링은 하늘·안개에만.

## 2. 주인공 — 척준경

| | |
|---|---|
| 시대 | 고려 중기, 1100년대 초 |
| 대표 싸움 | 여진 정벌 선봉 (1107, 윤관 휘하) · 홀로 성벽을 넘어 적장을 벤 무용 |
| 실루엣 표식 (제안) | **정수리에 붉은 술이 달린 둥근 투구 + 양손으로 쥔 장검 + 등에 멘 갈고리 밧줄** |
| 갑주 | 고려 찰갑(쇠비늘) — 유물 기준. 소매 짧고 허리 아래 치마형 |
| 자세 | 횡스크롤 액션의 공격 프레임 — 검을 크게 휘두르는 순간, 검기·잔상이 보인다 |

- **표식은 공용 원장에서 겹치면 안 된다.** 이미 쓰인 것: 뿔 투구+원형 방패(윤관) ·
  복두 날개+흰 수염(강감찬) · 언월도(최영) · 민머리+활(김윤후) · 삿갓 투구+짧은 창(배중손) ·
  붉은 두건+쌍검(곽재우) · 고리자루 큰칼+목가리개(김유신) · 허리 밧줄+만곡도(장보고).
  붉은 술·양손 장검·**등의** 밧줄 조합이면 겹치지 않는다. 더 나은 표식이 있으면 바꾸되
  20px 크기에서도 구분돼야 한다.
- **실물을 보고 그린다** — 갑주·투구 유물, 고분벽화. **정부 표준영정은 보지 않는다**(화가 저작권).
  초상은 창작한다. 희화화하지 않는다.
- **구현 한계로 그림을 깎지 않는다.** 지금 코드로 만들 수 있는 형태로 줄이지 말고 목표를 그린다.

## 3. 적 — 조선 이전의 귀신·도깨비

| 이름 | 실루엣 | 역할 |
|---|---|---|
| 도깨비 | 외뿔 · 털가죽 바지 · 못 박힌 방망이 · 사람보다 한 뼘 큼 | 근접 잡졸, 무리로 |
| 원귀 | 흰 소복 · 얼굴 가린 긴 머리 · 발 없이 떠 있음 · 반투명 | 원거리, 통과 불가 |
| 두억시니 | 주인공의 2배 덩치 · 푸른 피부 · 큰 입 | 중간 보스 |
| 이무기 | 강·안개에서 솟는 뱀 몸통 | 스테이지 보스 (이번 화면엔 없음) |

이번 화면에는 **도깨비 3~4 + 원귀 1~2** 만 넣는다. 적은 연지(붉은) 계열 강조색 한 점을 갖는다
(눈·불꽃·혀) — 어두운 배경에서 적을 가르는 규칙이다.

## 4. 환경과 목표

- 고려 산성의 밤 — 보름달, 낮게 깔린 안개, 소나무, 석축 성벽, 장승 한 쌍, 등롱 불빛.
- 횡스크롤이므로 지면은 화면 아래 1/3, 그 위로 성벽·산·하늘 층이 겹친다(패럴랙스 3층).
- **분명한 목표 하나**: 화면 오른쪽 끝에 봉인 부적이 찢어진 성문(또는 사당). 주인공은 왼쪽에서
  그쪽으로 싸우며 나아간다. 방향이 그림만으로 읽혀야 한다.

## 5. HUD (상단)

| 요소 | 표기 |
|---|---|
| 체력 | 붉은 칸 10개 (칸 단위, 바 아님) |
| 기력(魂) | 푸른 게이지 — 검기·필살에 쓴다 |
| 부적 | 노란 부적 아이콘 × 수 |
| 목숨 | 투구 아이콘 × 수 |
| 점수 | 6자리 |
| 스테이지 | **「스테이지 1」** 로 표기 — 「1면」 「1스테이지」 금지 |
| 제목 | HUD 위 또는 HUD 안 왼쪽에 픽셀 로고. 이 그림에서 영감받은 창작 한글 제목 + 짧은 부제 |

HUD 는 상단 한 줄(또는 두 줄)에 모두 들어가야 하고, 게임 화면을 가리지 않는다.
글자는 도트체(둥근모·Galmuri 느낌). 폰트를 못 쓰면 글자를 픽셀로 직접 그린다.
이모지·현대 폰트·그라데이션·둥근 카드 UI 금지.
