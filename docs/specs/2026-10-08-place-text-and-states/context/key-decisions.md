# Key Decisions

### 2026-10-08 — 3라운드 BLOCK 해소: 편집 반영 상태로 구현 착수
마지막 라운드에 REVISE 3건(행사 분류 해제 사후 상태 · 집계 응답 해석 테스트 · 버킷 크기 테스트)이 유지돼 hns 규칙상 BLOCK 이었다. 심판 편집으로 셋 다 스펙에 반영했고 사용자가 「스펙 B 도 그대로 구현 진행해」로 착수를 승인했다. 재리뷰는 하지 않는다.

### 2026-10-08 — 세션 기본값(사용자 위임)
「모두 해제」는 숨은 속성까지 비운다 · 지역 해제는 반경 유지 · `relax` 는 검색 제출·필터 적용에서 빼고 「0건 해제」 행으로 센다 · ADR-0090 에 「분류 사전 = 코드표 ∩ 그 언어 색인」 개정 한 줄.
