## 출처로 확인하지 못한 것
독립 인스턴스형 '던전'을 위 버전들의 공통 원작 기능이라고 입증하는 문헌은 검색에서 찾지 못했다. 사용자 필수 요구인 던전은 별도 공간/연속 방/입장·퇴각/수문장·보상을 가진 실제 콘텐츠로 구현하되, 원작에서 그대로 복사한 던전이라고 주장하지 않는다. 특정 버전의 모든 수치·지형·트리거를 동일복제했다고 주장하지 않는다. 확인된 구조를 유지하고 웹판 밸런스와 명칭/아트를 구분한다.

## 확정 진행
초기 거점 방어 → 사냥 포인트 환전 → 일꾼 배치/병종 고용/공방업 → 영웅 유인 공략 → 병력 승급·조합 → 외곽 주둔지 파괴 및 역습 방어 → 두 던전 공략/중간보스 → 최종 주둔지·최종보스. 병력 손실이 실제 전력 손실이고 일꾼/본진이 살아 있으면 재모집한다. RTS 클릭 노동은 파티 이동/명령/일꾼업무 UI로 단순화한다.
