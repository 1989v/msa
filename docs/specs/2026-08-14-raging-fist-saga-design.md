# DESIGN.md — 레이징 피스트 사가

벨트스크롤 액션 + 대전격투식 커맨드 격투. 이 문서는 이 게임 폴더 안에서만 유효한 디자인 SSOT다.
색은 hex 직접 입력 대신 아래 토큰명을 근거로 쓴다 (코드에서는 팔레트 객체/상수로 표현).

---

## 1. 컨셉

| 항목 | 값 |
|---|---|
| 장르 | 벨트스크롤 난투 + 모션 커맨드 격투 |
| 벤치마크 | 32비트 세대 2D 액션 (CPS2/Saturn/PS1 급 스프라이트 밀도) |
| 톤 | 밤의 항만 → 적열 제련소 → 설산 사원. 무겁고 뜨겁고, 마지막에 차갑다 |
| 시점 | 의사 3D 벨트 — x 진행 / y 깊이 / z 높이 |

---

## 2. 해상도 · 레이어 규약

| 토큰 | 값 | 의미 |
|---|---|---|
| `VW × VH` | 480 × 270 | 내부 렌더 해상도(픽셀아트 기준). 정수배로만 확대 |
| `SCALE` | 2~4 (정수) | 창 크기에서 자동 산출. `image-rendering: pixelated` |
| `HZ` | 162 | 배경 벽면 하단 = 지평선 |
| `FLOOR_TOP` | 158 | 바닥 레이어 상단 (지평선보다 4px 위에서 시작해 이음매를 감춘다) |
| `GROUND_TOP` | 176 | 걸을 수 있는 벨트 위쪽 한계 |
| `GROUND_BOT` | 254 | 벨트 아래쪽 한계 |
| `DEPTH_HIT` | 13 | 같은 깊이로 인정하는 y 오차 (타격 판정) |

**UI는 월드 버퍼가 아니라 네이티브 해상도에 그린다.** 480×270 버퍼에 한글을 그리면 뭉개지므로,
월드만 확대 합성하고 그 위에 UI를 1:1로 얹는다.

파랄랙스 계수: 하늘 `0.05~0.06` / 원경 `0.16~0.20` / 중경 `0.34~0.40` / 근경 `0.60~0.66` / 바닥 `1.0`.

## 4. 캐릭터

### 4.1 비율

발밑 원점 기준, 기본 스케일 1.0에서:

| 부위 | 길이(px) |
|---|---|
| 허벅지 / 정강이 / 발 | 21 / 19 / 8.5 |
| 상완 / 전완 | 16 / 15 |
| 몸통 / 목 / 머리 반지름 | 20 / 5 / 8.6 |
| 어깨폭 / 골반폭 | 15 / 11 |
| **전체 키** | **약 86px = 화면 높이의 32%** (요구치 25% 초과) |

보스는 `scale 1.12~1.32`, `girth 1.0~1.32` 로 실루엣을 키운다.

### 4.2 스프라이트 파이프라인

```
포즈(각도 배열) → 스켈레톤 → 볼륨 캡슐/폴리곤 렌더(3톤 음영)
  → 8방향 실루엣 오프셋으로 1px 외곽선
  → 15비트(채널당 5bit) 색 양자화   ← 32비트기 하드웨어 색 재현
  → 알파 바운딩 박스로 크롭 후 캐시
```

- 오른쪽 향만 굽고 왼쪽은 런타임에 좌우 반전 → 베이크 비용 절반.
- 프레임마다 **손 좌표/각도**를 함께 저장해서 무기와 투사체를 손에 정확히 붙인다.
- 스테이지에 필요한 캐릭터만 로딩 시점에 굽는다 (시간 예산 10ms/프레임으로 분할).

### 4.3 그리기 순서 (오른쪽 향 기준)

`먼쪽 다리 → 뒷팔 → 몸통 → 가까운 다리 → 머리 → 앞팔`
앞팔은 항상 마지막. 공격하는 팔을 `frontArm` 으로 지정해 펀치가 몸통에 가리지 않게 한다.
머리는 `두개골 → 헤어 → 머리띠 → 눈/눈썹/입 → 마스크/수염` 순서 — 얼굴이 헤어에 먹히지 않는다.

## 5. 전투 규약

### 5.1 프레임 데이터 (60fps)

| 기술 | 발동 | 지속 | 경직 | 데미지 | 비고 |
|---|---|---|---|---|---|
| 약공격 1/2 | 4 | 3 | 7/8 | 6/7 | 캔슬창 4~12 |
| 약공격 3 (회전차기) | 7 | 4 | 15 | 13 | 다운 |
| 강공격 | 9 | 4 | 16 | 17 | 다운 |
| 파열탄 (약/강) | 11/15 | 2 | 20/24 | 16/24 | 투사체 |
| 승천각 | 5 | 14 | 26 | 16+12 | 0~12F 무적 |
| 선풍참 | 7 | 22 | 20 | 9×3+14 | 전진 4다단 |
| 폭쇄장 | 13 | 5 | 26 | 32 | 벽 강타 |
| 열화연무 (초필) | 14 | 40 | 26 | 9×6+26 | 기 1칸, 0~18F 무적 |
| 천붕패황권 (히든 초필) | 26 | 10 | 34 | 120 | 기 3칸, 0~32F 무적 |

### 5.2 캔슬 규칙

`기본기 → 필살기 → 초필살기` 한 방향으로만. 히트를 맞혀야(hitConnected) 캔슬이 열린다.
기본기끼리는 `chain` 으로 이어지고(약→약→약), 필살기는 발동 이후 종료 4프레임 전까지 초필로 캔슬된다.

### 5.3 입력

- 방향 히스토리는 **입력 당시의 facing 을 함께 기록**한다. 모션 도중 캐릭터가 돌아서도 커맨드 의미가 뒤집히지 않는다.
- 매칭은 백트래킹 + 스텝별 `optional` 허용 + 스킵 상한. 승룡(623)은 창 16프레임/스킵 1로 좁게 잡아
  "앞으로 걷다가 파동" 오폭을 막는다.
- 버튼 입력 버퍼 6프레임.

## 6. UI

- 좌상단: 이름 · 잔기 하트 · 체력바(감소 잔상 포함) · 기 게이지 3칸 · 무기 잔여
- 우상단: 점수 · 스테이지/구간명 · 두루마리 수집 현황
- 좌측: 콤보 카운터 (10/20/30 히트에서 색과 문구가 승격)
- 하단 중앙: 보스 이름 + 보스 체력바 / 안내 토스트
- 전체 오버레이: 커맨드 목록(Tab), 일시정지(P), 스테이지 인트로, 클리어 정산, CONTINUE 카운트다운

폰트는 Galmuri14(제목) / Galmuri11(본문). 한글 픽셀 폰트라 저해상도에서도 자소가 뭉치지 않는다.

## 7. 연출 규칙

| 연출 | 규칙 |
|---|---|
| 히트스톱 | 기술별 4~22프레임. 월드 전체 정지, FX만 정지 |
| 화면 흔들림 | 히트스톱 강도에 비례 (`1 + hitstop × 0.42`), 세로는 60% |
| 데미지 팝업 | 20 이상은 `big` 등급(더 크고 붉게) |
| KO 슬로모 | 보스 격파 시 130프레임 동안 timeScale 0.28 + 대상 중심 14% 줌인 |
| 초필 발동 | 화면 플래시 + 히트스톱 18프레임 + 캐릭터 가산합성 발광 |
| 파괴 | 파편 14개 + 먼지 + 화면 흔들림. 드럼통은 추가로 폭발 광역 판정 |

## 8. 접근성 / 조작

- 키보드 전용. 방향키 또는 WASD 병행 지원.
- `J` 약 / `K` 강 / `L` 점프 / `U` 잡기 / `Space` 가드 / `Tab` 커맨드 목록 / `P` 일시정지 / `M` 음소거
- 커맨드 목록은 타이틀·게임 중 어디서나 Tab 한 번으로 열린다.
- 색만으로 정보를 전달하지 않는다 (체력=바 길이+숫자, 기=칸 수+MAX 문구).
