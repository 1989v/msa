## 보존하는 핵심 재미와 구성
활잡이 한 명으로 시작해 사냥 수입으로 목수를 고용하고, 목수가 채집한 금화로 활잡이를 늘리고 공방업을 올리며, 탑을 세워 주둔시키고, 활잡이 셋을 영웅으로 합쳐 거점과 전초기지를 공략한다. 그동안 본진으로 웨이브가 오고 거점을 치면 역습이 온다. 본진이 부서지면 패배. 첫 판부터 어렵고, 치료사 고리 근처에서 움직이며 싸우는 것이 생존의 기본이다.

## 구현 경계
- 서버 권위: 금화·고용·강화·피해·사망·탑·저장은 서버가 결정한다. 클라이언트는 입력과 연출만.
- 공유 순수 규칙(`Config`·`Rules`)은 Roblox API 없이 luau CLI 로 검사한다. 서버·클라이언트 모듈은 Roblox API 에 의존하며 Studio 에서 확인한다.
- 외부 에셋은 Roblox 공식 소유(creator id 1)만 쓰고 `assets/roblox/provenance.json` 에 출처·해시를 적는다. 빌더가 스크립트를 제거한다.
- 네트워크 입력은 타입·유한수·범위·빈도를 검증한다.

## 검사
1. `tests/rules.spec.luau` 가 실제 `Config`·`Rules` 를 실행해 가격·강화·합성·웨이브 구성·탑 배치 판정을 검사한다.
2. 구조 게이트(`tools/verify.py`): 모든 Luau 컴파일 · 미지 전역 · 빌더 결정성 · 서비스 배치 · 에셋 스크립트 0 · provenance 해시 일치 · **네이티브 검사**(기본 카메라가 기본값이고 Scriptable 은 전환 함수 안에만 있다 · 캐릭터 PointLight 가 있다 · 화살 연출에 Trail·ParticleEmitter·Sound 가 있다 · 키 이름 안내 문자열이 없다 · 적 템플릿이 Humanoid 리그다 · 동시 적 상한 ≤ 60).
3. Studio 실행·물리·애니메이션·터치·2인·DataStore 는 UNVERIFIED 로 남기고 사용자가 확인한다. 첫 60초(본진·첫 웨이브·화살·조명·카메라)를 먼저 보여 준다.
