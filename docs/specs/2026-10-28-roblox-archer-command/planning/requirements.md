# Requirements — 궁수 키우기(marine-command) 로블록스 이식 · 첫 범위

사용자 확정(2026-10-28): 대상은 `portal-fe/public/games/marine-command/`(공개명 「궁수 키우기」, Three.js 2D 탑다운 부대 성장 RPG)이고 `archer-outbreak`(유니티)가 아니다.
선택: ① 첫 범위 = **시작 분지 전부** ② 표현 = **3D 파트 지형 + 탑다운 고정 카메라** ③ **서버당 1~2인 협동** ④ **이 세션이 직접 구현**.
추가 지시: "로블록스로 이식이니 로블록스 구성에 최적화하면서 전환" — 원작 코드를 그대로 옮기지 않고 Roblox 의 서비스·캐릭터·입력·저장 방식에 맞게 재구성한다. 규칙·수치·초반 리듬은 원작을 따른다.

## 로블록스에서 바꾸는 것 (Roblox 최적화)
- 플레이어 아바타가 자기 원정대의 **선두 활잡이**다. 걷기는 Roblox 기본 조작(WASD·터치 스틱)이고 고용한 병력이 뒤따른다. 원작의 클릭 목적지·Shift 드래그·R 귀환은 쓰지 않는다. 서버가 틱마다 위치를 검사해 어긋나면 되돌린다(spec §R).
- 리더가 죽으면 자동 고용하지 않는다(원작에 없다). 「리더 없음」이면 본진에서 관전하며 고용 패널로 산다.
- 적·동료·목수·투사체는 **클라이언트가 그린다**(서버 10Hz 압축 패킷). 서버 Workspace 에는 지형·탑·캐릭터만 둔다.
- 동시 적 상한을 Roblox 에 맞춰 낮춘다(웨이브 150 · 주변 30). 대기열과 인원수는 원작 그대로.
- 안개(fog of war)는 첫 범위에서 뺀다. 고지→저지 LOS·절벽 사격 차단은 유지(격자 LOS).
- 저장은 DataStore. 결제 없음. 랭킹 없음.
- 화면 색·글꼴은 `marine-command/DESIGN.md` 토큰을 Luau Theme 모듈로 옮긴다.
- 2인 협동은 **호스트가 수락**해야 시작된다(공개 서버에서 모르는 사람이 솔로 캠페인을 coop 으로 바꾸지 못하게). 수락 시 본진 max+2000·hp+2000, 둘째 소유자 활잡이 1·금화 0, 이후 생성 적 ×1.5·웨이브 ×1.4·보상 ×1.5. 한 명이 나가도 coop 으로 남는다(원작과 같다). 저장은 호스트 키 하나.
