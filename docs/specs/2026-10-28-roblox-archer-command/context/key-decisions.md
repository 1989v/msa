- 액터는 클라이언트 렌더링(서버 10Hz buffer 패킷). 서버 Workspace 는 지형·탑·캐릭터만.
- 리더 위치: 서버 클램프(속도×dt×2+0.5, 통행 셀, 직선 통행) + 되돌림. 역방향 쓰기 넷(구르기·리스폰·되돌림·이어하기).

- 협동은 호스트 수락. 슬롯 userId 결속. 저장은 호스트 키 하나, 손님 저장 없음.

- Esc/Tab 안 씀, R 귀환 없음, 점프 끔, Q/E 2단계 조준.
- 카메라 경계 클램프 없음 → 벽 24 + FogEnd 180.
