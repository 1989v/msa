# 병기와 역할 — 시안 제안

아래 역사 설명과 게임 역할은 별개다. 사거리·피해·둔화·관통은 밸런스 설계이며 역사적 성능을 재현한 값이 아니다.

| 게임 후보 | 명칭·형태 기준 | 역할 제안 | 화면에서의 구별 |
|---|---|---|---|
| 투석기 | 목제 지지대, 지렛팔과 돌주머니. 특정 시대·한국 독자 발명품으로 단정하지 않음 | 느린 곡사, 넓은 착탄, 일시 감속 | 높이 솟은 팔·굵은 밧줄·큰 돌 궤적 |
| 신기전 화차 | 신기전기를 올린 바퀴 달린 발사 수레. 신기전은 화약 추진 화살형 무기 | 다수 적에게 부채꼴 일제 사격, 긴 재장전 | 다수의 가는 화살과 발사틀·불꽃 궤적 |
| 총통기 | 여러 사전총통을 묶는 방식 등. 신기전기와 구별 | 비교적 짧은 사거리의 밀집 제압 | 여러 짧은 청동 총열·짧고 조밀한 화살 묶음 |
| 대형 총통 | 천자·지자·현자·황자총통 등 조선 화포. 구체 종류는 원화 확정 때 선택 | 중갑·보스 관통 한 발, 느린 발사 | 하나의 굵은 포신·낮은 포가·강한 반동 |
| 완구 + 비격진천뢰 | 비격진천뢰는 지연 폭발 탄체이고 완구는 발사 병기 | 이후 확장 후보: 예고 후 폭발하는 지역 제압 | 위를 향한 짧은 포구·둥근 탄체·도화선 |

초기 시안은 위 네 병기를 중심으로 사람 무장과 같은 칸에 배치한다. 완구는 후속 후보로만 남긴다.
병기마다 외형뿐 아니라 탄도·발사 간격·유효 표적·지원 조합이 달라야 한다. 승급 외형은 과한 금장 대신
받침 보강, 장전 상태, 발사틀·밧줄의 구조 변화로 표현한다. 화차가 로켓 포드처럼 보이지 않게 화살과 목조 구조를 드러낸다.
