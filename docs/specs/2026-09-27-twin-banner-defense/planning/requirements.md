# 쌍성 수비대 — 디자인 단계 요구사항

가칭 `쌍성 수비대`, 작업 식별자 `twin-banner-defense`.

## 사용자가 정한 범위

- 캐주얼한 2인 협동 타워 디펜스와 싱글 플레이.
- 하나의 격자 맵을 두 플레이어가 나누어 소유하고 특성이 다른 방어 유닛을 건설.
- 기존 게임과 이어지는 한국 삼국시대~조선시대 무장·병기 콘셉트.
- 2D~2.5D 탑뷰. 디자인 시안을 먼저 진행한 뒤 개발.
- 랜덤 다이스는 장르와 플레이 구조를 설명하는 참조이며 고유 그림·UI의 복제 대상이 아니다.

## 이번 제안 — 미확정

| 항목 | 제안 |
|---|---|
| 협동 | 서로 다른 기기에서 온라인 2인. 각자 4×4, 총 32칸 |
| 싱글 | 동일한 맵에서 나 + AI 동료. 플레이어는 한 진영만 조작 |
| 승패 | 공용 성문 체력. 마지막 보스 격파 시 승리, 체력 0이면 공동 패배 |
| 길 | 고정된 외곽 길을 따라 적이 성문으로 이동. 격자는 배치 전용이며 길을 막지 않음 |
| 한 판 | 8~12분, 20웨이브를 초기 밸런스 가설로 검증 |
| 조작 | 소환, 재배치, 합성, 병종 강화, 지원. 공격은 자동 |
| 소환 | 군량 지불 → 준비한 5병종 중 무작위 1종 → 내 빈 칸 배치 |
| 합성 | 같은 병종·같은 등급 2개 → 같은 병종의 다음 등급 1개. 역할은 유지 |
| 협력 | 각자 군량·배치 소유, 공용 목표. 동료에게 군량 지원 또는 지원 표식 |
| 캐릭터 | 실제 인물의 이름을 붙이기 전 병종 6종으로 실루엣 검토 |

덱은 6종 후보 중 5종 선택 제안이다. 기본 덱과 해금 여부는 구현 명세에서 확정한다.
맵 전체 유닛이 아무 적이나 때리게 하지 않고, 배치 위치·사거리·지원 반경에 의미가 있어야 한다.
장창의 사거리, 중앙에 놓인 근접 유닛의 효용은 경로 시뮬레이션으로 검증 후 확정한다.

## 첫 구현 슬라이스의 수락 기준 초안

1. 혼자 시작해 튜토리얼, 소환·합성·강화, 보스, 승리와 패배, 재시작을 경험한다.
2. 독립된 두 브라우저에서 같은 웨이브·유닛·군량·성문 상태를 본다.
3. 상대 칸을 변경할 수 없고, 중복 입력·군량 부족·빈 칸 없음이 재화를 잃게 하지 않는다.
4. 병종별로 일반 다수 적·빠른 적·중갑 적·보스에 대한 효용이 실제로 구분된다.
5. 연결 끊김과 재접속 정책을 먼저 정하고 검증한다. 조용히 세션을 초기화하지 않는다.
6. 손가락 입력과 마우스로 같은 조작이 가능하며 병종·소유권을 색만으로 구분하지 않는다.

## 단계 범위

이번 산출물은 시안, 디자인 브리프, 요구사항, 미정 항목이다. 네트워크 구조·런타임·영구 성장·과금·카탈로그 등록·배포는 확정하지 않았다. 구현 spec/tasks 작성과 리뷰는 시안 피드백을 반영한 뒤 진행한다.
