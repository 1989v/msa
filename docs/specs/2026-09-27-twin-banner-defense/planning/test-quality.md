# 검증 계획 초안

시안 단계에서는 생성 이미지의 격자, 역할 실루엣, 아군 구별, UI 위계와 요구사항 대응을 눈으로 확인한다.
게임 코드를 만들지 않았으므로 빌드·테스트 통과를 주장하지 않는다.

| 단계 | 검증 | 중요도 |
|---|---|---|
| Unit | 고정 시드 소환, 자원 차감 원자성, 합성 조건·등급, 칸 소유권 | critical |
| Unit | 이동로 진행, 사거리, 타깃 선정, 병종별 피해·지원 효과 | critical |
| Integration | 두 클라이언트 명령 순서, 중복 입력, 권한 검증, 상태 동기화 | critical |
| Integration | 실제 2석 릴레이의 입장 핸드셰이크·이탈·재접속 정책 | critical |
| Component | 선택·합성·군량 부족·빈 칸 없음·AI 상태·키보드 포커스 | high |
| E2E | 싱글 시작→소환→합성→보스→승패→재시작 | critical |
| E2E | 독립 두 브라우저 협동 완주, 연결 끊김과 복귀 | critical |
| Visual | 가로/세로의 동일 전투 상태, 44px 터치, 작은 병종 식별 | high |

직접 조작하는 플레이테스트에서 단순 반복 소환보다 배치·역할 조합이 유리한지 확인한다.
AI 대전 로그만으로 재미나 캐주얼 난이도를 통과 처리하지 않는다.
