# Requirements — deal.1989v.com (혜택 링크 허브)

- 작성: 2026-08-19
- 상태: shaped (topology locked, R0~R2)

## 1. 무엇을 만드나

카테고리별로 **각 서비스의 혜택 링크를 모아 보여주는 공개 페이지**와, 그 링크를 등록·관리하는
어드민, 그리고 클릭을 세는 리다이렉터.

링크는 두 종류다. 이 구분이 도메인 모델의 축이다.

| 유형 | 정의 | 예 | 운영자 수익 | 공정위 고지 |
|---|---|---|---|---|
| `AFFILIATE` | 제휴 프로그램이 발급한 트래킹 URL. 유입→구매 시 수수료 | 쿠팡 파트너스, 트립닷컴/클룩 파트너 링크 | O | **필수** |
| `PLAIN` | 제휴 프로그램이 없는 곳의 공개 혜택/프로모션 페이지 | 신규가입 쿠폰, 카드 청구할인 공지 | X | 불필요 |

둘을 같은 그리드에 섞어 보여주되 배지로 구분한다. 전부 뭉뚱그려 고지하면 `PLAIN` 링크까지
광고로 읽혀 페이지 신뢰도를 스스로 깎는다.

## 2. 사용자 결정 (shaping 결과)

| 항목 | 결정 | 근거 |
|---|---|---|
| 서브도메인 | `deal.1989v.com` | 용도 기반 이름. 기존 host 1단어 규칙(`place`/`game`/`resume`)과 정렬 |
| 카테고리 | 여행 / 커머스 / 디지털구독 / 교육 / 생활·통신 | 공개 제휴 프로그램이 실제로 존재하고 업권 규제가 없는 축 |
| 제휴 현황 | 미가입. 여행(트립닷컴·클룩·아고다·마이리얼트립) 우선 가입 후 하나씩 추가 | 플랫폼을 범용으로 짓고 오퍼는 데이터로 채운다 |
| 유입 경로 | P1 = SNS/메신저 공유형 허브, P2 = 오퍼 상세 콘텐츠로 SEO 승격 | 검증 빠른 쪽 먼저 |
| P1 범위 | 공개 FE + 어드민 CRUD + `/go/{slug}` 302 + 클릭 로그 | 클릭 데이터는 처음부터 안 쌓으면 소급 불가 |
| 신선도 | 만료일 + 자동 숨김 + 어드민 경고 + **링크 헬스체크 배치** | 죽은 링크 방치가 이 종류 페이지의 주 실패 원인 |
| 성과 대시보드 | P2 | 아직 가입 전이라 넣을 데이터가 없다 |

## 3. 배제 (명시적)

- **의료·금융 카테고리** — 의료법 27조(영리 목적 환자 소개·알선·유인 금지), 금융소비자보호법
  (대출모집인 등록). "링크 타고 가서 결제하면 수수료"가 정확히 규제 대상 구조다.
  카테고리 행 자체를 만들지 않는다 (전시 테이블에 비전시 행을 심지 않는다 — ADR-0066 관례).
- **링크 변조·클로킹** — 리다이렉터는 302로 원본 URL을 **그대로** 넘긴다. 파라미터 재조립,
  iframe 래핑, 서브ID 임의 주입은 대부분의 제휴 네트워크 약관 위반이고 트래킹 쿠키를 깬다.
- **회원/로그인** — 공개 페이지. 개인화 없음.
- **다국어** — P1 한국어만. `place`/`game`의 `/en`은 대상 독자가 다르다.
- **자체 전환 추적** — 전환·정산의 원본은 각 네트워크 대시보드다. 우리는 클릭까지만 센다.

## 4. 법·정책 제약 (설계 입력)

1. **공정위 「추천·보증 등에 관한 표시·광고 심사지침」** — 경제적 이해관계 공개 의무.
   페이지 상단 고정 고지 + `AFFILIATE` 카드 배지. 문구는 어드민에서 수정 가능해야 한다
   (네트워크마다 요구 문구가 다르다. 쿠팡 파트너스는 약관상 지정 문구가 있다).
2. **구글 링크 정책** — 어필리에이트 아웃바운드는 `rel="sponsored nofollow noopener"`.
   `PLAIN` 은 `sponsored` 없이 `nofollow noopener`.
3. **thin affiliate** — 자체 부가가치 없는 링크 모음은 색인에서 밀린다. P1은 `noindex`로 두고
   P2 콘텐츠 승격 시 해제한다 (ADR-0062 호스트별 robots 분기 재사용).
4. **쿠팡 파트너스** — 사이트 사전 등록 심사, 지정 고지 문구 필수. 오퍼 등록 전 선행.

## 5. 토폴로지 (R0 gate — 확정)

```
1  deal 도메인          Category / Offer / OfferClick        (:deal:domain + :deal:feature)
2  리다이렉터            GET /go/{slug} → 302 + 클릭 적재
3  공개 FE               portal-fe host 라우팅 (deal.1989v.com)
4  어드민 CRUD           admin.1989v.com — 카테고리·오퍼·만료경고
5  링크 헬스체크 배치     CronJob (code-dictionary 이미지 재사용, 상주 파드 0)
```

## 6. 인수 조건 (P1)

- `deal.1989v.com` 이 카테고리 5종과 각 오퍼 카드를 렌더한다. 만료된 오퍼는 안 보인다.
- `AFFILIATE` 카드에 제휴 배지가 있고, 페이지 상단에 고지 문구가 고정 노출된다.
- 오퍼 카드 클릭 → `/go/{slug}` → 302 → 원본 URL. 쿼리스트링 무변조.
- 클릭 1건이 `deal_offer_click` 에 적재된다. **적재 실패가 302를 막지 않는다.**
- 만료된 slug 로 진입하면 404가 아니라 해당 카테고리 목록으로 302 (공유 링크가 안 죽는다).
- 어드민에서 카테고리·오퍼 CRUD 가 되고, "만료 임박 / 링크 깨짐" 목록을 볼 수 있다.
- 헬스체크 CronJob 이 오퍼 링크를 점검해 `link_status` 를 갱신한다.
- 메인 런처(`1989v.com`)의 전시 타일에 `deal` 이 OPEN 으로 뜬다.
- `deal.1989v.com` 은 `noindex`. apex `/deal` 은 프로덕션에서 서브도메인으로 302.

## 7. 비기능

- **신규 상시 파드 0** — free-tier 최상위 제약. code-dictionary:app 에 폴드, 헬스체크는 CronJob.
- **신규 datasource 0** — code-dictionary 의 기존 커넥션풀을 공유한다. 두 번째 HikariCP 풀은
  실제로 강제하지도 않을 경계를 위해 free-tier 메모리를 쓰는 일이다.
- 리다이렉트 P99 < 100ms (slug→URL 은 Caffeine 캐시, TTL 5분, 어드민 수정 시 evict).
- 클릭 로그 보존 90일 — 초과분은 헬스체크 CronJob 이 같이 정리한다 (배치를 또 만들지 않는다).
