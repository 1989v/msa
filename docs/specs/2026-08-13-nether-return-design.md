# 황천 회귀 (Nether Return) — 로그라이크 액션 로그라이크 액션 RPG

> **Status**: 구현 진행 중 (이 문서가 단일 설계 원본 — 세션이 끊겨도 여기서 재개한다)
> **Slug**: `nether-return` · **위치**: `portal-fe/public/games/nether-return/`
> **목표**: 기존 캔버스 게임과 격이 다른, 장르 벤치마크작급 룩앤필과 게임 루프.
> 콘텐츠(시나리오/퀘스트/스킬)는 1차 완성 후 개편 가능 — **벤치마크작 같은 게임이 나오는 것**이 1순위.

## 1. 컨셉

저승(황천)에 떨어진 주인공이 이승으로 **탈주를 반복**하는 런 기반 로그라이크.
벤치마크작의 핵심 루프를 그대로 옮긴다:

1. 허브(망자의 안식처)에서 영구 강화·스토리 대사 → 런 시작
2. 방(전투 챔버) 클리어 → **문 보상 미리보기** 중 선택(장르 시그니처)
3. 신격의 **문장(=분/Boon)** 을 모아 빌드 구축, 희귀도 4단계
4. 계층 보스 격파 → 다음 계층 → 최종 관문 → 사망/승리 → 허브로, 명전(冥錢)은 유지

한국 저승 신화 스킨 (그리스 신화 = 벤치마크작 IP 회피 + 차별화):
신격 4주 — **염라대왕**(화염/처형), **바리공주**(생명/치유), **강림차사**(대시/신속), **마고할미**(대지/방어).

## 2. 규모 (벤치마크작 수준 요구 — 사용자 명시)

- **3계층 + 최종전**: 한 런 = 약 25방 (계층당 7방 + 보스)
  - 1계 「재의 뜰」 (잿빛/보라) — 임프·해골궁수 / 보스: 오거 문지기
  - 2계 「핏빛 회랑」 (적색) — 촐트(3방향 화염)·가면오크 돌진 / 보스: 대악마
  - 3계 「망각의 옥좌」 (청록) — 전 종족 정예화·네크로맨서 / 최종 보스: 재의 군주 (2페이즈)
- **런 이어하기**: 중단 시 런 상태(방 인덱스·HP·문장·명전·시드·RNG 상태) 직렬화 저장 → 재접속 시 복원.
  짧은 캐주얼이 아니라 **끊었다 이어하는** 게임.
- **예언 목록**(업적형 체크리스트): 업적형 퀘스트 체크리스트, 달성 시 명전 보상 (첫 보스 격파, 문장 12개 수집, 무피격 방 10회, 계층별 첫 돌파, 승리 …)
- **허브 스토리**: 런 횟수·진행 마일스톤에 따라 갱신되는 NPC(뱃사공) 대사 — 장르 표준식 내러티브 루프의 최소 구현.

## 3. 전투 (타격감 체크리스트 — 전부 필수)

- **대시**: 0.16s / 220wpx, **무적 프레임**, 잔상 고스트, 기본 1충전(메타·문장으로 +)
- **3연격 콤보**: 전방 원호, 마지막 타 강타(넉백·1.6배), **공격 시 전방 러지**(장르 시그니처)
- **캐스트**: 영혼 파편 투척(자동 조준 보정), 쿨다운형
- **히트스톱**(40ms), **화면 흔들림**, 피격 백색 플래시, 데미지 숫자(치명 강조), 처치 파편
- 적 공격은 **전부 텔레그래프**(예고 도형 0.4s) 후 발동 — 회피 가능해야 함
- 저체력 붉은 비네트 펄스, 방 클리어 슬로모(0.3s)

## 4. 문장(Boon) 시스템

- 신격 4주 × 5문장 = 20종 + 전설 4종. 희귀도: 일반(1x)/희귀(1.5x)/영웅(2.25x)/전설(고유효과)
- 효과는 스탯 테이블 + 훅(onHit/onDashEnd/onHurt/onKill)으로 구현
- 방 클리어 보상 문: **문장/명전/회복(부적)/단조(무기 강화)** 아이콘 미리보기, 2택 분기 존재
- 선택 UI: 대형 카드 3장(신격 문양·이름·희귀도 색 테두리·설명·신 대사 1줄)

  뷰보다 큰 방은 **카메라 추적**. 구덩이(이동 불가)·기둥·가시·해골 장식. E2E 로 방마다 구조가 다름을 실측
