# EPOCH OF NATIONS — 제작 기록

헥스 대륙 턴제 4X 전략. 게임 파일은 `portal-fe/public/games/epoch-of-nations/`, 카탈로그 시드는 `V95__seed_epoch_of_nations.sql`.

## 어떻게 만들었나
- **game-forge 키트 첫 실전** (`docs/standards/game-forge/`). 레포 밖 빈 폴더에서 프롬프트 한 번으로 만들고, 17축 게이트 PASS 본을 옮겼다
- **아트는 클로드 디자인** 프로젝트 「EPOCH OF NATIONS — 아트 시안」(projectId `a426416e-114c-47c9-bcfc-735575612c78`)에서 1~4차(지형 → 유닛 → 도시·문명 → 화면)로 먼저 받았다
- 제작 세션이 실수로 둘 돌았다(첫 실행의 종료가 껍데기 프로세스만 죽였다). 두 판이 각자 완성에 가까웠고 **게이트 17/17 을 먼저 통과한 `session-b` 판**을 골랐다.
  나머지 판(16/17, FPS 미측정)은 `~/games/epoch-of-nations` 의 `main` 브랜치에 남아 있다

## 라운드
배포 전 **벤치마크 일치도 심사**(만든 과정을 모르는 서브에이전트가 소스만 읽고 원작 대비 누락을 찾는다)를 돌리고, 나온 결함을 같은 forge 폴더에서 다음 라운드로 고쳤다.
각 라운드의 완성 조건은 판정 도구 0 실패 + 회귀 주입 빨간불 · 게이트 17/17 · 스크린샷 판독 · 온라인·방치 E2E 재통과다.

심사가 찾은 3차 결함은 **2차 도구가 재지 않는 칸**에 있었다 — 코드만 고치면 다음에 또 숨으므로 도구 범위를 같이 넓혔다.
통합 세션이 도구 셋을 직접 다시 돌리고, 라운드마다 회귀를 직접 넣어 빨간불을 확인했다(2차: 약탈 금 효과 삭제 → `failed ["raid"]` · 3차: 전쟁 판단을 전체 군사력으로 되돌림 → `hiddenReads 224531` · 4차: 경기장 반경 끊기 → `arena_maximus`, 무덤 공짜 횟수 상수 → `sun_tomb` · 5차: 문구 없는 효과 키 → 부팅 거부).
