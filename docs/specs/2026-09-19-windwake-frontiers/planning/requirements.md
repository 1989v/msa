# Requirements

Expand the existing original WINDWAKE into a bright exploration/life/defense adventure. Area must exceed 50 times the original 240×240m; choose 1920×1920m (64×). Region variety, meaningful encounters, new skills, farms, customizable village and repeated night defense must connect into one playable progression.

Keep the original central sanctuaries and spatial controls. A first guardian is an early milestone; regional bosses and a later capstone extend progression. Discovered waypoints connect distant places. No external engine, assets or game-service backend is required. User delegates content and implementation decisions, so no additional design interview is necessary.
