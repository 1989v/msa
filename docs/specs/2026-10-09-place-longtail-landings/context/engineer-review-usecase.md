## Findings

### U1. 운영자의 검수·게시 흐름이 끝까지 그려지지 않았다 (체크: Main/Alternative flows, Postconditions)
- 스펙: draft → published 전환은 머리말 수정 + 검수자 필수(`spec.md:26`), 게시는 Out of Scope(`spec.md:39`).
- 빠진 것: ① 게시 단계(머리말 수정 → 커밋 → 배포) ② 게시 뒤 사후조건 — sitemap·llms 포함, noindex 해제, `/guides` 목록 노출, 허브·지역·랜딩에서 편집 페이지로 가는 내부 링크(계획 S3-1 "내부 링크 확인", `work-plan.md:93`) ③ 검수 뒤 색인 값이 바뀌어 카드 사실이 달라지는 경우(카드는 빌드마다 색인에서 다시 받으므로 검수 시점과 게시 문서가 갈린다 — `reviewedAt` 의 의미).
- 수정안: SR-3 에 「게시 절차 3줄」과 「published 의 사후조건」을 적고, 카드 값이 검수 뒤 바뀌는 것은 허용(날짜 표기)인지 차단인지 한 줄로 정한다.

### U2. `/guides` 목록 주소의 응답이 정해지지 않았다 (체크: Exception flows)
- 스펙: "published 만 보인다(지금은 0 — 빈 목록 대신 링크를 내지 않는다)"(`spec.md:28`).
- 링크를 안 내도 주소로 직접 오면 무엇이 나가는지 없다. location 이 없으면 SPA 셸 200 + NotFound(noindex)다(`nginx.conf:331-332`, `App.tsx:334-338`) — 스펙이 랜딩에서 피하려던 soft 404(`spec.md:4`)와 같은 상태.
- 수정안: published 0 이면 `/guides` 는 404(프리렌더 파일 없음 + `=404`), 1 이상이면 목록 프리렌더 — 랜딩과 같은 규칙으로 명시.

### U3. 랜딩이 빌드 사이에 사라지는 흐름이 없다 (체크: Exception flows, Edge cases)
- 스펙: 선정은 빌드마다(`spec.md:13`), 미선정은 404(`spec.md:16`).
- 이미 색인·공유된 랜딩이 다음 빌드에서 빠지는 경우(건수 10 미만 하락, 순위 5위 밖)의 사용자 경험(404)과 크롤러 처리(색인 제거)가 정의돼 있지 않다. 계획은 2~4주 색인률을 본다(`work-plan.md:94`).
- 수정안: implementation I4 와 같다 — 목록 고정 + 미달 시 처리 규칙, 또는 이탈 주소의 301 대상(같은 시군구 지역 페이지)을 명시.

### U4. 사용자가 조건을 바꾼 뒤의 주소가 공유 시 다른 화면을 연다 (체크: Alternative flows)
- 스펙: 조건이 바뀌어도 주소는 그대로(`spec.md:20`), canonical 도 그대로(`spec.md:22`).
- 결과: `/regions/11110/parking` 에서 속성을 풀고 다른 시도로 옮긴 화면을 복사·공유하면 받는 사람은 프리셋 화면을 본다. 허브의 속성 칩은 원래 주소를 만들지 않으므로(`PlacePage.tsx:339`) 허브와 같은 성질이지만, 랜딩에서는 주소가 조건을 「말하고」 있어 어긋남이 눈에 띈다.
- 수정안: 의도된 동작이면 그렇다고 한 줄 남긴다(대안: 조건이 바뀌면 `replace` 로 허브 주소 `/` 로 옮긴다 — 다만 SR-2.1 은 히스토리 교체 없음을 택했으므로 그 이유를 적는다).

### U5. 랜딩의 사전조건·메타가 빠졌다 (체크: Preconditions, Edge cases)
- 사전조건: 시군구 코드는 `administrative-regions`(`prerender-seo.mjs:953-967`)에서 오고 언어별 건수 0 지역은 이미 빠진다. 랜딩 후보는 그 목록 안에서만 뽑는다고 적어야 지역 페이지가 없는 랜딩(부모 링크가 404)이 생기지 않는다. 세종처럼 시군구가 없는 시도의 처리도 한 줄.
- 같은 이름 시군구(중구·동구 등)의 h1 중복은 domain D5. title·description 정의 부재는 implementation I9.
- 형제 링크가 0개인 랜딩(같은 시군구 다른 속성·같은 시도 같은 속성이 모두 미선정)은 지역·허브 링크만 남는다 — 허용인지 명시.

### U6. 0건/미선정 주소 응답의 본문 (체크: Exception flows)
- 스펙은 미선정 주소에 nginx `=404`(`spec.md:16`). 선례 `return 404`(`nginx.conf:215-217`)처럼 nginx 기본 404 본문이 나가 사용자는 사이트 안내 없이 막힌다.
- 수정안: 기본 본문 허용인지, 또는 `error_page 404` 로 SPA 셸을 **404 상태로** 내서 「따로 모은 페이지가 없습니다 + 지역 링크」(SR-1.5 의 SPA 문구)를 보여 줄지 정한다. 후자면 SR-1.5 의 SPA 분기가 실제로 도달 가능한 경로가 된다(implementation I8 과 연결).
