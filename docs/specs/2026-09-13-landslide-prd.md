# 사태(沙汰) (landslide) — PRD

- 일자: 2026-09-13
- 형태: 캔버스 2D · **턴제 포격 대전** · 2~8인(개인전·팀전) · 플랫폼 릴레이 위 **결정론 락스텝** · 파드 0
- 상태: **설계 승인** (2026-09-13) — 다음은 원화·시안(클로드 디자인) → 클린룸 서브세션 수직 슬라이스
- 가제: 「사태」(산사태의 沙汰). slug `landslide`. 이름은 §12 미결정

## 0. 한 줄 정의

**쏘면 파이고, 파인 것은 흘러내리고, 뜨거우면 바람이 솟는다.**
삼국시대~조선의 무장 여덟이 한반도의 화산·사구·설원에서 활과 총통과 검으로 순서대로 겨룬다.
지형은 지워지지 않고 흐른다 — 파묻고, 무너뜨리고, 굳히는 것이 조준만큼 중요하다.

## 1. 왜 지금인가

| 근거 | 내용 |

## 2. IP 경계 — 무엇을 쓰고 무엇을 안 쓰나

저작권은 아이디어가 아니라 표현을 보호한다. 다만 한국 대법원은 2019년 퍼즐 게임 사건에서
**규칙의 선택·배열·조합이 창작적 표현이 될 수 있다**고 보았고, 부정경쟁방지법의 성과 도용
조항도 같은 방향이다. 그래서 "아트만 바꾸면 된다"가 아니라 **조합 자체가 달라야** 한다.
(이 절은 설계 지침이지 법률 자문이 아니다.)

| 구분 | 항목 |
|---|---|
| **장르 관용 — 쓴다** | 순차 턴 · 각도+파워 조준 · 중력 · 바람 · 파괴되는 지형 · HP · 낙사·익사 · 폭발 반경 · 팀전 · 이동 게이지 · 서든데스라는 개념 · 아이템이라는 개념 |
| **이 게임 오리지널** | 재질표와 정착 물리(흐르는 지형) · 온도→기류장 · 매몰 피해 · 에너지식 아이템 경제 · 전투가 만드는 「뭉친 기」 픽업 · 지진 서든데스 · 검기(지형 절단) · 삼국~조선 무장 병과 셋 · 실존 무기 목록 · 유닛·이름·아트·사운드·UI 전부 |
| **쓰지 않는다 — 참조작 고유 표현·조합** | 참조작의 이름·유닛·아이템·맵·음성 · 특정 유닛 스탯표 · 아이템 카탈로그 · 밧줄·제트팩류 이동 · 물 차오르기 서든데스 · 상자 드롭 · 참조작 이름을 코드·문서·카탈로그·마케팅 어디에도 쓰지 않음 |
| **제작 규율** | 클린룸 — 참조작의 아트·사운드·UI 화면을 열지 않는다. 규칙은 이 문서의 재질표에서만 파생한다 |

## 3. 벤치마크 하한 (수치)

참조작 이름을 적지 않으므로 하한은 **수치로만** 둔다. 슬라이스 단계에서 전부 잰다.

| 축 | 하한 | 잰다 |
|---|---|---|
| 한 판 인원 | 2~8 (사람 + 봇). 빈 좌석·이탈자는 봇 | 릴레이 좌석 · 봇 충원 게이트 |
| 한 판 길이 | **8~15분** (8인 기준 30턴 안팎). 20초 턴 × 8 = 한 바퀴 ≤ 2분 40초 | `PaceGate` — 봇 8인 판 100회 |
| 맵 | 1600×900 셀 기본. 최대 축소에서 **전모가 한 화면** (G1 하한) | 축척 게이트 |
| 축척 | 유닛 높이 24셀, 기본 줌에서 화면 세로 480셀 → **1/20**. 줌 3단 (240/480/900) | CDP 실측 렌더 높이 |
| 바이옴 | 3 (화산·사구·설원) + 혼합 맵. 절차 생성 + 시드 | 시드 계약 |
| 병과 × 무기 | 병과 3 × (기본 1 + 에너지 무기 3~4) = **12종 이상** | — |
| 조작 | 모바일 1순위. 드래그 조준(당겨서 각도·파워), 이동은 목표 지점 탭 | 세로·가로 CDP 좌표 탭 |
| 성능 | 실기 ≥45fps (조준 중), 정착 단계 ≤1.5초 | 헤드리스 + 실기 |
| 첫 판부터 어렵다 | 봇은 실제 탄도 시뮬로 조준한다 — 기류까지 계산한다. 난이도는 오차 폭으로만 조절하고 1단계도 봐주지 않는다 | 봇 300판 |

## 4. 핵심 물리 — 재질 하나로 지형·흐름·기류

세계는 2D 셀 격자(1 셀 = 1 월드 단위, `Uint8Array`). 셀은 재질 하나를 갖는다.
**재질표 6종이 게임의 물리 전부**다 — 맵·아이템·병과 규칙은 여기서만 파생한다.

### 4.1 재질표

| 재질 | 종류 | 흐름 | 온도 | 변화 |
|---|---|---|---|---|
| 바위·현무암 | 고체 | 안 흐름 | — | 폭발에만 깎임 |
| 흙 | 고체 | 깎이면 **가루로 부서진다** | — | — |
| 모래·화산재·눈 | 가루 | 흘러내림. 재질별 미끄러짐 문턱(옆 기둥 높이차) 모래 1 · 화산재 2 · 눈 3 | 눈은 차가움 | 눈은 열 받으면 물 |
| 용암 | 액체 | 수평으로 퍼짐 | **뜨거움** | 3턴 뒤 굳어 현무암 |
| 물 | 액체 | 수평으로 퍼짐 | 중립 | 용암과 닿으면 둘 다 현무암 |
| 얼음 | 고체 | 안 흐름 | 차가움 | 열 받으면 물 |

문턱값은 초기값이다 — 슬라이스에서 "고지가 몇 턴을 버티나"로 조정한다.

### 4.2 정착(settle) — 지형 물리는 발사 직후에만 돈다

```
발사 → 탄도 적분(기류 포함) → 착탄·폭발(재질 제거·변환·열 부여)
→ 정착: 가루 낙하·미끄러짐, 액체 퍼짐, 재질 변환(눈→물, 물+용암→현무암) — 안정될 때까지, 최대 900스텝
→ 온도장·기류장 재계산 → 유닛 낙하·매몰·용암·익사 판정 → 다음 턴
```

- 조준 중에는 **아무것도 움직이지 않는다**. 모바일 부담이 0이고, 결정론은 정착 스텝 상한 하나로 보장된다.
- 턴 시작에도 짧은 정착이 있다: 용암 굳기 카운터 감소, 지진(§5.6) 적용.
- 렌더는 지형을 오프스크린 캔버스에 한 번 그리고 정착 뒤 **더티 사각형만** 갱신한다. 프레임마다 격자를 다시 그리지 않는다.

### 4.3 기류장

굵은 격자(40×20, 셀 40×45 단위) 위의 2D 벡터장. 정착 뒤 재계산.

```
기류 = 기본 바람(맵 프로파일, 턴마다 ±변동, 화면 상단에 표시)
     + 온도 항(그 칸의 용암·열원 수 − 눈·얼음 수 → 위/아래 성분)
     + 지형 그림자(높은 지형 바로 뒤는 약해진다)
```

- 탄은 `중력 + 항력 × (기류 − 탄 속도)` 로 적분한다. 항력 계수는 탄종이 정한다(화살 큼 · 포탄 작음 · 신기전은 기류 방향으로 가속).
- 기류는 **항상 보인다** — 유선(流線)과 흐르는 입자로. 읽을 수 없는 흐름은 규칙이 아니라 운이다.

### 4.4 결정론

- 물리는 **정수 고정소수점(16.16)**. 시뮬 패키지 안에서 `Math.sin/cos/pow/exp/random` 을 금지한다(lint grep 게이트). 삼각함수는 정수 테이블.
- 난수는 판 시드에서 파생(시드 계약 — `docs/standards/game-cleanroom-pipeline.md`). 난수 소비 순서를 바꾸는 변경은 맵을 바꾼다 — 단계는 맨 뒤에 붙인다.
- 검사: 같은 입력 로그 두 번 재생 → 같은 해시(단위) · Chrome/WebKit 교차 재생 → 같은 해시(E2E).

## 5. 판 구조

### 5.1 인원·편성

- 2~8인. 개인전 / 팀전(2v2 · 3v3 · 4v4 · 비대칭 허용). 방장이 좌석을 팀에 배정한다.
- 빈 좌석과 이탈자는 **봇**. 판 중간 충원은 없다.
- **1인 1기**, 병과 셋 중 하나(§6). 시대 스킨은 외형만.

### 5.2 턴

- 순차 턴 **20초**. 팀전은 교대(A1→B1→A2→B2…).
- **남의 턴에 미리 조준**할 수 있다 — 내 턴에는 발사만. 8인 순차 턴의 대기 시간을 이것이 지운다.
- 턴당 이동 게이지(궁수·포수 기본 120셀, 검사 **300셀** — 2.5배). 이동은 목표 x 를 정하면 결정론 경로로 걷는다 — 경사 문턱을 넘거나 절벽이면 멈춘다.
- 타임아웃은 패스. 타임아웃·봇 입력은 최저 좌석이 생성해 방송한다(§7.3).

### 5.3 노템전

기본 무기 + 이동 + 파내기(매몰 시)만. 흐르는 지형 덕에 이것만으로 파묻기·산사태가 성립한다.
**조준 실력의 판**이고, 슬라이스가 이것이다.

### 5.4 템전 — 에너지식, 상자 드롭 없음, 「뭉친 기(氣)」

- 매 턴 시작 **에너지 +1** (상한 6). 에너지 무기는 비용 1~3. 무기는 전부 병과 소속(§6)이고 전부 **실존 무기 또는 재질 물리의 파생**이다.
- 하늘에서 떨어지는 상자는 없다. 대신 **전투가 기를 만든다**:
  - **게이지**: 전원 공용 하나. 피해 1 = 1, 파괴된 셀 100 = 1. 문턱(초기 30)에 닿으면 다음 턴 시작에 「기」가 생성되고 게이지는 0. HUD 에 항상 보여 "곧 나온다"를 전원이 안다.
  - **위치**: 시드 난수로 **순수 랜덤**(착탄 가중 없음). 조건 — 지표면 · 모든 유닛에서 150셀 이상(공평) · 바위 안 금지. 조건을 만족하는 후보 중 하나를 뽑는다(거르기는 난수를 뽑은 뒤 — 시드 계약).
  - **줍기**: 걸어서 닿으면 **+3**(상한의 절반). 3바퀴 안에 안 주우면 흩어진다.
  - **지형을 따른다**: 정착 물리에 실려 떨어지고 **묻힌다** — 산사태로 상대 쪽 기를 파묻거나 내 쪽으로 흘려 내리는 것이 전술이 된다. 묻힌 기는 파내야 한다.
  - 기본 +1 은 "누구나 무기를 쓴다"를, 기는 "더 쓰려면 움직여라"를 맡는다. 발이 느린 포수가 굶지 않고, 검사(이동 2.5배)가 독점하지도 못한다.
- 노템전에는 에너지도 기도 없다(순수 조준 판).

### 5.5 피해

| 원인 | 규칙 |
|---|---|
| 직격 | 탄종 피해 |
| 폭발 반경 | 거리 감쇠 |
| **매몰** | 몸의 절반 이상이 가루·흙에 묻히면 턴마다 피해. 자기 턴에 "파내기"로 나온다(이동 게이지 소모, 검사는 절반) |
| 낙사 | 낙하 높이 비례 |
| 용암 접촉 | 큰 지속 피해 |
| 익사 | 머리까지 물에 잠기면 턴마다 피해 |
| 근접 강타 | 검사 전용. 화살 직격의 1.6배 + 밀어내기(낙사·매몰 유도) |
| 검기 절단선 | 선분 위 유닛에 화살의 0.6배. 본 효과는 지형 절단 → 정착에서 산사태 |

### 5.6 승리·서든데스

- 마지막 생존 팀(개인전은 마지막 한 사람). 2~8위를 기록한다.
- **30턴 뒤 지진**: 매 턴 시작에 모든 가루 재질의 미끄러짐 문턱이 1씩 줄어 고지가 무너진다. 물·용암 차오르기는 쓰지 않는다(§2).

## 6. 병과 — 삼국시대~조선 무장 셋

| 병과 | 기본 무기 | 탄도 문법 | 지형·기류와의 관계 | 에너지 무기(비용) |
|---|---|---|---|---|
| **궁수** (기본) | 각궁 | 빠르고 낮은 궤적. 가벼워 **기류 영향이 크다** — 조준 실력의 병과 | 지형 파괴 거의 없음 | 편전(1 — 관통·초장거리, 항력 최소) · 불화살(2 — 착탄점에 열원, 눈·얼음을 녹이고 기류를 띄움) · 신기전(3 — 로켓, 기류 방향으로 가속) |
| **포수** | 총통 | 느린 곡사, 파워 게이지 큼, **지형 파괴 큼** | 산사태·매몰을 만드는 병과 | 대완구(2 — 대형 곡사, 반경 최대) · 비격진천뢰(2 — 시한탄, **흐르는 지형 위를 구른다**) · 화차(3 — 산탄 다발, 가루 흩뿌려 매몰) · 질려포통(1 — 파편) |
| **검사** | 환도 — 근접 강타 **또는** 검기 | 근접 강타: **궁수 기본 화살 직격의 1.6배** + 밀어내기. 검기: **직선** 200셀, 곡사 불가, 유닛 피해는 화살의 0.6배. 이동 게이지 **2.5배**, 파내기 절반 | **검기(劍氣)로 지형을 선분으로 자른다** — 잘린 쪽이 흘러내려 산사태. 지형이 무기인 병과 (노템전에서도 기본기라 지형 절단이 된다) | 장검기(2 — 사거리 400셀·유닛 피해 화살과 같음) · 방패(1 — 다음 상대 턴까지 정면 피해 절반) · 도약(1 — 이동 게이지 추가) |

- 병과는 능력을 정하고, **시대 스킨**(고구려 개마무사 · 신라 화랑 · 고려 · 조선 갑사 등)은 외형만 정한다. 능력치 차이 없음.
- 검기는 사극 판타지 요소로 인정한다(사용자 승인). 궁수·포수는 사실 기반.
- **검사의 보상 근거**: 검기는 직선이라 **곡사가 안 된다** — 엄폐 너머·고지 위를 못 때린다. 그 값어치를 이동 거리(2.5배)와 근접 피해(1.6배)로 돌려준다. 이 둘이 검사 밸런스의 손잡이다.
- 커스터마이징: 스킨 + 팀색 + 엠블럼(amp-arena 의 12×12 격자 엠블럼 재사용).

## 7. 네트워크 — 결정론 락스텝, 서버 변경 0

### 7.1 왜 락스텝인가

| 후보 | 판정 | 근거 |
|---|---|---|
| **결정론 락스텝** | **채택** | 턴 입력이 수십 바이트. 전원이 같은 시뮬을 돌리면 스냅샷도 권위도 필요 없다. 정수 물리로 결정론을 잡는다 |
| 호스트 권위(amp-arena) | 탈락 | 60틱 스냅샷은 턴제에 과하다. 지형 격자(1.4MB)를 스냅샷으로 나를 수 없다 |
| 서버 권위 | 탈락 | 파드 0 원칙. 게스트 랭킹이 없어 치팅 방어 실익도 작다 |

### 7.2 프로토콜 — 릴레이 그대로

`/ws/games/landslide`, `join(seats=8)`. **릴레이 변경 없음.** `move` 는 방 전체 방송(전원이 모든 입력을 필요로 하므로 `to` 를 쓰지 않는다).

| 메시지 (릴레이 `move` 페이로드) | 내용 | 크기 |
|---|---|---|
| `setup` (최저 좌석, `start` 직후) | 판 시드 · 모드(템전/노템전) · 팀 배정 · 바이옴 | <200B |
| `turn` | `{좌석, 턴번호, 이동 목표 x, 각도(0.1°), 파워(0~1000), 무기 id, 검기 선분}` | <100B |
| `hash` (턴 끝) | `{턴번호, 월드 해시}` | <40B |
| `pass` / `bot` (최저 좌석) | 타임아웃 패스 · 봇 좌석의 `turn` | <100B |

### 7.3 봇·타임아웃·승계

- 봇과 타임아웃의 입력은 **최저 좌석이 생성해 방송**한다 — 그래야 전원이 같은 값을 본다. 봇의 조준은 실제 탄도 시뮬을 각도×파워 격자로 훑고 국소 정제(8봇 × 400 시뮬 × 200스텝, 모바일에서도 수십 ms).
- 최저 좌석이 나가면(`left`) 다음 좌석이 그 역할을 잇는다 — **상태 이전이 없다**, 전원이 같은 상태를 이미 갖고 있다.
- 무언 이탈: 해당 좌석의 `turn` 이 타임아웃(20초 + 3초 유예)까지 없으면 최저 좌석이 `pass` 를 낸다. 두 턴 연속 무응답이면 그 좌석은 봇이 된다.

### 7.4 디싱크 가드

- 턴 끝마다 월드 해시(재질 격자 + 유닛 상태 FNV-1a)를 방송. 다수와 다른 좌석은 **입력 로그 전체를 처음부터 재생**해 재동기한다 — 로그가 작고 시뮬이 결정론이라 스냅샷 전송이 필요 없다(30턴 재생 수 초).
- 재생 뒤에도 다르면 그 좌석은 관전으로 내려가고 봇이 잇는다. 이 사건은 계측한다(발생하면 결정론 게이트가 놓친 것).

## 8. 맵

- 절차 생성 + 시드. 바이옴 프로파일 = 재질 층 배치 + 기본 바람 프로파일 + 열원 배치.
- **화산**(한라·백두 — 화산재·용암·현무암, 열원 많음, 상승기류) · **사구**(서해안 — 모래·바위, 기본 바람 강함) · **설원**(개마고원 — 눈·얼음·물, 하강기류) · **혼합**(예: 얼음 위 화산, 눈 덮인 사구). 혼합은 프로파일 둘을 섞는 것이라 코드가 늘지 않는다.
- 맵 크기는 인원과 무관하게 1600×900. 시작 위치는 팀별로 갈라 배치(개인전은 균등 분산).
- 시드는 결과 화면에 「지도 #」로 보인다.

## 9. 플랫폼 통합·제작 순서

- 캔버스 2D + TypeScript. 소스는 games 서브모듈 `portal-fe/public/games/_src/landslide/`, 게시는 `landslide/`. 카탈로그 BETA · IFRAME · LANDSCAPE, 순위표(online/practice, 점수 = 승 100 · 격파 30 · 피해 1), `lib/auth.js`. amp-arena 의 게시 절차(`tools/publish-games.mjs` → `update-index`)를 그대로 쓴다.
- 모바일 1순위: 가로 고정 + 세로 회전(amp-arena `ui/orient.ts` 방식). 조준은 드래그, 이동은 탭.
- **순서** (단계마다 이어받기 문서):
  1. PRD (이 문서)
  2. **원화·시안** — 클로드 디자인: 병과 3 실루엣 · 바이옴 3 화면 · HUD(기류 유선·에너지·턴 순서) · 시대 스킨 예시. 사용자 확인 뒤 코드
  3. 클린룸 서브세션 **수직 슬라이스**: 노템전 궁수 1v1 vs 봇, 화산 맵 1, 정착·기류·조준·피해·승리·지진 전부 + 게이트(결정론·축척·fps)
  4. 사용자 체크
  5. 확장: 포수·검사 → 템전 무기 10종 + 뭉친 기 → 팀전·8인 → 바이옴 3 + 혼합 → 온라인(릴레이) → 순위표·엠블럼 → 게시
- 클린룸 조건: 다른 게임 폴더·참조작 자료 열람 금지. 서브세션에는 이 PRD 와 원화만 전달한다.

## 11. 예산·제약

- 파드 0, 릴레이 변경 0. OCI 무료 티어 안.
- 릴레이 메시지 상한 4KB · 40 msg/s — 이 게임의 최대 메시지는 `setup` <200B 라 여유가 크다.
- 지형 격자 1600×900 `Uint8Array` 1.44MB — 메모리는 문제 없고, 렌더는 오프스크린 + 더티 사각형으로 프레임 비용을 격자 크기에서 떼어낸다.

## 13. 미결정

- **이름**: 「사태」는 가제. 무장 컨셉이 확정된 뒤 다시 본다.
- **로비 설정 전달**: 모드(템전/노템전)·팀 배정을 `join` 전에 알릴 방법 — 방 코드 접미사(예: `item-4v4`) vs 릴레이 `join` 한 필드 확장. 방 코드가 싸다(릴레이 변경 0 유지).
- **갯벌(진흙) 재질**: 느리게 흐르는 가루로 4번째 바이옴 후보. v1 제외.
- **관전 카메라**: 남의 턴에 탄도를 따라갈지, 내 유닛에 머물지 — 슬라이스에서 정한다.
