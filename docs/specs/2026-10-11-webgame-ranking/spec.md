# 네이버 웹게임 상위 노출 보완 2차

## 승인·목표

사용자의 2026-10-11 `진행` 요청으로 기존 진단 9절의 후속 작업을 실행한다.
목표는 네이버 `웹게임` 검색에서 서비스 홈페이지의 상위 노출이다. 아래 변경·검증 통과는 순위 달성 증명이 아니다.
기존 ADR-0062 내 FE 콘텐츠 보완 L2. 새 아키텍처·백엔드·DB·게임 본체 변경 없음.

## 이번 구현

- 홈페이지의 기존 이용 안내 영역에 대표 게임 3개의 실제 선택 이유와 상세 링크를 더한다. 대상: `block-burst`, `mine-pioneer`, `rift-front`.
- 단순한 추천 순위 대신 각 게임의 다른 플레이 방식과 대상 이용자를 설명한다. 근거 없는 인기·최고·추천 시간·모든 게임 모바일/저장/멀티 지원 주장은 금지한다.
- 대상 상세 소개에 목표·조작법·첫 플레이 팁을 추가한다. 한국어·영어 대응. 소개는 플레이 버튼을 밀어내지 않도록 기존 소개 패널 내부에 둔다.
- 안내 문구와 링크는 런타임·프리렌더 공통 JS 원본을 사용한다. 해당 안내가 없는 게임은 기존 상세 유지. 추천 링크의 해당 언어 경로를 유지한다.
- 실제 게임 소스·화면의 문구 및 로직을 읽고 설명 근거를 파일/라인과 게임 소스 revision으로 기록한다. `portal-fe/public/games` 소스는 읽기만 한다.
- 부정확한 title·description·canonical·alt가 발견되면 이 범위의 명확한 결함만 보완한다. 키워드 반복·유사 페이지 대량 생성·허위 FAQ/schema 평점은 하지 않는다.
- 기존 광고·개인화·장르/태그/정렬·플레이/랭킹/기록 UI 유지. 홈페이지 메타 전체 82종 회귀 유지.
- DESIGN.md k-heritage/arcade의 기존 토큰·타이포·레이아웃 재사용. 신규 hex·카드 그리드·장식 추가 없음.

## 검증

- 안내 대상/비대상, ko/en 문구·링크, 초기 HTML과 런타임 일치, 기존 meta 전체 수·canonical을 관련 회귀로 검증.
- 실제 게임 소스에서 제어키·목표·팁 근거 점검. 게임을 실제 플레이했다는 근거 없는 표현 금지.
- 콘텐츠 생성 → `npx tsc -b` → Vite 빌드, 관련 Vitest, 변경 ESLint, git diff --check.
- 모바일390/데스크톱1280에서 홈페이지·대상 상세 읽기·링크·플레이 버튼·가로 넘침 브라우저 확인.
- 변경된 renderHub/renderDetail을 직접 호출해 초기 HTML 일치 확인. 관광지 전체 프리렌더를 반복할 필요 없음.

## 운영·게시 경계

- 부모가 실제 네이버 결과/공개 HTML/CSV를 근거로 기준선과 대표 URL 표본 점검을 기록한다. 접근 제한은 미확인으로 기록한다.
- 외부 커뮤니티·블로그 소개용 초안과 배포 후 측정 기록지를 준비한다. 외부 게시·연락은 이번에 실행하지 않는다.
- 배포는 구체적 변경과 검증 결과를 정리한 뒤 사용자에게 승인받는다. 앞선 배포 승인은 앞선 변경에 한정된다.
