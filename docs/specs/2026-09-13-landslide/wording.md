# 「사태」 화면 문구 기준 (2026-09-25)

사용자 소감: 「게임 전반적으로 한글화가 너무 어색하다. 영문을 의역하거나 억지로 한자어로 쓰는 것 자체가 한국말로 어색하다.」
화면 문구 340줄을 뽑아 본 결과 원인은 넷이었다 — **설계 문서 말투가 그대로 화면에 올라왔다.**

| 원인 | 예 (지금) |
|---|---|
| ① 개발·물리 용어 | 셀 · 선분 피해 · 착탄점 · 열원 · 시한탄 · 순 낙차 · 탄도 · 동기화 복구 — 로그 재생 · 넉백 |
| ② 굳은 한자어 | 직격 · 반경 · 광역 · 점사 · 곡사 · 절단 · 엄폐 · 무효 · 인접 · 격파 · 상한 · 방벽 · 사거리 |
| ③ 말끝이 섞임 | 「상대가 나갔다」(해라체·문서체) / 「방이 가득 찼습니다」(합쇼체) — 합쇼체로 통일 |
| ④ 설명이 규칙서 | 「사거리 1275셀 · 선분 피해 14 · 더 두껍게 벤다 (기 2)」 — 숫자와 기호가 문장보다 많다 |

## 규칙

1. **말끝은 합쇼체(「~습니다」) 하나로 — 존댓말.** 안내·알림·오류는 전부 「~합니다 / ~했습니다 / ~할 수 없습니다」 (2026-09-25 사용자 결정: 「합쇼체가 나을듯. 존댓말은 유지」). 버튼·칩·제목은 명사나 동사 원형 짧게(「시작」「다시 하기」「방 만들기」). 「~한다 / ~했다」 문서체와 「~해요」 해요체 모두 쓰지 않는다. 로비 오류 문구(로비 표준 §3)도 이미 합쇼체라 그대로 맞는다.
2. **플레이어가 쓰는 말로.** 사람이 게임하면서 입으로 하는 말을 쓴다. 물리·코드 용어는 화면에 올리지 않는다.
3. **숫자는 비교가 필요할 때만.** 병과 설명은 「무엇을 잘하나」 한 줄. 수치(피해·거리)는 조작법·도움말 표로 따로 — 거리 단위 「셀」은 화면에서 쓰지 않는다(「멀리/짧게」 또는 「화면 절반쯤」).
4. **한 문장에 한 가지.** 줄표(—)·가운뎃점(·)으로 세 가지를 잇지 않는다. 길면 두 문장.
5. **게임 용어는 한국 게이머가 이미 쓰는 것.** 템전·노템전·팀전·개인전·방장·관전·봇·턴·게이지·패스는 그대로 써도 된다(이미 입말이다). 직격·반경 같은 문서 한자어는 풀어 쓴다.
6. **참조작 이름을 쓰지 않는다**(PRD §2).
