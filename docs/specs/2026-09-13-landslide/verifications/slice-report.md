### 3.6 죽은 입력 감사 (8씬 × 14키 = 112칸, 실제 KeyboardEvent, `logs/dead-input-matrix.md`)

씬: 타이틀 · 도움말 · 플레이(내 차례) · 플레이(상대 차례 = 미리 조준) · 플레이(비행 중) · 플레이(매몰 상태) · 일시정지 · 결과. 키: Space Enter X ←→↑↓ Q E = − Esc M + 무배정 Z.
**죽은 칸 0 / 112.** 판정은 (씬 전환 | 상태 변화 | 효과음 호출 수) 셋 중 하나. 무배정·못 하는 때는 전부 거절음 + 흔들림. 이 감사가 실버그 하나를 잡았다: 결과 → Esc → 로비로 간 뒤 타이틀 배경을 그리는 클로저가 `G.st`(null) 를 읽어 TypeError 3건 — 고친 뒤 콘솔 0.

## 7. 미결 (사용자에게 묻는다)

1. **용암 원천이 굳는가** — PRD 표는 "3턴 뒤 굳어 현무암". 원천까지 굳으면 화산 맵 열원이 3턴 뒤 전부 사라진다. 슬라이스는 「흘러내린 용암·착탄 반경 안 용암만 굳는다」로 뒀다.
2. **착탄 흔들림(반경 56셀 문턱 −1)과 폭발 둔덕** — 재질표 밖 규칙 둘. 이것 없이는 화살로 산사태가 안 났다. PRD §4 에 넣을지.
3. **파내기 턴에 발사도 되는가** — 지금은 파내기가 그 턴의 행동 전부.
4. **매몰 빈도 손잡이 ①(스폰을 분석구 근처로)** 을 슬라이스에서 할지, 포수까지 기다릴지.
5. **기본 난이도** — 보통(±3°) 로 뒀다. 정밀(±1.5°)은 봇 직격률 25% 로 첫 판에 가혹하다.
6. **디자인 캔버스 주소** — `index.html` 의 `<!-- design: … -->` 에 디자인 시스템 프로젝트 id 로 URL 을 적었다. 실제 공유 주소가 다르면 한 줄 교체.
7. **랭킹 🏆 버튼(우하단)과 발사 버튼 겹침** — 통합 세션이 `lib/platform.js` 를 붙일 때 확인.
8. **관전 카메라** — 상대 턴에 탄도를 따라가게 했다(PRD §13 미결정 항목). 내 유닛에 머무는 쪽이 낫다면 한 줄.
