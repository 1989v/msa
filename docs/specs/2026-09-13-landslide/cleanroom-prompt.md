## 과제
턴제 포격 대전 — **흐르는 지형** 위에서 삼국~조선 무장이 순서대로 겨룬다. "쏘면 파이고, 파인 것은 흘러내리고, 뜨거우면
바람이 솟는다." 세계는 셀 격자(`Uint8Array`)이고 셀은 재질 하나를 갖는다. 규칙은 전부 재질표에서 파생한다.
벤치마크: 참조작 이름을 쓰지 않는다. 하한은 **PRD §3 의 수치표**(판 8~15분 · 맵 1600×900 셀 · 축척 1/20 · 실기 ≥45fps ·
정착 ≤1.5초 · 첫 판부터 어려운 봇)이고, 그래픽·연출의 하한은 **디자인 판 06·07·09 와 나란히 놓아 동급 이상**이다.

## ★ 벤치마크의 규모 — 품질과 따로 판정한다 (전역 가드레일 G6)

화면 축척 — 세 수치: **시야 폭 = 화면 짧은 변이 담는 월드 480셀(기본 줌)** · **주인공 1/20** · **주인공 36 CSS px(1280×720)**.
 줌 3단 = 시야 세로 240 / 480 / 900셀(최대 축소에서 맵 전모). 이 값은 참조작 실측이 아니라 **PRD §3 규격 + 디자인 판 06**
 에서 왔다 — 예외를 이름 불러 선언한다: 「참조작 열람 금지(IP)로 축척 실측을 대신한다. 이 예외가 사 주지 않는 것 —

플레이타임 — 한 판 8~15분(8인 30턴 안팎). 슬라이스 1v1 은 5~8분. 판 단위라 이어하기는 없고, 시드는 결과 화면에 「지도 #」로 보인다.

줄여야 할 이유가 생기면 **줄이기 전에 사용자에게 알린다.**
타겟 방향 — **가로 전용으로 선언한다.** 근거: 포격 궤적과 지형이 수평으로 길고(16:9 맵), 8인이 한 화면에 선다.
