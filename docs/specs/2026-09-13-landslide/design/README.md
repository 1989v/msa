# 사태(沙汰) — 아트 시안 브리프 (클로드 디자인용)

삼국시대~조선의 무장 여덟이 **흐르는 지형** 위에서 활·총통·검·창·방패로 겨루는 2D 턴제 포격 대전.
이 문서는 클로드 디자인이 **캐릭터 시트**를 그리기 위한 스펙이다. 캐릭터 아트는 코드가 아니라
여기서 나오고, 구현은 여기 저장된 그림을 그대로 가져다 쓴다.

**흐름** — 이 프로젝트(`사태 — 아트 시안`)를 디자인 시스템으로 고르고 아래 프롬프트를 붙여 넣는다 →
산출물을 `artboards/` 에 저장한다 → 코드 세션이 `artboards/` 를 읽어 게임에 넣는다.
`reference/` 는 세계·HUD 의 방향을 보여 주는 참고 화면이다 — **거기 그려진 먹 실루엣 캐릭터는
자리표시일 뿐이니 따라 그리지 않는다.**

---

## 붙여넣을 프롬프트 (1차 — 병과 다섯)

> 웹 턴제 포격 대전 게임 「사태(沙汰)」의 캐릭터 시트를 그려줘. 삼국시대~조선의 한반도 무장이고,
> 아트는 **귀여운 SD(2.2등신)** 다. 화면에서 캐릭터 높이가 화면 높이의 1/20(36px)이라
> **작게 그려도 병과 다섯이 실루엣만으로 갈려야** 한다 — 이것이 첫째 조건이다.
> 스타일·팔레트·병과 표·금지 조건은 README §1~§5 를 따르고, 아트보드 넷을 §6 의 파일명으로 저장해줘.
> `reference/` 의 화면은 세계와 HUD 의 방향만 참고하고, 거기 있는 먹 실루엣 캐릭터는 따라 그리지 마.

## 2차 프롬프트 (1차가 확정된 뒤 — 시대 스킨)

> 같은 스타일·팔레트·등신으로 궁수 하나를 §7 의 시대 스킨 넷으로 그려줘. 스킨은 **투구와 갑옷 윤곽만**
> 바꾼다 — 활·포즈·크기·팀 깃발은 1차와 같아야 한다(능력치 없는 외형 옵션이라 병과 실루엣이 흐려지면 안 된다).
> 300px 한 줄과 36px 한 줄로 `artboards/05-era-skins.html` 에 저장해줘. 36px 줄에서 넷이 모두 궁수로 읽혀야 한다.

## 1. 규격

| 항목 | 값 |
|---|---|
| 등신 | **2.2등신** — 큰 머리, 짧은 팔다리, 둥근 실루엣 |
| 인게임 크기 | 화면 높이의 **1/20** (1280×720 에서 36px, 폰 가로에서 약 20px) |
| 캐릭터 상자 | **200 × 300**, 발이 바닥선에 닿게. 무기는 상자를 넘어도 된다 |
| 팀 구분 | 등에 꽂은 깃발(배기) + 허리띠 **에만** 팀색. 갑옷·피부는 팀과 무관 |
| 형식 | 배경과 분리되는 벡터 도형 (SVG 로 내보내 게임에 넣는다). 아트보드마다 PNG 로 뽑을 수 있게 |

## 2. 스타일

- 얼굴은 점 눈 + 작은 입, 표정이 있다. 귀엽되 **무장**이다 — 아기 옷이 아니라 작은 장군.
- 외곽선은 굵고 부드러운 먹선 `#1D1D1F`. 채색은 한지 위 담채 — 평면 색면 2~3톤, 가는 결 질감 살짝.
  그림자·그라데이션·광택 없음. 깊이는 색 단차로만.
- 갑옷·투구는 실제 한국 무구를 **단순화**한다: 찰갑(비늘 갑옷)은 가로 줄 3~4개, 투구는 윤곽 하나.
  실물 유물을 보고 단순화하되 사실적 세부(징·문양 다수)는 넣지 않는다.
- 무기는 몸보다 **과장해서 크게** — 활은 키만큼, 총통은 몸통보다 굵게, 창은 키의 1.5배.
  축소했을 때 무기가 실루엣을 정한다.

## 3. 팔레트 (hex 고정 — 근사하지 말 것)

| 축 | hex | 쓰는 곳 |
|---|---|---|
| 한지 | `#F9F8F2` | 바탕 · 밝은 면 |
| 기와 | `#1D1D1F` | 외곽선 · 먹 |
| 황토 | `#B38B6D` | 갑옷 · 가죽 · 나무 (명도 2~3단으로 나눈다) |
| 연지 | `#A2231D` | **홍팀** 깃발·띠 |
| 청자 | `#2B4B63` | **청팀** 깃발·띠 |
| 소나무 | `#1A472A` | 장식 한 점 |
| 피부 | 따뜻한 밝은 톤 한 가지 | 얼굴·손 |

새 색을 지어내지 않는다. 갑옷은 황토·기와 계열만.

## 4. 병과 다섯 — 시그니처 포즈 하나씩

| 병과 | 무기 | 실루엣의 핵심 | 시그니처 포즈 | 게임 안 역할 |
|---|---|---|---|---|
| 궁수 | 각궁 + 등의 전통(화살통) | 키만 한 활의 **곡선** | 활을 당겨 조준 — 옆모습 | 기류를 읽는 정밀 사격 |
| 포수 | 총통(대형 화포)을 포가에 얹음 + 손에 화승 막대 | 몸통보다 굵은 **포신의 사선** | 포신 옆에서 화승을 대는 순간 | 지형을 무너뜨린다 |
| 검사 | 환도 | 머리 위로 올린 **검의 사선** | 내려치기 직전, 두 손 | 검기로 지형을 자른다 |
| 창병 | 장창 | 키의 1.5배 **수직선** | 앞으로 찌르기, 한 발 내딛음 | 지형을 뚫는다 |
| 방패병 | 장방패(長防牌, 네모) + 허리의 환도 | 몸 절반을 가리는 **네모 한 덩어리** | 방패를 비스듬히 들어 막기 | 막고, 적을 던진다 |

병과 이름을 캐릭터 밑에 붓글씨 느낌 명조로 적는다 (궁수 · 포수 · 검사 · 창병 · 방패병).
1차는 다섯을 **조선 갑사 복식** 으로 통일하고 홍팀 깃발을 단다.
**확정본(2026-09-13, 2차)**: 머리는 병과별 — 궁수 갓(흑립) · 검사 투구(드림) · 포수/창병/방패병 전립(상모+공작 깃). 방패는 장방패. `artboards/characters.js` 가 원본이다.

## 5. 하지 말 것

- 특정 상용 게임의 캐릭터 인상 — 특히 **동물·벌레형 소대**나 **전차·탱크형** 유닛. 사람 무장만.
- 이모지·스티커 광택, 드롭 섀도, 3D 렌더 느낌, 그라데이션 배경.
- 캐릭터 시트에 UI 요소(카드·비대칭 모서리·버튼)를 섞기. 캐릭터와 이름만.
- 실루엣을 흐리는 장식.
- `reference/` 의 먹 실루엣을 따라 그리기 — 그것은 자리표시다.

## 8. 3차 — 세계·HUD (캐릭터가 확정된 뒤)

캐릭터 결(굵은 먹선 · 평면 2~3톤 · 둥근 실루엣 · 밝고 귀여움)에 **세계와 HUD 를 맞춘다.** `reference/` 의 수묵담채는 방향이 바뀌어 **버린다** — 배치와 정보만 참고한다.

### 붙여넣을 프롬프트 (3차)

> 「사태」의 세계와 HUD 를 characters.js 의 캐릭터와 같은 결로 그려줘 — 굵은 먹선, 평면 2~3톤, 둥글둥글하고 밝고 귀여운 대중적 인상.
> 지형은 재질표(README §8.1)의 색을 쓰고, 가루 재질은 점 알갱이·고체는 덩어리·액체는 물결로 질감을 갈라줘.
> 유닛은 새로 그리지 말고 characters.js 의 render() 로 화면에 세워줘(높이 36px, 8명, 홍·청, 스킨 섞어서).
> HUD 는 §8.2 의 토큰·부품 목록을 따르되 모서리와 글꼴을 캐릭터처럼 둥글고 친근하게. 산출물은 §8.3 의 파일명으로.

### 8.1 재질표 → 색 (hex 고정)

| 재질 | hex | 질감 |
|---|---|---|
| 현무암·바위 | `#1D1D1F` | 덩어리, 먹선 |
| 흙 | `#8A6A50` | 덩어리 |
| 화산재 | `#4A4A4C` 위에 `#5C5C5E` 점 | **가루 — 점 알갱이** |
| 모래 | `#D9C39B` 위에 `#C9AE7E` 점 | 가루 |
| 눈 | `#F9F8F2` 위에 `#E4E2DA` 점 | 가루 |
| 용암 | `#E0562A` → `#A2231D` | 액체 — 물결, 은은한 빛 |
| 물 | `#2B4B63` 위 `#9FBFD3` 물결 | 액체 |
| 얼음 | `#9FBFD3` → `#2B4B63` | 덩어리, 하이라이트 한 줄 |
| 하늘 | 파스텔 — 한지 `#F9F8F2` 에서 밝은 청자 `#CFE0EA` 로 | 둥근 구름 몇 점 |
| 소나무 | `#1A472A` | 둥근 덩어리 셋 겹침 |

기류는 **항상 보이게** — 밝은 청자 `#9FBFD3` 유선(굵기 2, 둥근 끝) + 용암 위로는 연지 상승 유선.

### 8.2 HUD — 아케이드 토큰 (사이트 규칙, hex 고정)

판 `#1D1D1F` 반투명 92% · 구조·라벨 황토 `#B38B6D` · 액션 연지 `#A2231D` · 글 한지 `#F9F8F2` · 숫자는 모노. 터치 44px. 모서리는 둥글게(8px) — 캐릭터 결과 맞춘다.

| 부품 | 내용 |
|---|---|
| 턴 순서 띠 (좌상) | 좌석 8 칩(팀색) + 현재 좌석 강조 + 남은 초 |
| 바람 (상단 중앙) | 방향 화살표 + 세기 숫자 + 「용암 위 상승」 같은 기류 메모 |
| 뭉친 기 게이지 (우상) | `기(氣) 18/30` 바 |
| 내 무장 (좌하) | 병과 · 스킨 이름 · 체력 바 · 에너지 6칸 |
| 무기 칩 (하단 중앙) | 기본 + 에너지 무기 3~4, 비용 숫자, 선택은 연지 채움 |
| 조준·이동 (우하) | `52.0° · 640` · 이동 게이지 · [파내기] [발사] |
| 줌 (좌측 중앙) | + / 단계 / − 세로 |
