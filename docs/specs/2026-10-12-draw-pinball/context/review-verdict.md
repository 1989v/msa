## Implementation adjudication

**Verdict: REVISE.** Both findings in `implementation-review.md` are retained within the approved SR-2/SR-3 and accessibility scope. Source was inspected; no tests or computer use were performed.

| Finding | Decision | Concrete evidence and disposition |
|---|---|---|
| Major — native controls collide with global shortcuts | **KEEP — Major** | `main.js:101–107` exempts only INPUT/TEXTAREA/editable targets; `SWALLOW` at `:68` prevents Tab and Space. Enter maps to `fill` (`:61`) and result handling at `:166` launches a new race after the initial 0.4 seconds. New native participant/result buttons are therefore affected by game shortcuts: Enter can change phase/seed instead of activating the intended control, Space cannot activate natively, and Tab cannot move focus. `copy.onclick` reads `Game.resultText()` (`:27–29`), which returns empty outside done phase (`game.js:233–234`); the review's empty-copy race is source-plausible but browser event ordering has not been verified. The keyboard/state collision alone warrants Major. Allow Tab and bypass shortcuts for native interactive targets and descendants, then check participant activation and completed-result copy preserve phase/seed. |
| Minor — selected participant offscreen guidance | **KEEP — Minor** | `drawWorld` uses `cam.band(80)` (`main.js:290`) for both drawing and status; its status checks only y (`:310–314`) and selects the first owned live marble. `Camera.band` adds 80 world units to the true vertical half-height, while `Camera.apply` transforms both x and y using viewport size/zoom. Thus x-invisible or vertically outside marbles can be announced as “화면 안에서 강조 중”. SR-2 explicitly requires guidance for offscreen selected participants. Use actual unpadded viewport bounds in both axes, directional/minimap guidance, and a consistent visible-member policy when an owner has multiple marbles. |

No downgrade or rejection is justified. These are corrections to approved behavior, not a scope expansion. Final verification remains the implementation worker's responsibility; this adjudication does not claim the scenarios were executed.
