# Specification: 랜덤레이스와 핀볼 관전 개선

## Goal
사용자가 승인한 우선순위(후반 경합/슬로모션 → 위험 무리 카메라/이름 → 랜덤레이스 페이지/명단 유지 → 코스 차별화)를 구현한다. 친구 초대는 기존 서버의 난수 방 코드를 짧은 공유 URL과 직접 입력에 재사용한다.

## User Stories
- 한 기기로 모인 사람들은 이름과 게임만 정하고 바로 추첨한다.
- 꼴찌를 피하려는 관전자는 마지막까지 위험한 사람들과 역전을 알아볼 수 있다.
- 친구는 짧은 링크를 열거나 6자리 코드를 입력해 지정된 방에 들어간다.

## Specific Requirements
### SR-1 후반 연출
- 기본 꼴찌 모드의 자동 슬로모션은 마지막 2~3개가 실제로 경합하는 결승 입구 앞 구간에서 동작한다. 단독으로 남은 구슬의 이동을 느리게 늘이지 않는다.
- 입구 진입/튕김 같은 경쟁 구간에서만 짧게 느려지고 경쟁이 해소되면 정상 속도로 복귀한다. 발동 조건과 최대 지속 시간은 코드 상수로 명확히 둔다.
- 1등/지정 등수는 목표 등수 경계의 경쟁을 보여준다. 전체 순서 모드는 마지막 순서 경합을 보여준다.
- 미완주한 물리 구슬이 정확히 하나인 경우에만 마지막 순위를 확정한다. 그 구슬을 마지막 order에 추가하고 rank/done을 일관되게 갱신한다. 동일 소유자의 구슬 둘이 남았어도 종료하지 않는다. 이 판정은 일반 step과 fastForward의 공통 고정 스텝 완료 경로에서 수행한다.
- 물리 엔진의 고정 스텝/시드/동일 구슬 조건을 유지한다. 연출 설정/카메라 선택으로 결과가 바뀌지 않는다.

### SR-2 관심 대상
- 꼴찌 모드 카메라는 위험한 뒤쪽 무리, 1등 모드는 선두, 지정 등수는 목표 경계에 주목한다.
- 이름 표시도 관심 무리와 일치한다. 마지막 경합 2~3개의 이름을 보인다.
- 참가자를 선택해 구슬/이름을 강조하는 터치 가능한 제어를 제공한다. 선택은 결과에 영향을 주지 않는다.
- 미니맵은 유지하고 화면 밖 선택 참가자의 위치를 알아볼 수 있게 안내한다.

### SR-3 랜덤레이스
- `/draw`와 `/en/draw`는 릴레이 방 생성/입장 및 이름 동기화 없이 이름, 방식(last/order), 게임(구슬/사다리/카드/무작위)을 정해 시작하는 독립 페이지다. 게임 카탈로그 API 요청은 허용한다.
- 기존 랜덤 순서 뽑기 모달 진입을 이 페이지로 통일한다. 일반 게임 랜덤 선택 버튼과 혼동하지 않는다.
- 기존 카탈로그와 party handoff 규약(v1)을 재사용한다. 지원 가능한 게임만 노출한다.
- 최근 명단/방식/선택 게임을 로컬에 유지한다. 이름은 URL에 담지 않는다.
- 로딩/목록 실패/빈 목록/2명 미만 상태에서 잘못 시작하지 않는다. 재시도/수정이 가능하다.
- handoff 저장이 실패하면 입력을 유지하고 오류를 보여주며 게임으로 이동하지 않는다. 최근 설정 저장만 실패하면 현재 입력을 유지하고 기기 저장 불가를 안내한다. v1 payload 확장/이름 URL fallback은 하지 않는다.
- 친구 초대는 별도 `/party`로 안내하며, `/draw`에는 코드 입장도 제공한다.
- 구슬 레이스 결과를 텍스트로 복사하고 동일 참가자로 새 판을 시작할 수 있다. 실패한 복사는 성공으로 안내하지 않는다.

### SR-4 짧은 초대
- 공유 URL은 현재 게임 오리진의 `/?r=ABC234` 형식을 사용한다. 기존 `/party/:room`, `/en/party/:room` 링크도 동작한다.
- 게임 호스트 루트에서 r 파라미터가 존재하면 초대 입장으로 해석한다. 다른 제품 호스트의 루트 동작을 바꾸지 않는다. 개발 localhost에서도 검증할 수 있다.
- 공유 코드와 수동 입력은 기존 서버의 6자리 문자 집합 `ABCDEFGHJKLMNPQRSTUVWXYZ23456789`를 기준으로 검증한다. 소문자/앞뒤 공백/표시용 하이픈은 정규화한다. 전체 초대 링크 붙여넣기도 지원한다.
- 빈/잘못된/중복 r 파라미터는 명확한 오류/수정 화면으로 간다. 방장 화면으로 전환하거나 방을 생성하지 않는다. 존재하지 않거나 종료된 방은 기존 릴레이 오류를 보여준다.
- 잘못된 입장 후 코드 수정은 새 입장 시도를 가능하게 한다. 기존 PartyPage의 mounted opened ref에 걸려 재시도가 무시되지 않는다.
- 파티 화면에서 링크 복사와 가능한 환경의 Web Share를 제공한다. 사용자의 공유 취소를 실패 경고로 처리하지 않는다. 복사/공유 버튼은 실제 사용자 클릭에서만 동작한다.
- 6자리 서버 난수/충돌 검사/private join/rate limit를 재사용한다. 새로운 단축 URL 서비스, DB, 인증 방식, 방 발급 규약 변경은 하지 않는다. 난수는 우연한 입장/추측을 줄이는 것이며 접근 권한 보장으로 표현하지 않는다.

### SR-5 코스 차별화
- 기존 조각을 재사용해 핀볼(입구 튕김), 폭포(갈림/합류 흐름), 회전목마(회전체 경합)의 후반 경험을 구분한다.
- 처음부터 전 맵을 재작성하지 않는다. 마지막 입구 전후의 작은 범위를 개선하고 통과/미완주/출발자리 편향을 검증한다.
- 기존 정적 코스 선택에는 간결한 미리보기/성격 설명을 제공한다. 새로운 외부 이미지/라이브러리를 도입하지 않는다.

## Visual Design
root DESIGN.md 및 docs/standards/design-md.md를 적용한다. CSS는 기존 아케이드 토큰을 재사용하고 새 hex literal을 추가하지 않는다. 모바일 터치 최소 44px, 입력 라벨, 포커스, reduced-motion을 지킨다.

## Out of Scope
맵 제작/공유, 새 인증/단축링크 서버, 서버 방코드 변경, 자동 배포/게시, 이번 작업과 무관한 게임/분석 변경. 기존 여러 명 지목/가중치 규약의 의미를 재설계하지 않는다. 관련 결함은 별도 열린 질문으로 보고한다.

## Open Questions
구현 차단 질문 없음. 실제 브라우저/스크린샷 검증은 별도 명시적 UI 승인 없이는 실행하지 않는다.
