# Requirements

사용자 승인: 벤치마크의 네 우선순위를 순서대로 진행. 친구 공유 링크는 짧고 직접 입력하기 쉬우며 난수화되어야 한다. 공유 파라미터 형태 허용.

구현 정본: ../spec.md. 명확한 요청과 기존 구현에 근거하여 반복 인터뷰는 생략한다.

기존 재사용: 6자리 SecureRandom 방코드와 private relay, v1 handoff, 고정 스텝 시뮬, 카탈로그, 호스트별 라우팅. 로컬 추첨은 방을 생성하지 않는다. 잘못된 링크는 방장으로 폴백하지 않는다.

범위 밖: 맵 제작/공유, 별도 단축 URL 서비스, 서버 규약 변경, 배포. 실패는 수정/재시도 가능한 UI로 안내한다. 검증은 명시적 결과와 시뮬 재현/완주로 관측한다.
