# 플랫폼 링크 노출 영역

상태: 컴포넌트/CSS 구현 반영, CLI·컴포넌트 검증 통과. 실제 브라우저 화면은 미검증이다. 기존 화면과 root DESIGN.md 및 현재 게임 화면의 `--ko-*` 의미 토큰을 따른다. 새 브랜드색·대형 홍보 배너·추가 애니메이션을 도입하지 않는다.

## 게임 목록 카드

카드 본문의 제목/장르 다음 정보 영역에 작은 `Roblox ↗` 텍스트 배지를 둔다. `availablePlatforms`에 Roblox가 있을 때만 표시한다. 웹게임의 기존 BETA 표시는 웹판 상태이고 이 배지는 플랫폼 제공 여부다.

카드 전체가 이미 상세 페이지로 가는 Link이므로 외부 링크를 안에 중첩하지 않는다. 배지는 비상호작용 텍스트이며, 카드 클릭은 계속 웹게임 상세로 이동한다. 홈 컬렉션·전체 목록·유사 게임은 공통 GameCard로 같은 표시를 사용한다. 추가 플랫폼이 생기면 같은 영역에 일관된 짧은 배지를 추가한다.

```text
┌─────────────────────────────┐
│          게임 썸네일          │
├─────────────────────────────┤
│ 인피니티 스탭        액션      │
│ Roblox ↗                    │
│ 평점 · 플레이 수             │
└─────────────────────────────┘
          카드 → 웹게임 상세
```

## 게임 상세 — 주요 노출

현재 썸네일 위 웹 플레이 버튼을 유지한다. 썸네일 바깥 아래, 장르/인원/시간 정보 위에 보조 링크 영역을 넣는다. 링크가 없는 게임은 영역 전체를 렌더하지 않아 빈 공간도 없다. 웹게임 실행 중에는 이 영역을 감춰 몰입 화면에 끼어들지 않는다.

```text
┌─────────────────────────────────┐
│            스크린샷              │
│          [ ▶ 플레이 ]            │ ← 현재 웹 플레이
└─────────────────────────────────┘
  [ 로블록스 버전으로 즐기기 ↗ ] 베타 ← 새 탭 외부 링크
  Roblox 계정과 앱이 필요할 수 있어요.
  장르 · 인원 · 예상 시간 · 모바일
```

- KO: `로블록스 버전으로 즐기기`, EN: `Play the Roblox version`.
- BETA일 때만 링크 옆 `베타` / `Beta` 상태 표시. 웹판의 상태와 독립이다.
- 보조 문구 KO: `새 탭에서 열려요. Roblox 계정과 앱이 필요할 수 있어요.` EN: `Opens in a new tab. A Roblox account and app may be required.`
- 실제 `<a href>`를 사용하고 `target="_blank" rel="noopener noreferrer"`를 적용한다. 링크와 아이콘의 접근성 이름/설명으로 새 탭을 알린다. 아이콘만 클릭하게 하지 않는다.
- 데스크톱은 썸네일 너비 안에서 가운데 정렬한 보조 윤곽 링크, 모바일은 가로 전체 너비와 최소44px 터치 높이를 확보한다. 텍스트 줄바꿈을 허용하며 기존 KO/EN 글꼴·명암·포커스 스타일을 사용한다.
- 링크 클릭은 `handlePlay`를 호출하지 않으며 iframe/세션/전체화면을 시작하지 않는다. 웹/Roblox 간 저장 공유를 암시하는 문구를 넣지 않는다.

## 관리 화면

게임 편집 화면의 별도 `플랫폼 버전` 구역에 플랫폼·게임 주소/Place ID·출시 상태·접근 범위를 둔다. 기본은 `초안 / 초대 전용`이다. 정규 게임 주소 미리보기와 `일반 방문자에게 표시됨/표시되지 않음`을 함께 보여 준다. 공개 페이지에는 이 관리 상태를 노출하지 않는다.

## 인피니티 스탭 적용 조건

지금은 게시된 Roblox 게임 주소가 확인되지 않았으므로 실제 링크를 표시할 수 없다. 공개 플레이 가능한 주소를 등록한 뒤 위 영역을 노출한다. 본인 인증용 주소나 업로드 대시보드 주소는 여기에 사용할 수 없다.
