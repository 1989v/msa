# 결정

### 2026-11-10 통합 저장
- 부모 세션에서 사용자가 승인한 UI 범위만 구현한다. 기존 API는 별도 요청이며 원자적 저장을 보장하지 않는다.
- 성공한 항목별 입력 기준선을 갱신하여 재시도에서 중복 저장하지 않는다. 실제 공개 상태는 성공한 서버 응답을 사용한다.
- 컬렉션은 독립 편집/저장을 유지하고 게임 통합 저장 폼 밖에 둔다.

### 2026-11-10 독립 검토 수정
- 플랫폼 PUT 전후 정확한 조회 키를 취소하여 오래된 GET 응답이 저장 스냅샷을 덮지 못하게 한다.
- Escape 처리는 열린 Dialog에만 document listener를 달고 정리한다. 최상단 Dialog만 처리하며 기본 동작을 이미 막은 이벤트는 존중한다.
