# 승천 (ascent) — PRD

- 일자: 2026-09-02
- 형태: 유니티 WebGL · **공용 프레임워크 `com.kgd.webgame`** 위에 짓는 두 번째 게임
- 상태: **PRD** — 설계·구현 전. 이 문서는 무엇을·왜·어디까지를 정한다

## 0. 한 줄 정의

**떨어지면 올라온 만큼 잃는 탑을, 점프 하나로 우주까지 오르는 게임.**
세이브도 체크포인트도 없다. 실수의 값이 곧 긴장이고, 그것이 이 장르(Jump King · Only Up! ·
Getting Over It)의 정체성이다.

## 1. 왜 지금인가

| 근거 | 내용 |
|---|---|
| 프레임워크 검증 | 아홉 종에서 뽑은 패키지(이동·등반·활공·카메라·지형·타격감·소리·챕터 번들)가 **다른 게임에서도 서는지**를 가장 싸게 확인하는 종목 — 전투가 없어 패키지의 이동·지형 축만 쓴다 |
| 플랫폼 재방문 | 랭킹(고도)이 곧 콘텐츠다. 아홉 종은 끝이 있지만 이 게임은 **끝 뒤가 랭킹**이라 `rank.1989v.com` 과 붙는다 |
| 제작 비용 | 적·무기·보스가 없다. 콘텐츠는 **지형 생성 규칙**이고, 그것은 이미 `KgdPlateau`/`KgdScatter` 가 갖고 있다 |

## 2. 벤치마크 하한 — 이 숫자를 못 넘으면 완성이 아니다

기준작 Jump King(2019) · Only Up!(2023). **전 축에서 동급 이상**이 완성 판정이다.

| 축 | 기준작 | 하한 | 잰다 |
|---|---|---|---|
| 정상까지 높이 | Jump King 약 43 화면(≈ 600 유닛 상당) | **우주 도달 3,000 유닛** + 그 위 무한 | `HeightGate` — 생성 규칙이 3,000 까지 끊김 없이 이어지나 |
| 완주 시간 (숙련) | Jump King 세계기록 4분대, 일반 10~20시간 | **첫 완주 6~12시간**, 숙련 25분 | 봇 완주 + 낙하 통계 |
| 구간(바이옴) 수 | Jump King 3 + DLC | **7** (지상·숲·폐허·구름·설산·성층권·우주) | 챕터 번들 7개 (ADR-0085) |
| 낙하 손실 | 최대 전체 | **최대 2구간 분량** — 무한 구간에서는 마지막 도달 구간 입구까지 | `FallGate` — 어느 지점에서 떨어져도 착지 지점이 규칙 안 |
| 점프 종류 | Jump King 1 (차지) | **차지 점프 1 + 벽 매달림 + 모서리 잡기** — 활공은 **없다** (장르를 부순다) | 이동 게이트 |
| 조작 | 키보드 | **모바일 1순위** — 스틱 + 버튼 2 (차지·잡기) | 세로/가로 CDP 실측 |
| 화면 크기 | — | 캐릭터 53 CSS px (아홉 종과 같음) | 스크린샷 측정 |

**첫 판부터 어렵다.** 튜토리얼 구간 없음 — 지상 첫 세 점프에서 이미 떨어질 수 있다.

## 3. 플레이어 경험

### 코어 루프 (한 사이클 8~40초)

```
발판을 본다 → 힘을 잰다(차지) → 뛴다 → (붙는다 | 떨어진다) → 다음 발판을 본다
```

- **차지 점프**: 누르는 시간이 힘이다. 짧으면 앞으로 조금, 길면 높이 멀리. 최대 1.2초.
  공중에서 방향을 바꿀 수 없다 — 뛰기 전에 다 정한다.
- **벽 매달림**: 벽에 닿으면 붙는다(아홉 종의 등반을 그대로). 스태미나가 있어 무한히 못 붙어 있다.
- **모서리 잡기**: 발판 가장자리에 손이 닿으면 끌어올린다 — 「아깝게」를 「간신히」로 바꾼다.
- **떨어짐**: 아래 발판 위로 착지할 때까지 떨어진다. 세이브 없음. 재시작 없음(탑은 하나뿐).

### 진행 구조

| 구간 | 높이 | 새로 생기는 것 |
|---|---|---|
| 지상 | 0~200 | 차지 점프만 |
| 숲 | 200~600 | 나뭇가지 = 좁은 발판, 바람(수평 힘) |
| 폐허 | 600~1,100 | 부서지는 발판(`KgdBreakables` — 밟으면 무너진다), 벽 매달림 |
| 구름 | 1,100~1,700 | 움직이는 발판, 보이지 않는 가장자리(안개) |
| 설산 | 1,700~2,300 | 미끄러지는 발판, 모서리 잡기 필수 |
| 성층권 | 2,300~3,000 | 발판 간격 최대, 중력 90% |
| 우주 | 3,000~ | **끝** — 여기서 랭킹 등록. 그 위는 무한 절차 생성 (중력 80%, 손실 규칙 완화) |

### 재방문 동기

- 랭킹은 **최고 고도**와 **완주 시간** 두 축 (`rank.1989v.com`, `KgdPlatform` 랭킹 제출)
- 시드는 **날짜**로 정한다 — 같은 날은 모두 같은 탑. 일일 랭킹이 생긴다(`lib/daily.js` 가 이미 있다)
- 세이브는 **고도·시드·낙하 횟수**뿐. 탭을 닫아도 그 자리에서 이어진다(이어지지 않으면 10시간짜리 게임이 안 된다)

## 4. 프레임워크에서 가져오는 것 / 새로 만드는 것

| 필요 | 있는가 | 비고 |
|---|---|---|
| 이동·점프·낙하·착지 | `KgdTraverse` | 활공을 **끈다**(튜닝 `GlideSpeed = 0` 이 아니라 상태 진입 자체를 막는 플래그가 필요) |
| 차지 점프 | **없음** | `KgdTraverse.Wish.JumpCharge(0~1)` — 패키지에 넣는다. 아홉 종은 안 쓴다 |
| 벽 매달림 · 등반 | `KgdTraverse.Climb` + `KgdLimbs.Climb` | 그대로 |
| 모서리 잡기 | **없음** | `KgdTraverse` 에 `LedgeGrab` 상태 추가 — 패키지 |
| 발판·지형 | `KgdPlateau`(고지대) · `KgdObstacles`(기둥) | 발판은 작은 고지대다. 탑은 고지대를 **세로로 쌓은 것** |
| 부서지는 발판 | `KgdBreakables` | 「맞으면」이 아니라 「밟으면」 — 트리거만 다르다 |
| 움직이는 발판 | **없음** | `KgdMover` — 왕복·회전 경로. 패키지 |
| 카메라 | `KgdOrbitCam` | 위를 자주 보므로 기본 피치를 올린다 |
| 하늘 | `KgdSky` | 구간마다 색·구름을 바꾼다 — 고도가 하늘로 읽힌다 |
| 구간 번들 | `KgdChapters` (ADR-0085) | 7 번들. 다음 구간을 미리 받는다 |
| 소리 | `KgdTone` | 낙하 시작음·착지음·차지음 |
| 타격감 | `KgdImpact` | 착지 흔들림에 재사용 |
| 랭킹·세이브 | `KgdPlatform` · `KgdSave` | 그대로 |
| 조작 | `KgdInput` | 버튼 2 (차지 = 액션1 길게, 잡기 = 액션2) |

**패키지에 새로 올라가는 것 3**: 차지 점프 · 모서리 잡기 · 움직이는 발판. 셋 다 아홉 종에도
쓸 수 있는 것이라(모서리 잡기는 특히) 아홉 종에서 먼저 켜 보고 올린다.

## 5. 범위

### 들어가는 것
- 7 구간 절차 생성 + 우주 위 무한 생성
- 차지 점프 · 벽 매달림 · 모서리 잡기
- 낙하 손실 규칙 + 손실을 **보여 주는** 연출(떨어지는 동안 지나온 구간이 스쳐 간다)
- 일일 시드 · 고도/시간 랭킹 · 이어하기
- 모바일 세로/가로

### 안 들어가는 것 (이유)
- 적·전투 — 장르 밖. 긴장은 낙하가 만든다
- 활공·이단 점프 — 낙하의 값을 없앤다
- 체크포인트 — 같은 이유. 「이어하기」는 종료 시점 저장이지 되돌림이 아니다
- 멀티플레이 — 남의 유령(고스트)은 후속 후보

## 6. 예산 · 제약 (`unity-game-pipeline.md` §6 상속)

| 항목 | 상한 |
|---|---|
| 총 전송량 | ≤ 15MB (아홉 종 7.2MB. 구간 번들은 각 ≤ 0.3MB) |
| 첫 화면 | ≤ 5초 |
| 모바일 fps | ≥ 45 |
| 화면 삼각형 | ≤ 25k (아홉 종 20.5k) — 탑은 세로라 **컬링이 쉽다**: 현재 고도 ±2 구간만 그린다 |
| 서버 | 랭킹 제출·세이브 외 **실시간 통신 없음** |

## 7. 완성 판정 — 게이트

| 게이트 | 잰다 |
|---|---|
| `HeightGate` | 시드 20개 × 3,000 유닛까지 **도달 불가 지점 0** (점프 최대 사거리로 다음 발판이 닿는가) |
| `FallGate` | 임의 지점 200곳에서 떨어뜨려 착지 지점이 손실 규칙(≤ 2구간) 안 |
| `PaceGate` | 봇(완벽 조작)이 25분 안에 완주 · 낙하 50% 봇이 6~12시간 |
| 이동 게이트 | 차지 점프 사거리 표 · 벽 매달림 스태미나 · 모서리 잡기 발동 폭 |
| 실기 | 세로/가로 CDP 4조합 + 폰 발열 10분 |

**게이트는 회귀를 주입해 빨간불을 본 뒤에만 켰다고 한다.**

## 8. 위험

| 위험 | 대응 |
|---|---|
| 절차 생성이 「못 오르는 탑」을 만든다 | `HeightGate` 가 시드 20개를 돌린다. 생성은 **보장 경로 먼저**(기법 카탈로그 G3), 장식은 나중 |
| 모바일에서 차지 점프의 정밀도 | 차지 게이지를 크게, 힘을 5단으로 양자화 — 연속값은 손가락으로 못 잰다 |
| 10시간짜리 게임의 이탈 | 일일 시드·랭킹이 「오늘 어디까지」를 만든다. 이어하기는 필수 |
| 활공 없는 `KgdTraverse` 가 어색 | 플래그로 막되 패키지 기본값은 아홉 종 그대로 |

## 9. 미결정 (설계 단계에서 정한다)

- 낙하 손실 규칙의 정확한 숫자 — 「최대 2구간」은 하한이고, 구간별로 달리할지
- 우주 위 무한 구간의 생성 규칙이 랭킹 공정성을 해치지 않는지(시드 공유로 해결되나)
- 캐릭터 — 아홉 종 주인공 재사용인가, 이 게임의 것인가
