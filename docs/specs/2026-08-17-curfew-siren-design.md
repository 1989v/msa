# 통금 사이렌 — 설계 문서

> slug `curfew-siren` · 순수 정적 웹(HTML + ES 모듈 + Canvas 2D) · 빌드 스텝 없음 · 런타임 외부 요청 0

---

## 0. 한 줄 정의

**해 지기 전엔 쿼터뷰로 폐허를 뒤지고, 사이렌이 울리면 벨트스크롤로 밤을 뚫는다.**
낮과 밤은 카메라와 페이스만 다르고, 팔레트 · UI 문법 · 캐릭터 리그 · 사운드 문법 · 폰트는 하나다.

---

## 1. 좌표계와 스케일 (전부 "화면 높이 대비 %" 로 잰다)

가상 해상도 **2560 × 1440** 고정. 백버퍼는 `CSS 크기 × DPR` 을 1440p 로 상한.

| 항목 | 값 | 근거 |
|---|---|---|
| 주인공 키 (밤) | **206px = 화면 높이의 1/7** | 1/5 보다 크면 필드가 안 보인다 |
| 플레이 z 레인 깊이 | **864px = 화면 높이의 60%** | 55~65% 요구 |
| 레인 상단 y | 470 (원단 z=0) | 위 470px 은 파랄랙스 배경 |
| 원근 스케일 | 0.90 (원) ~ 1.08 (근) | 2D 룩 우선, 과장 억제 |
| 상호작용 소품 높이 | 주인공 키의 **48~94%** (상자 0.52 · 드럼통 0.58 · 노점 0.56 · 자판기 0.94 · 차 0.86) | 캐릭터 축소에 딸려 작아지지 않게 별도 상수 |
| 주인공 키 (낮) | **115px = 화면 높이의 1/12.5** | 방 구조가 한눈에 읽혀야 한다 |
| 아이소메트릭 타일 | 128 × 64 (2:1) | — |

좌표계: `x` = 좌우(월드) · `z` = **깊이를 화면 픽셀 그대로** 0..864 · `y` = 지면 위 높이.
**깊이를 화면 픽셀로 저장한 것이 핵심 결정이다.** 월드 좌표로 두면 원근 압축 때문에
"수치는 정상인데 화면에서는 안 움직이는" 깊이 이동 버그가 반드시 생긴다.

## 2. 이동 속도 — 응답성과 별개로 잡는다

| 항목 | 목표 | 구현값 | 실측 |
|---|---|---|---|
| 보행 · 화면 폭 횡단 | 3.5~4.5초 | 640 px/s × 클래스 계수 | **4.25초** (peak 602 px/s, 한서준 0.94) |
| 질주 · 화면 폭 횡단 | 1.5~2.0초 | 1463 px/s × 계수 | **1.86초** (peak 1375 px/s) |
| 깊이/좌우 비 (보행) | 60~75% | 0.675 | **67.4%** (406 / 602) |
| 깊이/좌우 비 (질주) | 60~75% | 0.675 | **67.5%** (928 / 1375) |

질주 배율은 `RUN_X`/`RUN_Z` 를 같은 비율로 정의해 **x·z 양쪽에 동시에** 걸린다.
대각선은 입력 벡터를 정규화한 뒤 각 축 상한을 곱하므로 z 만 과하게 깎이지 않는다.

## 3. 응답성 — "손이 빠른 게임"

**속도감 = 입력 반응의 빠름이지 보행 속도가 아니다.** 걸음은 묵직하게, 손은 즉각.

| 항목 | 목표 | 구현 | 실측 |
|---|---|---|---|
| 약공 입력 → 타격 판정 **(중립)** | ≤ 0.08초 | wind 0.070s | n=28 · 최소 74.3 · **p50 79.6** · p90 83.2ms ✓ |
| 약공 입력 → 타격 판정 **(체인 2~4단)** | ≤ 0.08초 | 직전 공격의 캔슬창 대기 포함 | n=16 · 최소 76.1 · **p50 93.7** · p90 218.3ms ✗ |
| 히트스톱 (약공) | 40~60ms | 48ms | 48ms |
| 히트스톱 (강공/필살) | 80~100ms | 90 / 100ms | 90 / 100ms |
| 대시 발동 | ≤ 2프레임 | 더블탭 즉시(startup 0.016s) | 1프레임 내 |
| 이동 → 공격 전이 | 미끄러짐 0프레임 | 지상만 halfLife 0.045s 감쇠, **vx·vz 동시** | 끊김 없음 |
| 공중 관성 | 100% 보존 | 공격 중 `brake()` 는 지상에서만 동작 | 점프 궤적 유지 |
| 강공 입력 → 판정 | — | wind 0.155s | 최소 159.3ms · p50 164.5ms |
| 다운 → 기상 | ≤ 1.2초 | 0.42 + 0.28 + 0.40 = **1.10초** | **1.106초** (연속 피격 시 그만큼 연장) |
| 연타 씹힘 | 0 | 시간 기반 버퍼(180ms) + 0스텝 프레임에서도 유지 | 없음 |

**루프**: 클램프된 가변 스텝. 프레임당 1~4 서브스텝, 서브스텝 ≤ 20ms, 프레임 상한 70ms.
렌더 프레임마다 반드시 1회 이상 시뮬한다. 히트스톱 중에도 0dt 스텝으로 입력/렌더는 계속 돈다.
`rAF` 재요청은 `try/finally` 로 보장하되 예외는 콘솔에 그대로 남긴다.

## 4. 판정 — 레인 폭과 함께 움직인다

아케이드 벨트스크롤은 z 판정이 관대한 게 정상이다. 레인을 864px 로 넓혔으므로
z 허용폭도 같이 올렸다.

| 항목 | 값 |
|---|---|
| z 허용폭 (약공 / 강공 / 보스) | 95 / 115 / 135 px (+ 대상 반경 30) |
| 세로(공중) 밴드 | 112px (공중 공격 150~160) — 저글 대상까지 닿는다 |
| 사거리 (약 / 강 / 공중) | 152 / 196 / 168 px × 클래스 계수 |
| 몸통 반경 | rx 44 · rz 30 |

캐릭터를 1/7 로 줄인 뒤 사거리를 스프라이트 비율로 재조정했고,
공중 저글용으로 세로 밴드를 넓힐 때 **지상 z 판정도 함께** 넓혔다.

## 5. 액터 충돌

- 살아있는 적도 스쳐 지나갈 수 있다. **하드 블로킹 없음** — 무게 비례 soft separation 만.
- 시체는 즉시 통과 가능 + 1.2초 후 페이드, 2.2초에 제거. **보스 시체는 제거하지 않는다** —
  제거하면 update 가 멈춰 세그먼트 전이가 기다리는 타이머가 얼어붙어 진행 불가가 된다.
- 전투 락 구간의 좌우 한계 = **화면 가시 영역의 양 끝** (`bounds = camX .. camX + 2560`).
  여유는 캐릭터 반폭(44px)뿐이라 보이는 바닥은 전부 걸어갈 수 있다.

## 6. 콤보 문법

- 약공 체인 **4단** (Lv2 이전 3단) — 각 단이 서로 다른 궤도(찌르기 / 훅 / 바디 / 상단 마무리).
- 강공 · 필살 · **점프**로 캔슬 가능. 점프 캔슬은 후경직에서 빠져나오는 수단이며,
  이게 없으면 "강공 한 번 지른 대가로 보스의 넘기 패턴이 회피 불가" 가 된다.
- **런처**(↑+강공) → 점프 → 공중 약공 ×2 → 공중 강공 마무리.
  - 런처 넉백은 **50** 으로 대폭 하향 (사거리 밖으로 밀면 저글이 끊긴다)
  - 저글 자석: 뜬 적을 공격자 앞 105px · 같은 깊이로 흡인
  - 저글 중 중력 0.46배, 피격마다 재상승(감쇠 0.85), 상승 상한 780, 최대 8히트
- 콤보 카운터 대형 표시, 10히트 이상에서 색·문구 변화. **실측 최대 54히트**.
- 잡기 → 던지기: 던진 적이 착지하면 주변 적을 쓰러뜨리고, **벽 충돌 시 추가 판정**(+22 피해).
- 처치 시 적이 튕겨 날아가며(vx 1100~1700, vy 620~980) 화면 밖으로.

## 7. 기술 체계 (셋 다 구현)

**① 모션 커맨드** — 캐릭터당 2~3종. 입력 당시 facing 을 히스토리에 함께 기록해
등을 돌린 순간 236 이 214 로 뒤집히는 오인식을 막는다.

| 캐릭터 | 커맨드 | 입력 |
|---|---|---|
| 한서준 | 파쇄 돌진 | ↓↘→ + 강공 |
| 한서준 | 승천 도끼 | →↓↘ + 약공 |
| 도유나 | 연격 질주 | ↓↘→ + 약공 |
| 도유나 | 비상 무릎 | →↓↘ + 강공 |
| 도유나 | 회전 낙하차기 | ↓↙← + 강공 |
| 최무길 | 아크 절단 | ↓↘→ + 강공 |
| 최무길 | 역류 점화 | ↓↙← + 강공 |
| 림 | 유도 전격 | ↓↘→ + 약공 |
| 림 | 반경 방전 | →↓↘ + 강공 |

**② 구매형 기술** — 거점 상점(교관 표진)에서 고철로 산다. 공통 5종 + 클래스 전용 4종.
산 기술은 **커맨드 입력 형태로** 붙는다 (예: 지진 강타 = ↓↓ + 강공).

**③ 레벨업 해금** — 4단 체인(Lv2) · 런처(Lv3) · 2번째 커맨드(Lv5) · 공중 강공(Lv7) ·
강화 필살(Lv9) · 3번째 커맨드(Lv12) · 합체 필살 강화(Lv15).
**성장 곡선은 8스테이지 전체로 배분했다.** 슬라이스(스테이지 1) 종료 시 Lv2~3.

## 8. 방어기 4종 — 성능이 아니라 "쓰는 방식" 이 다르다

| 클래스 | 방어기 | 유형 | 동작 | 자원 |
|---|---|---|---|---|
| 한서준 | **가드** | 지속형 | 누르는 동안 전방 피해 78% 차단. 게이지 소진 시 **브레이크**(1.0초 경직) | 가드 게이지 (초당 17 회복) |
| 도유나 | **패링** | 타이밍형 | 입력 후 **0.16초** 창. 성공 시 피해 0 + 상대 경직 0.9초 + 필살 게이지 +16 | 없음 (실패 시 0.34초 경직) |
| 최무길 | **쳐내기** | 특화형 | 0.30초 창. **투사체 무효 + 반사**(피해 1.6배). 근접엔 50% 경감만 | 없음 |
| 림 | **실드** | 자원 흡수형 | 흡수 게이지가 피해를 대신 받고, 흡수량의 절반이 필살 게이지로 | 실드 게이지 (초당 8 회복, 유지 시 9 소모) |

전용 키는 `Shift`(1인 배치1) / `I`(1인 배치2) / `,`(2P 모드 1P) / `T`(2P 모드 2P).
게이지는 플레이어 패널에 방어기 고유 색으로 시각화된다.

## 9. 보스 — 패턴 → 정답 → 예고 → 실패 시 결과

### 중간보스 「망치」 배덕수 (철거반 감독) · HP 1450 · 2페이즈

| 패턴 | 정답 대응 | 예고 — 형태 | 예고 — 색 | 예고 — 소리 | 예고 길이 | 실패 시 |
|---|---|---|---|---|---|---|
| 지면 횡소 | **점프로 넘어라** | 낮게 깔린 띠(가로 타원 + 수평 줄무늬), 레인 전체 | 앰버 | 낮게 깔린 저음 슬라이드 | 0.62초 | 26 피해 + 다운 |
| 해머 강타 | **안쪽으로 붙어라** | 도넛 — 안쪽 원 라임(안전) / 바깥 확장 링 크림슨 | 라임 + 크림슨 | 상승 트라이앵글 | 0.86초 | 34 피해 + 다운 |
| 철거 돌진 | **방어기로 받아라** | 전방 쐐기 + 진행 화살표, **레인 폭 전체(±520)** | 사이렌 레드 | 2음 경보 | 0.78초 | 30 피해 + 다운 |
| 난무 후 탈진 | **수축할 때 때려라** | 보스로 수축하는 고리 | 시안 | 하강 사인 | 1.05초 | 16 피해/0.3초 |

**2페이즈에서 해머 강타의 정답이 뒤집힌다** — 도넛이 반전되어 안쪽이 위험, 바깥이 안전.
예고 도형도 색이 뒤바뀌므로 "형태로 읽는" 훈련이 그대로 통한다.

### 정답이 실제로 성립하는지 — 3조건 검증

**① 정답 성립 창 ≥ 예고 시간**

점프: `v0 = 1760`, `g = 4200` → 정점 해석값 369px / **실측 361px**, 체공 **0.825초**.
높이 88px 이상에 머무는 시간 = 해석값 0.731초 / **실측 0.720초**.

| | 예고 | 정답 창(실측) | 비 |
|---|---|---|---|
| 1페이즈 | 0.620초 | 0.720초 | **1.16** ✓ |
| 2페이즈 | 0.521초 | 0.720초 | **1.38** ✓ |

**② 정답 직후 안전 시간** — 횡소 0.62초 / 강타 0.78초 / 돌진 0.70초 / 난무 1.55초(탈진, 피해 1.9배 증폭).

**③ 정답이 필요한 거리에서 발동** — 강타는 안전 반경(210)의 1.24배 밖에서만, 돌진은 380px 밖에서만 선택된다.
**붙어 싸우는 상대에게 거리 패턴이 영영 안 나오는 문제**는 보스가 스스로 거리를 만드는
**백스텝**(700px, 0.42초, 짧은 무적, 2.6초 쿨다운)으로 해결했다.

**비공격(안전) 프레임 비율**: 한 사이클 12.9초 중 실제 피해 판정이 열리는 시간 2.71초 → **79% 안전**.

**소환/장판 등 상시 피해원 동시 상한**: 3 (`AMBIENT_DMG_CAP`).

### 정답 효과 실측 — 정답봇 vs 오답봇 (인스턴스 단위, 총 283 인스턴스)

대조군은 무대응봇이 아니라 **오답봇**이다 — 가만히 있는 봇은 붙기 정답 패턴에서
우연히 안전 지대에 서 있게 되어 비율이 왜곡된다.

| 패턴 | 정답 n | 정답 피해/인스턴스 | 오답 n | 오답 피해/인스턴스 | 감소율 |
|---|---|---|---|---|---|
| 지면 횡소 (점프) | 66 | 5.5 | 62 | 19.7 | **72%** ✓ |
| 난무 후 탈진 (거리→반격) | 43 | 0.7 | 48 | 28.4 | **98%** ✓ |
| 해머 강타 (붙기/벗어나기) | 11 | 6.2 | 13 | 21.2 | **71%** ✓ |
| 철거 돌진 (방어기) | 18 | 11.2 | 22 | 18.2 | **38%** △ |
| **합계** | **138** | **4.8** | **145** | **22.5** | **79%** ✓ |

**철거 돌진만 60% 미달이다.** 원인은 설계가 아니라 표본 구성이다 —
가드가 실제로 올라간 인스턴스는 30 피해 중 **6.6** 만 받아 **78% 경감**이 성립하지만,
정책 봇이 직전 공격 후경직에 걸려 가드를 못 올린 인스턴스(약 30%)가 평균을 끌어올린다.
가드/패링형 정답은 "맞되 경감" 이라 적중률이 아니라 피해로 읽어야 하며,
후경직에서 방어기로 빠져나오는 **방어 캔슬**을 추가해 접근 가능성을 높였다.

## 10. 낮 페이즈 — iso-scavenge

- **시야 원뿔**(약 76°, 14타일) + **기억 안개**. 못 본 방은 검고(하늘색이 아니라 어둠이다), 봤던 곳은 40% 밝기로 남는다.
  전지적 시야를 주면 이 페이즈가 통째로 무의미해진다.
- **기억은 2단계다** — `1 = 지면만`, `2 = 내용물까지`. 시작 지점 반경 9타일(LOS 통과분)은 **지면만** 연다.
  시야 원뿔 하나로 시작하면 화면 대부분이 미탐색이라 긴장이 아니라 **덜 그려진 화면**으로 읽힌다.
  걸어 들어온 골목 정도는 이미 알고 있는 게 자연스럽고, 지면만 여는 한 정보 이점은 생기지 않는다 —
  좀비·컨테이너·히든은 `2` 를 요구한다. 실측: 개방 반경 안의 좀비 1기, **화면에 보이는 좀비 0기**.
  탐색률 2.9% → 6.8%. "길은 보이는데 그 길에 뭐가 있는지는 모른다" 가 탐색이라는 동사에 맞는 상태다.
- 안 보이는 위협은 **화면 가장자리 방향 표시**로만 알린다(보이면 표시하지 않는다).
- **소음 예산**: 감쇠 1.1/s 기준 · 걷기 1.4/s(순증 +0.3) < 수색 5.0/s(+3.9) < 달리기 11.0/s(+9.9)
  < 문 부수기 26/s < 유리 34. 웅크림은 걷기의 0.28배라 **순감소**한다.
  임계(100) 도달 시 **3.2초 예고**(화면 테두리 적색 + 경고음) 후 호드 4기 스폰.
  실측 위계: 정숙 0 < 걷기 0.48 < 달리기 15.84 (각 2.6초).
  **감쇠가 생성률보다 크면 조용한 행동이 "소음 0" 이 되어 트레이드오프가 통째로 사라진다** —
  초기값(감쇠 3.4 / 걷기 0.7 / 수색 3.2)이 정확히 그 상태였고, 실측으로 잡아 재조정했다.
- **수색 게이지** 1.5~4초(빠루 보유 시 1.7배 단축). 취소 가능하며 중단 지점을 컨테이너가 기억한다.
- **부피 가방** 26. 통조림 2 · 쇠파이프 3 · 각목 3 · 연료통 4 · 무기 3~5.
  가득 차면 "무엇을 버릴까" 가 매번 발생한다.
- **자원 인과 제작** (추상 강화 포인트 없음):

| 결과 | 재료 | 작업대 |
|---|---|---|
| 보강 파이프 | 쇠파이프 + 청테이프 | — |
| 스파이크 배트 | 각목 + 못 ×2 | — |
| 화염병 | 알코올 + 천 조각 | — |
| 개조 식칼 | 강판 + 청테이프 | — |
| 부목 | 각목 + 천 조각 | — |
| 빠루 | 쇠파이프 + 강판 | 정비공 |
| 혈청 | 항생제 ×2 + 알코올 | 의사 |
| 전격 코일 | 배터리 ×2 + 볼트 | 정비공 |
| 더운 스튜 | 통조림 + 생수 | 요리사 |

- **낮 타이머 5분**, 상시 표시. 해가 지면 그 자리에서 밤으로 끌려간다. **조기 귀환 가능**(초록 표식).
- **전투는 손해**: 스윙 0.62초(밤 약공의 2.5배), 피격 시 42% 확률로 물림(감염 시작), 20% 확률로 부상.
  **비전투 해법**: 밀치기 · 병 던져 유인 · 문 잠그기 · 창문 넘기.
- **약공(Z)은 낮에서도 항상 무언가를 한다** — 대상이 있으면 수색(홀드), 없으면 스윙.
  밤에서 공격이던 키가 낮에서 무반응이면 플레이어는 "불리하다" 가 아니라 **"고장났다"** 로 읽는다.
  불리함은 스윙 성능(0.62초·물림 확률)으로 만들지, 입력을 죽여서 만들지 않는다.
  헛스윙에도 무기 궤적 잔상을 그린다 — 반경은 실제 사거리(1.5타일)와 같아 "어디까지 닿는가" 를 겸한다.

## 11. 생존 층 (중간 강도 — 아케이드 리듬을 끊지 않는 선)

| 축 | 규칙 |
|---|---|
| 감염 시계 | 물린 부위별(팔 0.85 / 다리 0.72 / 몸통 1.25 배율) 누적. 항생제로 -22, 혈청으로 제거. 100 도달 시 사망 |
| 허기 | 초당 0.30 감소(야간 1.35배). 25 미만 공격력 ×0.82, **0 이면 ×0.62 + 초당 1.6 체력 감소** |
| 피로 | 초당 0.24 증가. 70 초과 시 이동 ×0.88 |
| 부위별 부상 | 팔 골절(공격 -28%) · 다리 골절(이동 -26%) · 열상(초당 출혈) · 타박상(최대 체력 -12%) |
| 무기 내구도 | 제작·습득 무기만 소모(강공 2, 필살 4). 파손 시 **클래스 기본 무기로 복귀** — 무기가 0이 되어 진행 불가가 되지 않게 기본 무기는 부러지지 않는다 |
| 거점 인구 | 생존자마다 소비 1~3 / 야간 습격 배율 +6~16%. 무작정 구하면 손해 |

**죽이는 시계는 감염 하나다.** 아사는 최대 체력의 **25% 를 하한**으로 깎다가 멈춘다 —
프리셋에서 허기의 역할은 "스탯에 영향" 이고, 치명적인 건 감염 시계 쪽이다.
바닥 없이 깎으면 밤에서 음식이 안 나올 때 **부활 → 아사 → 부활**의 탈출 불가 루프가 된다
(실측: 밤 179초에 허기 0 → 163초마다 확정 사망, 부활해도 허기는 0 그대로).
대신 벌은 스탯으로 준다 — 공격력 ×0.62. 밤에는 허기 게이지가 없으므로 0 도달 시 배너로 한 번 알린다.

체온·수면·질병 풀 시뮬은 넣지 않았다.

## 12. 2인 협동 — 처음부터 전제

- **키 배열을 인원수에 따라 동적으로 갈아끼운다.**

| 모드 | 플레이어 | 이동 | 약공 | 강공 | 점프 | 잡기 | 방어기 | 필살 |
|---|---|---|---|---|---|---|---|---|
| 1인 (배치 1) | 1P | 방향키 | Z | X | C | V | Shift | Space |
| 1인 (배치 2) | 1P | W A S D | J | K | L | U | I | O |
| 2인 | **1P (키보드 오른쪽)** | 방향키 | `.` | `/` | `'` | `;` | `,` | `L` |
| 2인 | **2P (키보드 왼쪽)** | W A S D | F | G | V | B | T | R |

  1인 모드는 두 배치를 동시에 받는다. `F` 는 1인 모드에서 미할당이므로 **2P 참가 트리거**로 쓴다.
  참가 순간 배열이 자동 전환되고 **양쪽 배열표가 6초간 화면에 표시**된다.
  난입 의사는 눌린 시각으로 600ms 동안 유효하다 — 하필 씬이 바뀌는 프레임에 눌러도 씹히지 않는다.
  2P 액션 키에 `ZXC` 를 쓰지 않는다 — WASD 바로 아래라 손이 겹친다.

- 카메라: 생존 플레이어 중점 추적 + 화면 끝 소프트 리시(300px 이내로 몰리면 밀어준다).
  전투 락 구간에서는 락 지점 고정.
- 체력·레벨·물자·필살/방어 게이지·인벤토리·점수는 **플레이어별 독립**.
- 적 수 ×1.45, 적 체력 ×1.55, 동시 공격 토큰 +1 로 인원수 스케일.
- 다운 시 파트너가 살아있으면 소생 대기, 없으면 잔기를 쓰고 재투입.
- friendly fire 없음. 던지기·벽 충돌 판정은 상대 플레이어를 대상으로 삼지 않는다.

## 13. 아트 디렉션

**단일 팔레트** (`js/art/palette.js`). 낮과 밤은 `GRADE` 로 **값과 광원 온도만** 이동한다.

- 무채: void `#070a0e` → white `#f6f9fb` (9단)
- 나트륨 앰버: `#3a2410` → `#ffd98a` (5단) — 낮 햇빛과 밤 가로등이 같은 계열
- 감염 라임: `#16240f` → `#d6f58f` (5단)
- 혈흔/사이렌: `#2b070b` → `#ff3242` (5단)
- 냉광 시안: `#0c2a33` → `#5fd0e0` (4단)

**캐릭터 리그는 낮/밤 하나**. 차이는 `h`(픽셀 키)와 `yaw` 뿐이다.
부품이 따로 노는 것을 막는 장치 4개:

1. **실루엣 선행 패스** — 모든 부품을 외곽선 색으로 먼저 칠하고 굵게 스트로크해 하나의 덩어리를 만든다.
2. **재질 단위 그라디언트** — 단위 좌표계(키=1)에 한 번만 만들어 전 부품이 같은 광원을 공유하고 액터를 따라 움직인다.
3. **겹침 윤곽만 스트로크** — 실루엣 전체를 스트로크하면 가려진 캡슐 윤곽까지 그려져 와이어프레임이 된다.
   실제로 몸통을 가리는 앞쪽 부품(머리·앞팔·앞다리·무기)만 선을 긋는다.
4. **하드 셀 그림자 + 의복 디테일** — 직선 terminator, 벨트, 칼라, 요크. 벡터 일러스트가 아니라 스프라이트로 읽히게.

**적은 스탯이 아니라 실루엣으로 구분한다.** 합격 기준은 **주인공 키 = 화면 높이 1/7 인 실전 거리에서,
색을 빼고 윤곽만으로 5종이 갈리는가** 다. 실루엣 시트를 뽑아 폭 프로파일로 검증한다:

| 종 | 체형 | 높이 | 폭 | 종횡비 | 채움률 | 윤곽 특징 |
|---|---|---|---|---|---|---|
| 배회체 | HUMAN | 205 | 57 | 0.28 | 0.57 | 좁은 직립 기둥 (기준) |
| 돌진체 | GAUNT | 226 | 84 | 0.37 | 0.39 | 전방 경사 + 긴 보폭, 앞으로 뻗은 팔 |
| 토사체 | GORGER | 172 | 104 | **0.60** | 0.47 | 깊게 굽은 상체, 목주머니가 가슴선 밖으로 |
| 팽창체 | BLOAT | 229 | 99 | 0.43 | **0.63** | 통짜 물방울 덩어리 |
| 호출체 | HOWLER | 256 | 111 | 0.43 | **0.30** | 긴 목 + 어깨선 뒤 머리 + 들어올린 팔 = 역삼각 |

윤곽을 만드는 장치는 세 가지다.

1. **체형(build) 자체** — 어깨/골반 폭, 사지 길이, `hunch`(상시 상체 기울기).
2. **`headPush` / `neckR`** — 머리를 몸통 기준 앞(토사체 +)/뒤(호출체 −)로 밀어 어깨선과의 관계를 바꾼다.
   목이 긴 체형은 `neckR` 로 목을 굵게 잡아야 한다 — 얇으면 머리가 떨어져 나간 것처럼 읽힌다.
3. **자세 편향(`build.bias`)** — 대기·이동 클립에만 더한다. 공격 클립에 섞으면 예고 실루엣이 흐려진다.
   가만히 서 있을 때도 종이 읽히려면 여기서 갈려야 한다.

장식(`DECOR`)은 **실루엣 패스 뒤에 그려지므로 바깥선을 바꾸지 못한다.** 목주머니처럼 윤곽을 깨야 하는
덩어리는 데코가 아니라 **리그 부품(`build.sac`)** 이어야 하고, 데코는 그 위의 표면만 칠한다.

애니메이션은 키프레임 보간을 정수 프레임으로 양자화(24fps 환산). 클립 26종:
idle(10f) walk(12f) run(10f) sneak(12f) dash(5f) jumpRise/Fall(4f) land(4f)
atk1~4(5·5·6·7f) heavy(8f) launcher(7f) airLight(4f) airHeavy(5f) guard(3f) parry(4f)
hurt(4f) down(6f) getup(6f) grab(4f) hold(6f) throw(6f) special(9f) cast(6f) search(8f)
lunge(6f) spit(6f) slam(8f) spin(8f) stagger(6f) dead(1f).
스쿼시&스트레치는 착지 1.16/0.84, 강공 발도 1.20/0.86, 필살 1.24/0.84.

**밤 배경**은 파랄랙스 **6층**: 하늘+달(0.02) → 원경 스카이라인(0.10) → 중경 창문 격자(0.32) →
근경 상가·간판·차양(0.72) → 노면(1.00) → 전경 전신주·전선(1.35).
노면은 데칼 9종(맨홀·균열·콘크리트 패치·잔해·유막·혈흔·차선)과 아스팔트 패치 이음새로 채운다.
z=0 경계에는 값 분리 띠를 깔아 원단 소품이 배경 파사드에 붙어 보이지 않게 한다.

**낮 배경**도 6층이다: 하늘 그라디언트+해(시간에 따라 하강·적화) → 원경 스카이라인 2겹(파랄랙스 0.06 / 0.14,
층마다 대기 원근) → 지면 타일 → 건물 매싱 → 액터 → 전경 전선+비네트.
**아이소메트릭이라고 배경 레이어를 생략하면 화면의 60% 가 검은 여백이 된다** — 실제로 그랬고, 고쳤다.
안개는 3단계로 나눈다: 실외 미탐색 0.16(거리 윤곽은 보인다) / 실내 미탐색 0.05(안은 안 보인다) / 기억·시야 0.44~1.0.
컨테이너·좀비·생존자는 별도 게이트(`entityLight`)로 한 번도 본 적 없으면 그리지 않는다 —
정보 은폐는 지면이 아니라 **내용물**에 건다. 타일은 3톤(면 분할) + 데칼 8종 + 벽 접지 그림자.
플레이어를 가리는 근접 벽은 반투명 처리하고 발밑 링·머리 위 셰브론으로 위치를 보장한다.

깊이 연출 3종 동시 적용: 파랄랙스 · 대기 원근(fog) · 비네트. 가로등은 기둥 광원 + 바닥 광원 풀 2패스.

## 16-b. 죽은 입력 감사 (씬 × 키 전수)

**합격 기준: 어떤 씬에서 어떤 키를 눌러도 "고장났나?" 가 들지 않을 것.**
판정은 (씬 전환 | 상태 변화 | 효과음) 중 하나라도 있으면 통과, 셋 다 없으면 죽은 입력이다.
12키 × 8상태 = **96칸을 실제 KeyboardEvent 로 눌러** 측정했다.

| 상태 | 죽은 입력 (수정 전 → 후) |
|---|---|
| 타이틀 · 조작법 · 기록 · 캐릭터선택 | **34 / 48 → 0** |
| 낮(대상 없음) · 낮(컨테이너 옆) · 가방/제작 · 밤(지상) | **20 / 48 → 0** |
| 거점 · 게임오버 · 사이렌 전환 · 밤(공중) · 밤(다운) · 밤(게이지0·탈진) | **22 / 72 → 0** |

**도달 비용을 상수로 낮췄다.** 거점·게임오버·사이렌 전환은 완주나 사망을 거쳐야 해서 1칸에 3~4분이 들었다 —
스테이지가 8개로 늘면 전수 감사가 불가능해진다. `dev.testScene(name)` 이 **실제 생성자·실제 후속 배선**으로
곧장 진입시킨다(개발 경로 전용). 감사 1칸이 초 단위가 된다.

키 계약을 한 줄로: **확정 = 약공·필살 / 뒤로·취소 = 잡기·Esc / 배정 없는 키 = 거절음 + 화면 흔들림.**
거절 흔들림은 씬마다 넣지 않고 `App` 렌더 한 곳에서 `scene.nudge` 로 처리한다.

특히 고친 것 — 전부 "입력은 받는데 아무 일도 안 일어나던" 것들:

- **Esc** — `takePause()` 호출처가 0건이라 전 씬에서 죽어 있었다 → 낮·밤 일시정지, 메뉴는 뒤로
- **밤 잡기(V)** — 잡을 대상이 없으면 완전 무반응 → 헛잡기 모션 + 소리
- **밤 필살(Space)** — 게이지 부족 시 완전 무반응 → 거절음 + **게이지 자체가 붉게 점멸**(어디를 보라는 신호)
- **F(2P 난입)** — 못 쓰는 씬에서 무반응 → 안내 노출. 단 **소비하지 않는다** — 여기서 소비하면 곧 이어질 캐릭터 선택에서 난입이 씹힌다(`peekJoin`)
- **낮 달리기(C)·정숙(Shift)** — 제자리에선 티가 안 나는 홀드 수식키 → HUD 에 이동 모드 상시 표시
- **사이렌 전환** — 3초 연출 동안 전 키가 죽어 있었다 → **아무 키나 스킵**. 완료 경로(`onDone`)는 그대로 타므로 낮→밤 인계는 깨지지 않는다
- **거점 정산 탭** — 실행(약공/필살)을 눌러도 목록이 비어 무반응 → "읽는 탭이다" 안내

**측정 자체의 함정 2가지도 남겨 둔다 — 둘 다 게임이 아니라 하네스가 틀린 경우다.**

1. **누른 뒤 한 번만 찍으면 짧은 동작을 놓친다.** 320ms 뒤에 보면 약공(0.24초)·점프·이동 탭은 이미 원상복귀라
   **밤 약공까지 "죽은 입력" 으로 나온다.** 누르는 동안 45ms 간격으로 폴링해야 한다.
2. **긴 세션 후반 블록에서 CDP 키가 씹힌다.** 같은 키가 앞 블록에선 통과하고 뒤 블록에선 전부 실패했는데,
   **블록 순서를 바꾸니 실패가 순서를 따라 이동했다** — 씬도 키도 아닌 위치 의존이다.
   블록마다 프로세스를 분리해 측정한다(6블록 × 12키를 각각 짧은 세션으로).
