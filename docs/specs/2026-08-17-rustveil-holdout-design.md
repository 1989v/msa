# 녹빛 봉쇄구역 (rustveil-holdout) — 설계 문서

> 쿼터뷰 좀비 아포칼립스 생존 · 건설 · 디펜스. 한 대의 PC, 한 개의 키보드로 둘이 함께.

---

## 1. 세계관

산업 방역제가 유출된 항만도시 **해천시**. 유출물은 공기 중에서 균사로 자라 금속과 유기물을
함께 부식시켰다. 감염된 몸에는 **녹빛 결정**이 돋고, 그 결정이 어둠 속에서 빛난다.
생존자 둘은 도시 한복판 공원에 남은 **중계 신호탑**을 지키며 구조 신호를 계속 쏘아 올린다.

- **팔레트 정체성**: 흔한 좀비-그린을 버리고 **녹(rust) 주황 × 냉광 청록** 대비로 잡았다.
  감염체 결정색이 종류마다 다르므로(호박/청록/연두/적/보라) 1/13 스케일에서도 종류가 즉시 읽힌다.
- 고유명·디자인은 전부 창작이다. 기존 작품의 캐릭터·로고·고유 명칭을 차용하지 않았다.

## 2. 시점 결정 — 왜 완전 아이소메트릭이 아닌가

요구는 "쿼터뷰"지만 동시에 "V Rising 같은 top-down 액션 조작감 우선"이었다. 둘을 만족시키는
투영으로 **기울어진 탑다운(pitched top-down)** 을 택했다.

```
screen.x = world.x
screen.y = world.y * 0.60 - world.z     (CFG.view.pitch = 0.60)
```

| | 완전 아이소메트릭(2:1) | 채택: 기울어진 탑다운 |
|---|---|---|
| 이동 방향 | WASD 와 화면축이 45° 어긋남 | WASD 가 화면축과 일치 |
| 건설 그리드 | 마름모 — 배치 판독 어려움 | 사각 — 배치가 직관적 |
| 구조물 입체감 | 3면 노출 | 상단면 + 정면 2면 (z 오프셋으로 충분) |
| 렌더 비용 | 회전 변환 필요 | 좌표 그대로, 패턴 정렬 공짜 |

깊이 압축(0.60) 때문에 세로 이동은 화면상 60% 속도로 보인다 — 이는 쿼터뷰 장르의 정상 범위다.
**마우스 조준은 이 압축을 역으로 풀어** 월드 방향으로 환산한다(`input.js`).

## 3. 아키텍처 — 엔진 비의존 시뮬 + 교체 가능 렌더러

```
js/
  core/                  ← 순수 시뮬레이션. DOM/Canvas/오디오 의존 0
    data/                ← 밸런스 단일 원본 (config·weapons·zombies·buildings·loot·waves)
    systems/             ← player · combat · enemy · build · wave · physics
    world/gen.js         ← 도시 구역 절차 생성
    state.js game.js     ← 월드 상태 · 스텝 오케스트레이션 · 세이브
  input/                 ← 물리 키 → 추상 액션 (마우스/키보드/2인 분할)
  render/canvas/         ← 이 게임의 렌더러 (스프라이트 베이킹·조명·FX·카메라)
  audio/                 ← WebAudio 자체 신스
  ui/                    ← DOM HUD·메뉴·키설정
```

**경계 규약**: 시뮬은 "무슨 일이 일어났는지"만 `CueBus` 에 적는다(`HIT`, `KILL`, `BUILD`…).
파티클·화면 흔들림·사운드는 표현 계층이 그 큐를 해석해서 만든다.

이 경계 덕분에:
- 렌더러를 통째로 갈아 끼워도 게임 로직이 동일하다 (Phaser 비교 샘플의 근거)
- 후속 온라인 멀티에서 **입력 → 액션 → 상태** 파이프가 그대로 네트워크 경계가 된다

**풀 ECS 를 쓰지 않은 이유**: 개체 종류가 6종(플레이어/감염체/투사체/드랍/구조물/산성장판)으로
고정이고 조합 폭발이 없다. 객체 풀 + 시스템 함수로 같은 성능을 얻으면서 코드가 절반이다.
(KISS / YAGNI — 조합이 실제로 늘어나면 그때 ECS 로 옮긴다)

## 4. 조작 — 2인을 나중에 얹지 않았다

게임 로직은 물리 키를 **절대** 참조하지 않는다. 추상 액션만 본다.
키는 전부 `KeyboardEvent.code` 로 저장되므로 **Num Lock 상태·자판 배열(QWERTY/한글)과 무관**하다.

| 모드 | P1 | P2 |
|---|---|---|
| 1인 · 키보드+마우스 | WASD 이동 / 마우스 조준 / 좌클릭·우클릭 / Space 회피 / E 상호작용 / B 건설 | — |
| 1인 · 키보드 전용 | WASD 이동 / **IJKL 조준** / F 공격 / G 강공 / R 회피 / T 상호작용 | — |
| 2인 로컬 | **WASD + F G R T Q E** (왼쪽 클러스터) | **방향키 + 넘패드 0 . Enter 1 2 3** (오른쪽 클러스터) |
| 2인 · 텐키리스 | 위와 동일 | **방향키 + / . R-Shift ,** |

- 두 사람의 손이 물리적으로 겹치지 않도록 좌/우 클러스터로 분리했다.
- 모든 키는 옵션에서 재지정 가능하며 **키 충돌을 자동 검출**한다.
- 옵션에 **동시 입력 점검 패널**이 있다 — 키보드 하드웨어의 고스팅/롤오버 한계를 직접 확인할 수 있다.
- 조준 방향은 입력 장치와 분리되어 있다: 마우스 / IJKL / (후속) 게임패드 우스틱이 모두
  같은 `AttackDirection` 을 만든다. 키보드 모드에는 부채꼴 내 최근접 대상 **조준 보정**이 붙는다.

## 5. 조작감 — 실측 프레임 데이터

| 항목 | 목표 | 실측 |
|---|---|---|
| 입력 → 타격 판정 (약공) | ≤ 0.08초 | **0.060초** |
| 히트스톱 (약공 / 강공 / 처치) | 40~100ms | 50 / 95 / 75ms |
| 회피 발동 | 즉시 | 입력 즉시, 무적 0.16s, 쿨 0.62s |
| 이동 → 공격 전이 | 미끄러짐 0 | 공격 진입 시 즉시 감속, 전진 lunge 로 헛스윙 방지 |
| 연타 입력 씹힘 | 0 | 공격 큐 + 0.24s 버퍼. 8회 연타 → 7회 발동(무기 최대 속도 한계) |
| 보행 속도 | — | 380 px/s (실측 374) |
| 60fps 유지 | 필수 | **감염체 133기 · 밤 조명 전부 켠 상태에서 120fps** |

**타격감 조합** (모든 적중에 예외 없이 적용):
히트스톱 → 스프라이트 백색 플래시 → 방향 넉백 → 포자/스파크 파티클 → 화면 흔들림 →
데미지 팝업(치명타는 확대·황색) → 타격음. 처치 시 추가 흔들림 + 링 + 시체 페이드.

**적 공격에는 반드시 예고**가 있고, 예고는 **형태로 구분된다**(색만 바꾸지 않았다):
- `arc` 부채꼴 = 근접 (물러나라)
- `line` 직선 띠 = 돌진 (옆으로 피하라)
- `ring` 원 = 광역/장판 (원 밖으로 나가라)
- `burst` 방사선 = 호출 (지금 잡아라)

## 6. 자원 → 구조물 인과

추상 "건설 포인트"는 쓰지 않는다. 모든 구조물은 **실제로 파밍한 자원**으로만 만들어진다.

| 채집원 | 자원 | 쓰이는 곳 |
|---|---|---|
| 고사목 | 목재 | 목재 벽 · 문 · 바리케이드 · 화톳불 |
| 돌무더기 | 석재 | 석재 벽 · 화톳불 |
| 폐차 | 고철 | 스파이크 · 포탑 · 문 보강 |
| 건물 수색 | 천 · 식량 · 의약품 · 탄약 · **무기** | 소비 · 회복 · 전투 |
| 폐공장 수색 | 전자부품 · 연료 | 포탑 · (후속) 전기 시대 |

- 채집은 시간이 걸리고(1.25~1.9초), **이동 입력이 들어오면 즉시 중단**된다 → 좀비가 오면 바로 싸운다.
- 자원은 **개인 소지품 + 공용 창고** 이원화. 건설 비용은 개인 → 창고 → 파트너 순으로 차감된다.
- 구역마다 파밍 테이블이 다르다: 주택가(생필품) / 상가(식량) / 보건소(의약품) /
  치안센터(**화력**) / 폐공장(산업자재). 위험도도 함께 올라간다(0 → 2.5).

## 6-b. 세계의 크기 — 121구역 · 다섯 겹의 고리

세계는 **34,400 × 25,600** 월드 단위 (초기 3×3 도시 대비 **12.7배 면적**), 11×11 = **121 구역**이다.
거점을 한가운데 두고 체비셰프 거리로 **다섯 겹의 고리**를 이룬다.

| 고리 | 진입 | 지역 종류 | 성격 |
|---|---|---|---|
| 0 | — | 거점 공원 | 유일한 안전지대 |
| 1 | 시대 0 | 주거지구 · 근린공원 · 주말농장 · 학교 · 하천 둔치 | 생활권 — 목재/식량/식수 |
| 2 | 시대 1 | 상업지구 · 복합상가 · 보건단지 · 차고지 · 경작지 | 상권 — 식량/의약품/부품 |
| 3 | 시대 2 | 치안센터 · 폐차장 · 외곽 임야 · 정수장 · 항만 | 화력과 산업의 시작 |
| 4 | 시대 3 | 폐공장 · 채석장 · 침수 저지대 · 통신단지 · 구치소 | 광물·전자 |
| 5 | 시대 4~5 | 군 주둔지 · 발전소 · 활주로 · 결정 오염지 · 연구동 | 최상급 물자, 치명적 |

- 고리 경계에는 **검역 봉쇄선**이 둘러 있고 각 변 가운데에 검문소 통로가 하나씩 있다.
  해당 시대가 열려야 사라진다 — **새 시대 = 새 지형 한 겹**.
- 지역 26종 중 8종은 **건물이 없는 자연 지형**(임야·경작지·채석장·저지대·오염지 등).
  도시와 실루엣부터 갈라서 "지금 어디에 있는가"가 한눈에 읽히게 했다.
- **생성은 지연된다.** 처음에는 121칸의 종류·고리·랜드마크 위치만 정하고(6ms),
  내용물은 생존자가 3,400 단위 안에 들어올 때 **한 프레임에 한 구역씩** 만든다.
  구역이 곧 청크라 렌더·충돌·조회가 전부 "보이는 구역"만 훑는다.
  실측: 전 구역 강제 생성 시 노드 7,714 / 건물 416 / 소품 4,287, 힙 37MB, 120fps 유지.

### 탐험이 성립하는 조건

넓기만 한 맵은 걷는 시간만 늘린다. 다음 네 가지를 함께 넣었다.

1. **랜드마크 16종 · 86개소** — 지역마다 최대 하나. 실루엣이 멀리서 읽히고, 발견하면 지도에 영구히 남는다.
   - `tower` 무전 중계탑 · 레이더 관측소 → 가동하면 **이동 거점** + 주변 지형 공개
   - `camp` 강도 야영지 · 요새 → 사람이 지키는 은닉처
   - `cache` 보급 투하 · 추락 헬기 · 호송대 잔해 → 감염체가 들끓는 대형 보급
   - `field` 급수탑 · 온실 · 목재 적치장 · 고철 산 · 폐광 · 결정 정원 → 특정 자원 노다지
   - `ruin` 대피소 · 지하철 입구 · 지하 무기고 → 기록 + 한 번뿐인 보상
2. **이동망** — 중계탑을 부품으로 가동하면 지도(M)에서 다른 중계탑으로 넘어간다.
   거리 비례 연료 소모, **낮에만**. 2인은 함께 넘어간다(한 명만 옮기면 이격 제한에 걸린다).
3. **도로 이동 +18%** — 넓은 맵의 이동 비용을 지형 선택으로 푼다.
4. **세계 지도 + 안개** — 가 본 구역만 색이 있다. 미탐사 칸은 고리 윤곽만 보인다.
   봉쇄선과 필요 시대, 랜드마크 표식(모양=종류), 거점·생존자 위치가 함께 표시된다.

## 6-c. 강도 — 두 번째 세력

감염체만 있는 세계는 결국 "같은 것을 더 오래"가 된다. 사람을 넣었다.

| 종류 | 무기 | 행동 축 |
|---|---|---|
| 부랑 약탈자 | 권총 | 2연발 · **창고에서 물자를 훔쳐 달아난다** |
| 몽둥이패 | 둔기 | 돌진 · 구조물을 부수며 파고든다 |
| 무장 약탈자 | 기관단총 | 5연발 견제 · 훔친다 |
| 산탄 강도 | 산탄총 | 220 거리까지 붙어 한 번에 쏟아붓는다 |
| 사냥꾼 | 소총 | 1,250 거리에서 **조준선**을 그린다 — 엄폐로 끊을 수 있다 |
| 방화범 | 화염병 | 방어선을 태운다 (지속 장판) |
| 패거리 두목 | 기관단총 + 방탄판 | 정면 55% 감소 · 증원 호출 · 3페이즈 |

- **감염체와 같은 액터 풀**에서 돈다. 충돌·타격·풀 재사용을 한 경로로 유지하기 위해서다.
  갈리는 것은 행동 규약이고, 그 분기는 `def.human` 하나가 담당한다.
- **3파전**: 강도는 감염체와도 싸우고, 감염체는 강도를 문다.
  실측: 생존자가 개입하지 않은 9초 동안 강도 172 피해 / 감염체 235 피해 · 3기 사망.
- **도망친다.** 체력이 기준 아래로 떨어지면 등을 돌린다. 쫓아가 마무리할지 보내줄지가 선택이 된다.
- **훔친다.** 창고에 닿으면 물자를 들고 달아나고, 머리 위에 무엇을 들었는지 표시된다.
  죽이면 그대로 떨어진다(실측: 고철 14 → 처치 시 전량 회수). 시야 밖까지 도망치면 잃는다.
- **기지 습격**은 낮에 온다 — 밤의 감염체 웨이브와 리듬이 겹치지 않게.
  무전 감청 예고 26초 → 한쪽에서 몰려온다 → 창고를 턴다 → 격퇴하면 다음 주기.
- **야영지 소탕**: 접근하면 수비대가 깨어나고, 전멸시키면 은닉처가 열린다(전용 파밍 표).

## 7. 방어전 구조

```
밤 시작 → 유예 6초 → 펄스 스폰(3~5기) → 신호탑으로 직진
   ↓                                   ↓
스파이크(지속피해+감속) → 벽/문(내구도) → 포탑(탄약 소모) → 생존자
```

- 감염체는 **구조물을 실제로 부순다**. 목재 벽 260 HP를 보행체 1기가 34초에 파괴(실측 7.6 dps).
- 길이 막히면 그 구조물을 **기억하고**(3초) 계속 두드린다 — 재타겟이 덮어써서 헛치지 않는다.
- **신호탑이 무너지면 게임 오버**다. 벽은 장식이 아니라 시간을 사는 수단이다.
- 낮/밤 사이클(168초 / 112초). 밤에는 시야가 줄고 감염체가 신호탑을 노린다.

## 8. 2인 협동

- 카메라는 **두 사람의 중점**을 추적하고, 벌어지면 자동 축소하되 **하한(0.62×)** 을 지킨다.
  1500 월드 단위를 넘어 벌어지면 부드럽게 끌어당긴다(이격 제한).
- HP·스태미나·레벨·인벤토리는 **플레이어별 독립**. 창고만 공유.
- HP 0 은 즉사가 아니라 **다운** — 32초 안에 파트너가 붙어 상호작용을 길게 누르면 소생(35 HP).
  1인 모드에서는 **붕대를 소모해** 자력 회복한다. 둘 다 쓰러지면 게임 오버.
- 감염체 수·체력은 인원수로 스케일된다(1.72배 수 / 1.12배 체력) — 2인이라고 난이도가 반토막 나지 않는다.

## 9. 아트 파이프라인

런타임 벡터 드로잉 대신 **로드 시 스프라이트를 굽는다**(감염체 100기+ 전제).
각 프레임 합성 순서: `외곽선 스탬프 → 3톤 음영 본체 → 상단 림라이트 → 하단 접지 그림자`.
부품(팔/다리/몸통/머리)을 그린 뒤 **실루엣 전체에 한 번에** 외곽선을 입히므로 부품이 따로 놀지 않는다.

- 방향 5종(S/SE/E/NE/N) × 클립 10종을 굽고 서쪽은 좌우 반전으로 재사용
- 감염체는 **결정 발광 + 안와 발광**으로 어두운 밤에도 실루엣이 읽힌다
- 배경은 절차 생성 노이즈 타일(아스팔트/콘크리트/흙/풀/타르) + 데칼 620개 + 구역 틴트
- 건물은 압출 박스: 정면(층 띠·창틀·판자·깨진 유리·녹물 자국·배수관) + 지붕(자갈·실외기·물탱크·환기구·옥상문·난간)
- 조명은 반해상도 오프스크린에서 `destination-out` 으로 어둠을 뚫고, 따뜻한 발광은 가산 합성
- **키 큰 오브젝트가 생존자를 가리면 자동으로 투명해진다** (건물/나무/신호탑)
- 무리에 파묻히면 **주인공 실루엣을 위에 덧그린다** — 자기 캐릭터를 놓치지 않게

## 10-b. 스택 결정 기록 — 순수 Canvas vs Phaser 3

**결정: 순수 Canvas** (2026-08-17). 판단을 위해 같은 `js/core/**` 시뮬레이션과 같은 절차 아트를

샘플과 vendored phaser(1.2MB)는 결정 후 제거했다(필요하면 git 이력에서 복원 가능).

| 항목 | 순수 Canvas (본편) | Phaser 3 샘플 |
|---|---|---|
| 부팅 | 즉시 (스프라이트 베이킹 ~0.4s) | **1.6s** (Phaser 1.2MB 파싱 + 텍스처 1,214장 등록) |
| 번들 크기 | 0 (자체 코드만) | **+1.2MB** vendored |
| 감염체 108기 fps | **120 (표시 상한)** | 110~120 |
| HiDPI | 디바이스 픽셀 1:1 자동 | **수동 처리 필요** — `resolution` 옵션이 제거되어 캔버스를 dpr 크기로 만들고 CSS 로 되돌려야 한다 |
| 고정 HUD | DOM 으로 분리 (선명·레이아웃 자유) | `scrollFactor(0)` 이 줌을 무시하지 않아 **매 프레임 역보정 필요** |
| 깊이 정렬 | 직접 정렬 (한 줄) | `setDepth` 로 엔진이 처리 |
| 파티클·화면흔들림 | 직접 구현 | 엔진 제공 (`particles`, `camera.shake/flash`) |
| 밤 조명 | 오프스크린 합성으로 구현 | 샘플 미구현 (파이프라인/셰이더 필요) |
| 빌드 스텝 | 없음 | 없음 (vendored script 태그) |
| 플랫폼 배선 | `<script>` 한 줄로 즉시 | 동일 |

**판단 근거**: 이 게임에서 엔진이 대신 해 주는 것(깊이 정렬·파티클·카메라)은 이미 구현되어
있고 각각 수십 줄 규모다. 반대로 엔진이 방해하는 것(HiDPI·고정 HUD·번들 크기·조명 파이프라인)은
이 장르에서 매일 마주치는 지점이다. 실제 플레이 비교에서도 순수 Canvas 판이 나았다.

### 감염체가 서로 다른 이유 (행동 축)

스탯 재탕이 아니라 **대응 방식이 다르다**: 포복체는 낮은 장애물 밑을 지나고, 매달림체는 벽을 타 넘고,
경갑체는 정면 피해를 78% 흘리고(옆·뒤를 잡아야 한다), 은신체는 멀면 안 보이고, 채찍체는 벽 뒤에서 끌어내고,
해체체는 생존자를 무시하고 방어선만 부수고, 전격체는 전력을 끊고, 통곡체는 발을 묶고,
직조체는 사격선을 균사로 막고, 재기체는 쓰러진 것을 다시 일으키고, 거체는 체력 구간마다 성격이 바뀐다.

### 장비 · 개조 · 소비품 · 투척물

제작이 만든 것이 전부 **실제로 쓰인다**. 만들기만 되고 쓸 데가 없는 산출물은 남기지 않았다.

| 계층 | 수 | 효과가 붙는 곳 |
|---|---|---|
| 장비 | 16종 (머리/몸/다리) | 피해 감소·이동 속도·채집 속도·재장전·산성 저항·야간 시야·적재·차폐 실드 |
| 무기 개조 | 10종 (무기당 2칸) | 피해·탄퍼짐·반동·탄창·재장전·연사·사거리·경직·무소음 |
| 소비품 | 23종 | 즉시 회복 + **지속 버프**(속도/공격/치명/야간시야/내열) + 반동 + 해독·감염 억제 |
| 투척물 | 8종 | 폭발 · 화염 장판 · 산성 장판 · 연막(추적 차단) · 섬광(경직) · 유인(무리 유도) · 지뢰 · 표적 포화 |

- 장비는 **합산 상한 72%** 로 잠가 무적을 만들지 않는다. 차폐 실드는 피격 후 재생된다.
- 각성제류는 버프가 끝나면 **반동**이 온다 (`after`).
- 투척물은 포물선으로 날아가고 **낙하 지점이 미리 표시**된다. 폭발은 자기 피해도 있다.
- 연막은 감염체의 추적을 실제로 끊고, 유인은 무리를 지정한 좌표로 끌어모은다.

### 자동화 (시대 5)

| 시설 | 하는 일 |
|---|---|
| 조립기 | 창고 재고로 만들 수 있는 정제품을 스스로 계속 만든다 |
| 자동 급탄기 | 창고 탄약을 주변 포탑에 넣는다 (포탑 종류별 탄약 매핑) |
| 수거 컨베이어 | 바닥에 떨어진 물자를 창고로 빨아들인다 |
| 자동 채굴기 · 해체기 | 주기마다 석재/광석/고철을 창고에 넣는다 |

전부 **전력을 먹는다**. 발전기가 멈추거나 전격체의 EMP 를 맞으면 함께 죽는다.

### 밤의 리듬 — 600번의 밤을 다르게 만드는 것

100시간 = 약 600번의 밤(사이클 10분)이다. 수치만 올리면 그 중 500번이 같은 밤이 된다.

1. **피의 밤** (7일 주기): 규모 2.1배 · 정예 +12% · 보스 다수(30일차 2기, 70일차 3기) ·
   **붉은 하늘 + 전용 컷인**
2. **밤 변수** (15일차부터 1개, 40일차부터 2개): 그날의 *문제*가 바뀐다
   - 짙은 안개 — 조명 반경 45% 감소 + 화면 안개막
   - 정전 — 전력 구조물 전면 정지 (포탑·전등·전기 함정)
   - 무리 폭주 — 감염체 이동 속도 +32%
   - 결정 증식 — 정예 비율 +20%, 결정 드랍 2배
   - 산성비 — 조명 밖에 서 있으면 계속 깎인다
   - 한파 — 기력 회복 절반, 이동 −10%
   - 연쇄 호출 / 고요한 밤 — 구성 자체가 바뀐다
3. **구성 이동**: 밤이 깊을수록 상위 티어 비중이 올라간다 (120일차엔 직조체·재기체가 주력)
4. **정예·보스·체력 배율**: 수가 성능 상한에 닿은 뒤의 난이도 축

### 전력 · 생산 · 농사

시대 4부터 구조물이 **전력 수지**(발전 − 소비)로 묶인다. 부족하면 포탑·조명·전기 함정이 함께 죽는다.
전격체의 EMP 는 이 관계를 노린다. 우물·빗물받이·밭·자동 채굴기는 주기마다 창고에 산출을 넣는다.

## 12. 실측으로 잡은 버그 (같은 함정 재발 방지용 기록)

1. **분무체가 매 프레임 신호탑을 때렸다** — 근접 프레임 데이터가 전부 0이라 공격 사이클이
   한 프레임에 끝났다. 초당 900 피해로 5초 만에 게임오버. → 데이터 수정 + **엔진에 프레임 하한 강제**.
2. **벽이 안 부서졌다** — 0.35초마다 도는 재타겟이 구조물 타깃을 덮어써서 대부분 헛쳤다.
   → 막힘 기억(3초) + 공격/특수 동작 중 재타겟 금지.
3. **파밍 무한 루프 위험** — 이미 가진 유니크 무기가 반복 추첨되면 `i--` 가 영원히 돈다. → 재시도 상한.
4. **캔버스를 디스플레이보다 작게 잡아 업스케일** — 밀도 손실. → 디바이스 픽셀 1:1, 줌을 해상도에 비례.
5. **건물이 생존자를 완전히 가림** — 쿼터뷰의 구조적 문제. → 발자국 축소 + 가림 시 자동 투명화.
6. **밤 fps 79** 로 보였으나 원인은 렌더가 아니라 **열려 있던 검증용 고아 탭들이 rAF 를 나눠 먹은 것**.
   단일 탭에서는 108기 + 조명 전부 켠 상태로 120fps.
7. **큐 페이로드가 큐 타입을 덮어썼다** — `push(type, data)` 가 `{type, ...data}` 라서 페이로드에 `type` 키가
   있으면(예: `KILL` 의 좀비 종류) 큐 자신의 타입이 지워졌다. 결과: **처치 연출이 한 번도 발동하지 않고 있었다.**
   조용히 죽는 종류의 버그다. → `{...data, type}` 으로 봉투를 마지막에 씌우고, 페이로드 키는 `zType` 으로 개명.
8. **풀 재사용 시 종류별 플래그가 남았다** — `cloaked` 가 남은 채 다른 종류로 재활용되어
   `z.def.cloak.alpha` 를 읽다 크래시(3,024회). → `resetZombie` 가 신규 필드를 전부 지우도록 확장.
9. **분류가 늘면 UI 가 먼저 무너진다** — 구조물이 9종에서 82종이 되자 한 줄 목록이 성립하지 않았다.
   분류 축(11개)을 만들고 시대 게이트로 걸러 한 화면에 6~16개만 보이게 했다.
10. **테스트가 게임오버를 만들면 그 뒤 검증이 전부 거짓이 된다** — `stepWorld` 는 `w.over` 에서 즉시 반환하므로
   전력·생산·큐가 전부 멈춘다. 실제로 "전력 0" 을 버그로 오독했다. 검증 스크립트는 코어와 생존자를 유지할 것.
11. **시대 문턱이 그 시대 안에서만 만들 수 있는 재료를 요구했다** — 시대 3은 철괴·석탄을, 4는 전선을,
   5는 합금·동력셀을 요구하는데 그 레시피가 전부 해당 시대 잠금이었다. **진행 불가 3건.**
   → 문턱 재료의 레시피를 한 시대씩 앞당겼다.
12. **작업 시설 비용에도 순환이 있었다** — 판재로 제재소를, 숯으로 화덕을, 철괴로 용광로를,
   회로판으로 전자작업대를 짓게 되어 있었다(전부 그 시설에서만 나오는 재료). **진행 불가 4건.**
   → 도달성 검사기를 만들어 고정점 반복으로 전 시대·전 레시피·전 구조물을 검증한다:
   현재 **미도달 0 · 미제작 0 · 미건설 0**.
13. **곡선은 데이터를 짜는 것만으로 검증되지 않는다** — 채집 봇으로 수입률을 실측(목재 786/h, 석재 378/h,
   고철 312/h)한 뒤 계산하니 시대 5 도달이 58시간으로 나왔다(100시간 대비 적정). 반면 **사이클이 4.7분이라
   100시간에 1,285번의 밤**이 오고 웨이브 수치는 44일차에 상한에 닿아 그 뒤가 전부 같았다.
   → 사이클 10분 + 피의 밤 + 밤 변수로 리듬을 다시 짰다.
14. **맵을 키우면 "가장자리에서 스폰"이 조용히 망가진다** — 월드가 12.7배가 되자 밤 웨이브가
   최대 2만 단위 밖에서 걸어오기 시작했다(밤이 끝나도 도착 못 함). 배회 개체도 아무도 없는 구역에서
   액터 예산을 태웠다. → 습격은 **방어 대상 둘레 2,500 링**, 배회는 **생존자 시야 밖 1,250~2,600** 으로.
   실측: 스폰 거리 중앙값 2,784 (월드 대각선은 42,880).
15. **습격조 전원이 코어에 달라붙어 창고에 닿지 못했다** — 물자를 노리고 온 세력이 길목의 핵심 시설을
   목표로 승격시켜 영원히 갈았다. → 강도는 코어를 목표로 삼지 않고 **접선 방향으로 돌아간다**(slide).
   실측: 수정 후 창고 도달 → 고철 14 탈취 성공.
16. **조준각을 `facing` 으로 쓰면 관성이 총구를 흔든다** — 조준 계산은 정확한데 전탄이 170 단위 옆으로
   지나갔다. `facing` 은 이동 방향에서 다시 계산되기 때문. → **조준각(`aimA`)을 따로 들고**,
   사격 중에는 이동이 조준을 덮지 않게 하고, 쏘는 동안 발을 붙였다. 실측 조준 오차 중앙값 0°.
17. **총을 든 적이 근접까지 붙으면 총이 의미를 잃는다** — 사거리 데이터(`keep`)를 넣어 두고
   실제 이동에 쓰지 않았다. → 계열별 유지 거리 + 측면 이동. 실측: 각 종류가 keep ±20 에서 교전.
18. **탄이 안 맞는 줄 알았는데 검증 배치가 틀렸다** — 생존자를 코어 위에 세워 두어 탄이 전부 구조물에
   막혔다. 엄폐가 정상 동작한 것. 실패를 보고하기 전에 **검증 장면 자체를 의심할 것**.
19. **투척물 정의 키 이름 한 글자 차이로 불이 안 붙었다** — `kind` 로 넘겼는데 소비처는 `effect` 를 본다.
   던지는 연출은 나가고 장판만 생기지 않아 눈으로는 정상처럼 보였다. → 실측 피해량으로만 확인 가능.
20. **첫 조우 때마다 140~380ms 화면이 멈췄다** — 종류별 스프라이트를 한 프레임에 통째로 구웠다.
   맵이 넓어져 만나는 종류가 늘자 체감이 커졌다. → 굽기를 **(클립 × 방향) 조각으로 쪼개
   프레임당 하나씩**, 나머지는 게임 중 배경에서 채운다. 실측: 30종 12.4초에 걸쳐 완료,
   **최악 프레임 20.4ms · 33ms 초과 0회** (이전 최악 197ms).
21. **자연 지형에 도시 소품을 뿌리면 숲 한복판에 공사장이 선다** — 임야 소품 목록이 철망 울타리였다.
   → 그루터기·바위를 추가하고 자연 지형의 소품 목록을 분리. 스크린샷으로만 잡히는 종류의 문제다.
