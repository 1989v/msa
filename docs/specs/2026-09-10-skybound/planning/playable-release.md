# 플레이 가능한 공개판 마감 · 2026-09-19

사용자: 제대로 구현해 끝까지 진행. 기존 기능/세이브를 보존하며 작은 변경→필수 검증→커밋 방식으로 마감한다. 새 승인 없이 이미 승인된 개인 게임 서비스 배포를 이어간다.

## 현재 간극과 구현 순서

1. 화면: 페이지 안 작은 진단 캔버스/여러 툴바를 전체 뷰포트 게임 장면으로 전환. 독자 세계 자체가 첫 화면이다. 시작·일시정지에 제목/진행/계속하기/지도/설정/저장을 모으고 실행 중 HUD는 체력·행동·목표·메뉴만 노출. 엔딩도 같은 화면 안에 배치. 키보드 포커스, 세로/가로 터치 겹침을 확인한다.
2. 진행: 첫 지도 완료 후 자동 목표가 야영지로 끝나는 문제를 고쳐 서부 정박지→기록섬으로 연결. 안전한 새 지역에 실제 착지하면 재도전 지점으로 사용해 한 번 추락으로 긴 항로를 전부 잃지 않게 한다. 수동 야영지 귀환과 재접속 안전 복원은 구분한다.
3. 조작: 벽에서 빠져나올 때 급격한 카메라 거리 변화를 완화하고, 접촉 시에는 즉시 앞쪽으로 당긴다. 기존 사용자 확대/축소 거리는 유지한다.
4. 묶음 검증과 배포: 새 게임→세 유적→확장 결말·저장 연결 근거를 재사용하고 바뀐 입력/지도/복귀/카메라 경계만 추가 검사. 최신 묶음을 개인 서비스에 배포하고 공개 파일로 확인한다.

## 화면 설계

- 세계의 밝은 석회암과 풀밭을 배경으로 그대로 사용. HUD는 root DESIGN.md의 어두운 surface/text/accent 토큰으로 대비를 확보한다. 직접 hex/외부 폰트/다른 게임 에셋 없음.
- 제목은 넓은 획의 기존 글꼴, 시작 패널은 왼쪽 24rem, 나루와 먼 유적은 오른쪽 화면에 남긴다. 작은 화면에서는 가운데 제한 폭/내부 스크롤.
- 실행 중 상단 상태/메뉴, 하단 상황별 액션/방향. 터치는 왼쪽 이동, 오른쪽 점프/달리기, 가운데 남은 시야 공간을 확보.
- 페이지 스크롤 없이 메뉴를 열고 닫고 플레이. 설정/지도/힌트는 native dialog, 시작·엔딩은 역할과 포커스 범위를 가진 패널.

## 완료 판정의 한계

이 문서는 소프트웨어 동작 마감 계획이다. 원화와 실제 캐릭터의 아트 품질 차이, 실기기 성능, 사람이 느끼는 완주 시간/음질을 검사하지 않고 전체 PRD 완료라고 선언하지 않는다. 불필요한 재검사를 줄이되 실제로 남은 항목은 기록한다.
