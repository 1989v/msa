# Requirements · 원문과 해석

## 사용자 원문

> 웹에서 동작하는 오픈월드 젤다의전설 왕국의 눈물 like 게임을 구축해 줘.

> 게임 생성시 기존 게임을 참고하지 않고 클린룸에서 너의 최대 성능을 발휘해서 진행해야 해. 내 다른 게임들이 너의 발전가능성을 제한하지 않게

> 가능하면 구현을 위한 전체적인 설계를 PRD형태로 만들고 진행. 디자인 에셋들도 만들고, 토큰이 많지않으니 쪼개어 할 수 있도록하면 좋을듯

> 계속 저장하면서 진행해주고 어느 경로에 저장한건지도 알려 줘

## 처리

- 전체 게임 제작이 장기 목표다. 최신 요청에 따라 현재 작업은 PRD/디자인/단계 분할이다.
- 기존 게임 코드 열람 전력이 있는 메인 에이전트는 게임 구현을 맡지 않는다.
  창작 에이전트에는 대화 이력 없이 독립 브리프만 전달했다.
- 구현 시작 전 사용자 조정으로 클린룸 제작을 중단했다. 작성된 게임 소스는 없다.
- 제목/서사/지역 수/수치는 제안이며 PRD에서 식별한다.
- 의존성 도구와 프로젝트 통합 계약만 재사용한다. 기존 게임 로직/아트/레벨은 재사용하지 않는다.
- 서버·로그인·랭킹·배포를 이번 산출물에 포함하지 않는다.
- 이후 계속 진행 요청에 따라 T01A 실험을 추가했다. 단위마다 경로와 검증 결과를 저장한다.
