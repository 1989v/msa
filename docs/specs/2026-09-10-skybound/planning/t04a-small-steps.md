# T04A · 물체 조작 소단위

## T04A-1 순수 상태 규칙

선택 → 집기 → 이동/회전 예고 → 유효 배치/취소를 다룬다. PRD SR-3의 사거리·벽 가림·플레이어/다른 물체 내부 배치 방지를 규칙으로 검증한다. 조작 대상은 사전 정의된 돌/프리즘 한 개씩이다. 화면·퍼즐 완료·게임 저장은 아직 연결하지 않는다.

회전은 초기 슬라이스에서 90도 단위로 제한해 상자 충돌 범위가 실제 회전과 일치하게 한다. 자유 회전·범용 조립 물리는 범위 밖이다. 벽/경계 데이터와 캐릭터 범위는 호출부가 제공한다. 기존 지형은 소품 벽 충돌이 없으므로 화면 연결 시 실제 검증용 장애물 데이터가 필요하다.

## T04A-2 데모 연결

독창적인 프리즘 하나와 조작 안내를 추가하고 PC/터치 공통 액션으로 선택·운반·회전·놓기를 연결한다. 선택 외곽, 유효/무효 배치 색+형태, 메뉴 중 운반 정지와 reset 복구를 실제 브라우저에서 검증한다.

### T04A-2b 지면 지지 보강

회전된 물체 바닥의 3×3 표본을 실제 지형에서 조회한다. 표본 중 지면이 없거나 높이 차이가 0.2m를 넘으면 배치를 거부한다. 유효한 목표는 가장 높은 표본에 바닥을 맞춘다. 이는 표본 기반 근사이며 표본 사이 작은 구멍까지 연속적으로 보장하지 않는다. 이동·회전·놓기에서 같은 지지 조건을 사용한다.

사용자 검증 비용 방침에 따라 이 단계는 지지/조작 관련 단위 검사와 번들 빌드만 수행한다. 벽 경계·작은 모바일 화면과 전체 플레이 회귀는 후속 퍼즐 통합 때 묶어 확인한다.

## T04B 첫 퍼즐

받침 하나에 놓인 물체만 완료 조건으로 판단하고 운반 중에는 완료시키지 않는다. 잘못된 배치·물체 분실 후 유적 reset으로 재도전한다. 게임 저장 계약(미완료 유적은 초기 배치, 완료 받침은 고정 복원)은 T07과 연결한다.

### T04B-1 첫 받침 연결

시작 지점 가까이에 바닥 표시형 받침 하나를 둔다. 프리즘을 90도 또는 270도로 돌려 바닥 면 전체를 받침 안에 내려놓으면 완료한다. 받침 높이는 실제 지형 표본을 사용하며 별도 충돌 플랫폼을 만들지 않는다. 운반/예고 상태는 완료 근거가 아니며 일시정지 중 새 완료는 발생하지 않는다. 완료는 유지하고 프리즘 재집기를 막으며 출발점 reset으로 함께 초기화한다. 보상·게임 저장·다른 유적은 다음 단계다.

이번 필수 검사는 순수 완료 규칙과 실제 지형에서의 배치 연결, 번들 빌드다. 브라우저 경계·모바일 QA는 후속 플레이 패스로 묶는다.
