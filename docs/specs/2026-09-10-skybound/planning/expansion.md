# P5 · 서부 관측 항로

2026-09-16. PRD §9의 새 지역2곳 확장을 기존 단일 물체/활공 규칙 위에 진행한다. 기존 첫 지도 결말은 유지한다.

## 첫 실행 단위: 도달과 귀환

- 전망섬 결말 후 북단 출항대(-3,-42)의 바람을 열고, 서부 정박지(-65,-67)와 높은 기록섬(-48,-126)으로 연결한다.
- 기존 원본 월드의 두 섬 실제 상면을 이동 지형에 연결. 바다 위 중간 착지대는 한 구간 약24m 이하, 모든 출항점에 상승/기력 회복 기류. 필수 항로에 기력 업그레이드/텔레포트 요구 없음.
- 중간 발판5곳: (-20,-46),(-40,-54),(-58,-62),(-64,-85),(-59,-105). 각 구간은 기본 기력으로 왕복할 수 있는 높이를 검사하며 지역 출항점3곳과 합쳐8개 기류를 사용한다.
- 전체 군도 지도와 기존 주섬 상세 지도를 선택. 새 목적지는 길잡이에서 중간 출항점까지 순서대로 안내한다. 발견 전에는 상세 기록을 숨긴다.
- 진행 저장은 기존 journeyComplete와 발견 ID를 재사용하며 새 유적 완료를 허위로 추가하지 않는다.

## 다음 실행 단위: 각 지역의 행동과 보상

- 서부 정박지: 분리된 관측 고리 정렬 퍼즐. 기존 회전 도구에 대응하는 원본 조작/가시적 정렬 조건을 설계하고 저장 계약을 추가한다.
- 높은 기록섬: 서부에서 복원한 항로를 이용하는 고도 선택 퍼즐과 지도의 두 번째 장. 기존 결말 뒤의 확장 완료 화면으로 구분한다.
- 환경 소품/원화 문법/음향 마감 및 사람의 완주 시간은 지역 연결 이후 진행한다. 45~90분은 목표이며 구현 완료나 실측으로 표현하지 않는다.

## 필수 검사

기존 저장 로드, 실제 섬 상면/모서리, 기본 기력 구간 왕복, 바람 잠금, 지도 좌표, 북단 출항→두 지역→귀환을 묶어 확인한다. 초기3유적 전체 검사는 변경된 경계가 없으면 반복하지 않는다.

## 지역 퍼즐 계약

- 정박지의 관측대3개(-75/-72/-69, -73)에서 G/활성화 버튼으로 바늘을90도씩 회전. 고정된 바닥 눈금과 움직이는 황동 바늘을 맞춘다(방향 목표1/2/3). 색 외에 방향과 정렬 수를 함께 표시한다.
- 관측대는 지면에서2.2m 이내, 높이 차1.2m 이내, 첫 지도 완료 후 조작. 운반/공격/회피/메뉴 중 조작 불가. 세 개 정렬 시 harborAligned 저장. 미완료 바늘 각도는 재접속 시 초기화한다.
- 기록섬은 harborAligned 이후 높이별 관측 고리3개를 정해진 순서로 활공 통과하고 중앙 장치에 착지해 G로 기록한다. 고리는 중심 기류에서 옆으로 벗어나야 닿도록 놓는다. 통과 진행은 세션 상태, 사망/재접속 시 초기화한다.
- archiveComplete는 harborAligned·journeyComplete가 모두 있어야 저장 가능. 완료 시 지도의 두 번째 장과 계속 탐험/야영지 귀환 제공. 기존 결말/첫 세 유적 조건은 그대로다.
- 어떤 지역 퍼즐 상태도 귀환 기류를 잠그지 않는다. 항로 개방 조건은 journeyComplete 하나를 유지한다.
