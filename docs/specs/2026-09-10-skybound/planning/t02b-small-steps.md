# T02B · 작은 단위 인계

사용자: “리밋이 15%남았으니 작은 단위로 진행 > 기록 반복”.
각 단위를 검증하고 저장한 뒤 다음 단위로 이어간다. 미완료는 체크하지 않는다.

## T02B-1 · 리깅 파일 경로

- 입력: spec.md, art-direction.md, context/open-questions.yml의 Q05.
- 소유: implementation/t02b/rig-check/.
- 설치된 Three.js 표준 GLTFExporter → GLB → GLTFLoader만 시험한다.
- 작은 진단 메시에 뼈대·스킨 가중치·애니메이션을 넣는다. 주인공 모델로 사용하지 않는다.
- 검증: 뼈대/가중치/트랙 보존, 재로드 후 애니메이션에 따른 꼭짓점 변형.
- 산출물: 재현 소스, GLB, 테스트, 명령과 한계를 적은 README.
- 제한: 텍스처·원화 품질·브라우저 렌더 통과로 확대 해석하지 않는다.

## T02B-2 · 텍스처 경로

- T02B-1 결과를 읽고 1K 아틀라스의 UV/색 공간/내보내기·재로드를 별도 검증한다.
- 실제 도구 가용성과 원본 파일 관리 방식을 기록하고 Q05를 해소한다.
- 새 이미지 생성이나 유료 도구가 필요한지는 이 단계에서 판단한다.

## T02B-3 / T02B-4

제작 경로가 검증되면 원화 기준 주인공 모델/리깅을 만들고 실루엣을 비교한다.
그다음 걷기·달리기·점프·착지를 만들고 T02A README의 이동 스냅샷에 연결한다.
원화 수준과 게임 조작감 검증 전에는 T02B 전체를 완료로 표시하지 않는다.

## 매번 남길 기록

수정 파일, 실행 명령, 실제 결과, 미검증 영역, 다음 한 단위, 커밋.
창작은 이 게임 자료만 전달한 새 컨텍스트에서 수행한다.
