# 전체 구축 진행 추정 · 2026-09-11

**약 30% (대략 25~35% 범위).** PRD의 15~25분 완주 가능한 독창적 브라우저 게임과 최종 검증·공개 준비까지를 기준으로 한 작업량 추정이다. 대형 상용 게임 규모를 의미하지 않는다. 작업 시간 측정이나 완료 체크박스 비율이 아니며, 남은 개발 시간·토큰으로 환산할 수 없다.

| 영역 | 전체 가중치 | 영역 내 추정 완료 | 근거 |
|---|---:|---:|---|
| PRD·설계·작업 분할 | 10% | 100% | 문서와 완료 기준 저장, 구현 중 조정 가능 |
| 렌더링·에셋 파이프라인·지형 기반 | 15% | 80% | GLB·리깅·텍스처 왕복 및 섬 지형 검증; 충돌·통합 보완 필요 |
| 캐릭터·이동·입력 | 15% | 50% | 이동/달리기/점프 및 PC 시야 구현; 터치·동작 품질 보완 필요 |
| 활공·퍼즐·전투 | 25% | 0% | 설계만 존재, 실제 플레이 미구현 |
| 퀘스트·월드 콘텐츠·엔딩 | 15% | 0% | 완주 흐름 미구현 |
| 저장·메뉴·사용성 | 10% | 0% | 게임 저장과 정식 UX 미구현 |
| 최종 아트·음향·성능·공개 준비 | 10% | 0% | 원화와 기술 초안은 있으나 최종 품질 미통과 |

가중 합 29.5%를 약 30%로 반올림했다. 세부 단계마다 1%씩 올리지 않고 주요 플레이 기능·완주·품질 검증이 완료될 때 다시 추정한다. 아트는 계속 REVISE이며 기술 검사 통과가 최종 품질 통과를 뜻하지 않는다.
