# 전체 구축 진행 추정 · 2026-09-13

**약 35% (대략 30~40% 범위).** PRD의 15~25분 완주 가능한 독창적 브라우저 게임과 최종 검증·공개 준비까지를 기준으로 한 작업량 추정이다. 대형 상용 게임 규모를 의미하지 않는다. 작업 시간 측정이나 완료 체크박스 비율이 아니며, 남은 개발 시간·토큰으로 환산할 수 없다.

| 영역 | 전체 가중치 | 영역 내 추정 완료 | 근거 |
|---|---:|---:|---|
| PRD·설계·작업 분할 | 10% | 100% | 문서와 완료 기준 저장, 구현 중 조정 가능 |
| 렌더링·에셋 파이프라인·지형 기반 | 15% | 80% | GLB·리깅·텍스처 왕복 및 섬 지형 검증; 충돌·통합 보완 필요 |
| 캐릭터·이동·입력 | 15% | 60% | PC/터치 입력·활공 양팔 접촉·기류/발판 이동 연결; 동작 품질·실기기 보완 필요 |
| 활공·퍼즐·전투 | 25% | 15% | 활공·기류·두 발판 이동 경로 검증; 이후 물체 조작·첫 퍼즐 연결, 전투 미구현(아래 수치는 T03B-2b 시점 추정 유지) |
| 퀘스트·월드 콘텐츠·엔딩 | 15% | 0% | 완주 흐름 미구현 |
| 저장·메뉴·사용성 | 10% | 0% | 게임 저장과 정식 UX 미구현 |
| 최종 아트·음향·성능·공개 준비 | 10% | 0% | 원화와 기술 초안은 있으나 최종 품질 미통과 |

가중 합 34.75%를 약 35%로 반올림했다. 세부 단계마다 1%씩 올리지 않고 주요 플레이 기능·완주·품질 검증이 완료될 때 다시 추정한다. 아트는 계속 REVISE이며 기술 검사 통과가 최종 품질 통과를 뜻하지 않는다.


T03B-2b 기본 기력 이동 경로 완주를 확인해 추정을 갱신했다. 현재 첫 퍼즐 연결까지 저장했으며 베타 공개 준비로 우선순위를 전환했다. 베타 통합 플레이 후 진행률을 재산정한다. 사용자 최신 한도 보고는 5h7%이며 직접 조회 도구가 없어 현재 수치는 확인할 수 없다.
