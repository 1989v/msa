상태: **독립 장면 구현·빌드·기하 검증 완료 / 최종 원화 품질 판정 전** · 2026-09-10

## 제작 범위

월드 원화의 밝은 석회암, 굽은 길, 초원, 원형 바람 유적, 바다와 높이가 다른
섬의 구도를 독창적인 Three.js 기하로 제작했다. 연속 표면을 가진 주 절벽과
8개 배경 섬, 층리와 수직 침식 음영, 초원과 181개 샘플의 연속 경로,
줄눈이 있는 대형 원형 유적과 매달린 황동 장치, 황토색 바람천을 포함한다.
전경 풀·꽃·돌·관목은 인스턴싱했고 하늘·바다도 실제 장면의 셰이더/기하다.
원화를 배경 이미지로 덮거나 다른 게임의 소스·문서·아트를 참고하지 않았다.

T01A 모델의 기술 결과와 소스는 읽었으나 이 장면은 새 기하를 사용한다.
외부 에셋·런타임 CDN·신규 설치·유료 도구는 없다. 고정 seed 17391.
설치된 Three.js 0.183.2 / esbuild 0.27.7 버전을 빌드에서 확인한다.
이번 작업에서는 창작 에이전트 크레딧 부족이 발생하지 않았다.

## 재현 및 검증

레포 루트에서:

```sh

python3 -m http.server 8768 --bind 127.0.0.1 --directory docs/specs/2026-09-10-skybound
```

`http://127.0.0.1:8768/implementation/t01b/index.html`에서 드래그/줌/처음 시점.
장면 렌더 2회 후에만 `window.__SKYBOUND_VIEWER__.ready`가 true가 된다.
브라우저 검증 결과와 세 화면비 캡처는 루트 검증 담당자가 추가한다.

terrainIslands: 9 / pathSamples: 181 / externalAssets: 0

실측 triangle 통계는 환경 기하만 포함한다. 하늘·구름·바다와 그림자 패스는
별도이며 실제 drawCalls/renderTriangles는 브라우저 hook에 기록한다.
테스트는 재생성 결정성, 정점/법선/인스턴스 유한 값, 인덱스 범위,
절벽 외향·초원 상향 법선, 경로 접지/경사, 렌더러 색 토큰 보존을 검사했다.
초기 번들 alias의 addons 경로 문제와 절벽 winding을 수정한 뒤 통과했다.

## 첫 실제 캡처에 따른 집중 수정

첫 데스크톱 캡처에서 절벽이 균일한 기둥, 식생이 촘촘한 반복 소품,
구름이 파란 납작한 덩어리로 읽히는 것을 확인했다. 기술 렌더 성공을 아트
완료로 보지 않고 다음을 변경했다.

- 주 지형의 높이를 세 번 상승하는 완만한 단차로 재작성했다. 섬 외곽에
  크고 작은 불규칙 굴곡을 주고 하단을 강하게 좁혔다. 절벽 중간 ledge와
  수직 침식, 전경의 노출된 돌 어깨, 석재 grain/퇴적선 셰이더를 추가했다.
- 바위·풀·꽃·관목을 군집에만 배치하고 나무를 23→7그루로 줄였다.
  전체 환경 인스턴스는 15,260→4,352로 감소해 열린 초원이 남도록 했다.
- 배경 큰 섬을 더 멀리 옮겨 중경 유적의 위계를 높이고 카메라를 낮췄다.
- 별도 pale horizon 토큰, 파란 상부 하늘, 밝은 emissive 구름과 덜 납작한
  구름 실루엣, 바다의 거리별 안개를 넣고 물결의 규칙적인 대비를 낮췄다.

단차를 22m 폭으로 완만하게 연결해 기존 경사 계약을 유지했다(법선 y >
0.9, 경로 |dy/dz| < 0.4). 접지 오차 허용치도 그대로다. 절벽 측면의
급격한 ledge와 달리 실제 길이 있는 상부는 완만하다. 이는 아트 지형
검사이며 후속 캐릭터의 충돌 구현을 대신하지 않는다.
수정 뒤 동일 빌드 성공 및 테스트 5/5 통과. 새 캡처 판정은 별도 기록한다.

## 남은 품질 차이와 T01C

- 연속 절벽에는 층리와 침식 음영이 있지만 원화의 깊은 균열, 오버행,
  천연 아치·동굴, 여러 갈래 능선과 돌별 퇴적 단면은 부족하다.
- 재질은 PBR·vertex color 중심이다. 원화 수준의 석재/풀 텍스처 아틀라스,
  미세 normal, 접촉 AO, 식생 LOD는 없다. 월드 확장 전 이 축을 보완해야 한다.
- 바다는 절차적 색/잔물결이고 실제 수심·해안 포말·굴절을 구현하지 않았다.
  구름은 구체 군집이며 볼륨 조명/바람 애니메이션이 없다.
- 옷감은 고정된 곡면이다. 캐릭터·도구·충돌·게임 이동은 T01B 범위 밖이다.
  길의 기하 접지는 검사했으나 플레이어 이동 가능성 검증으로 보지 않는다.
- 배경 섬은 경관용이다. 월드 지도·실제 이동 경계는 후속 구현에서 구분한다.
- T01C는 세 화면비 구도/줌/궤도 한계, WebGL 실패·복구 안내, 실제 모바일
  터치와 해상도·성능 기준선을 검증한다. 현 DPR 상한은 1.6이다.

**원화 품질 통과를 선언하지 않는다.** 이 장면의 캡처와 원화 비교에서
남은 차이를 평가하고, 임시 블록 수준으로 판단되면 월드 확장을 보류한다.
