# T02B-4a · 제자리 걷기 / 달리기 클립 진단

2026-09-11. 자체 제작 나루 리그를 사용한 기술 검증용 초안이다.
다른 게임·외부 모션 데이터를 사용하지 않았으며 모델·atlas는 수정하지 않았다.
**이 문서는 아트 PASS 판정이 아니다.**

## 구현

| 클립 | 주기 | 발 앞뒤 진폭 | 회수 구간 발 들림 | 트랙 |
|---|---:|---:|---:|---:|
| walk | 1.12초 | 0.17m | 0.075m | 16개 |
| run | 0.68초 | 0.26m | 0.165m | 16개 |

각 주기는 64구간의 quaternion 키프레임과 골반 위치 트랙으로 구성한다.
발목 목표와 기존 허벅지·정강이 길이를 두 관절 평면식으로 풀고 발바닥을
수평으로 유지한다. A포즈 팔을 몸쪽으로 내리고 반대 다리와 교대하여 흔든다.
상체 반회전과 망토 지연은 작은 주기 함수이며 물리 시뮬레이션은 아니다.

최상위 root는 이동하지 않고 골반은 Y축으로만 진동한다. 클립을 정지하면
AnimationMixer가 원래 위치와 A포즈를 복구한다. viewer는 원본 clips와
walk/run을 합쳐 GLB export 후 loader로 재로딩한 clip만 재생한다.

## 로컬 실행 증거

`node --test .../tests/model.test.mjs .../tests/motion.test.mjs`:
**tests 10, pass 10, fail 0**. 기존 모델 검사 6개와 동작 검사 4개를 함께 통과했다.
빌드 출력: `Built character/viewer.bundle.js`.

새 검사는 유한 값·정규화 quaternion·주기 끝점 일치, 수평 root 이동 없음,
두 LOD의 실제 스킨 발바닥 정점, 좌우 교대, 반대 팔 전진, 정지 복귀를 확인한다.
발 검사는 키프레임 사이를 포함한 96시점을 각 LOD·클립에서 샘플링한다.

브라우저 측면 캡처에서 발목의 붕대와 부츠가 분리되는 문제가 추가 발견됐다.
발바닥 높이는 정상이었으므로 기존 지면 접촉 검사로는 발견하지 못했다.
기존 rigid shin/foot 가중치를 부츠와 붕대에 공통으로 적용하는 높이 기반
가중치로 수정했다. Y=0.11–0.15m에서 foot→shin으로 전환하여 커프와 붕대의
25mm 겹침 구간이 같은 본을 따르게 했다. 정점·삼각형·본 수는 변경하지 않았다.

회귀 검사는 두 LOD·두 클립에서 64개의 키프레임 사이 시점마다 하단 붕대 링의
실제 변형 정점과 부츠의 실제 삼각형 간 최단거리를 계산한다. bind 상태의
소재 두께/간격보다 2mm 넘게 벌어지면 실패한다. 이전 rigid weights에서
17.5mm 분리 사례를 재현했고, 수정 후 전체 10개 검사가 통과했다.

추가 192시점 측정 결과는 두 LOD에서 같았다. 단위는 미터다.

| 클립 | 최소 발바닥 Y | 지지 발의 최대 최소 Y | 회수 발의 최대 최소 Y |
|---|---:|---:|---:|
| walk | 0.002947 | 0.003000 | 0.077887 |
| run | 0.002864 | 0.002999 | 0.167734 |

테스트 허용선은 지면 관통 4mm 이내, 지지 발 높이 25mm 미만이다.
현재 샘플에서는 지면 관통이 관찰되지 않았다. 이는 연속 시간 전 구간에 대한
수학적 증명이나 cloth 충돌 검사가 아니다.

## 남은 검증 / 범위

- 브라우저 GLB 재로딩·선택/정지/포즈/초기화 검사는 root의 별도 보고서로 기록한다.
- run은 짧은 주기·큰 회수 동작의 지지 접촉을 우선한 초안이다. 양발이 동시에
  뜨는 비행 구간, 발뒤꿈치→발가락 굴림과 지형 적응은 아직 구현하지 않았다.
- 월드 속도와 보폭을 맞추는 이동 연결, 전환 블렌딩, 점프, 정지 이동은 다음 단위다.
- 손/가방/망토/튜닉의 동작 중 관통과 장시간 관찰의 자연스러움은 미검증이다.
- 게임 입력, 충돌, 실제 플레이 카메라 연결은 포함하지 않는다.
