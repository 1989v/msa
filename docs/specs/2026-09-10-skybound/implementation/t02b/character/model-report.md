# 나루 모델 · T02B-3 제작 원본

원본은 `src/model.mjs`와 `src/atlas.mjs`다. 캐릭터 원화를 직접 시각 확인한 뒤 이 작업에서
단면 loft/곡면/뼈대/UV를 작성했다. 다른 게임의 모델·코드·이미지를 참조하거나 가져오지 않았다.
외부 모델, 이미지 생성 API, 유료 도구 또는 추가 라이브러리를 사용하지 않았다.

## 제작 계약

- Y-up, +Z 전면, 발바닥 Y=0, 높이 1.681m. 성인 약 7.5등신을 출발 비례로 삼았다.
- LOD0: 14,340 triangles / 8,752 vertices. LOD1: 4,654 triangles / 3,252 vertices.
- 단일 SkinnedMesh / 단일 1K basecolor atlas / 19 bones. 두 LOD는 같은 bone 이름과 클립 계약이다.
- 원화 표식: 짧은 검은 머리, 황토 망토, 남색 탐험복, 크림 붕대, 가죽 부츠, 지도 사첼.
- 머리는 턱·볼·이마 단면, 귀/코/입/눈/눈썹, 비대칭으로 갈라진 머리 락을 별도 조형했다.
- 몸통은 허리에서 좁아지는 재단, 소매·팔꿈치·붕대·손·손가락, 바지·정강이·부츠를 구성한다.
- 망토는 비대칭 아래단, 실제 두께, 주름, 접힌 목깃과 브로치를 갖는다.
- 사첼은 덮개/잠금 스트랩/버클과 말린 지도, 몸통 앞뒤를 잇는 가죽 스트랩을 갖는다.
- Canvas 2D의 `MATERIAL_PALETTE`가 소재 색 원장이다. 천 직조, 붕대 사선, 가죽 스티치,
  지도 등고선과 망토 나선은 직접 그린 픽셀 패턴이다. 입력 texture는 sRGB / flipY=false를 요구한다.

## Rig

`hips → spine → chest → neck → head`, 좌우 `upperArm → forearm → hand`,
좌우 `thigh → shin → foot`, `chest → capeUpper → capeLower`.
접미사는 `_L`, `_R`이며 L은 모델의 +X 쪽이다. 팔은 낮은 A-pose로 내려간다.
팔꿈치/무릎/몸통/망토에는 혼합 skinWeight를 사용한다.

`idle`은 3초 호흡/시선/망토 미세 움직임이고 `rig-inspection`은 3초 팔꿈치·무릎·망토 검사다.
둘 다 시작/종료가 bind rotation으로 돌아온다. 걷기·점프·착지와 이동 연결은 T02B-4다.

## 검수 범위

이 문서는 제작 및 CPU 검증 기록이다. 표준 GLTFExporter → GLTFLoader 실제 왕복과
브라우저 렌더/앞뒤측면 캡처 결과는 별도 viewer 검증 기록을 따른다.
원화의 회화적 얼굴과 직물 마감에 도달했다고 주장하지 않는다. 유기적 얼굴 곡면, 관절 이음새,
망토/팔 간섭과 실제 게임 카메라의 식별성은 실제 캡처로 판정해야 한다.
천 시뮬레이션, 손가락 개별 rig, 얼굴 표정 rig, normal/roughness map은 이 원본에 없다.
