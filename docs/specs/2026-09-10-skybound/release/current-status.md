## 완료 판정에 남은 항목

원화 수준의 캐릭터/소품 아트 최종 마감, 실제 청취와 발 접지 감각, 실기기의 성능·장시간 메모리·접근성, 사람이 플레이한 완주 시간은 미측정 또는 미완료다. PC의 모바일 에뮬레이션 결과를 실기기 지원 완료라고 하지 않는다. 물체 결합·탈것·등반·되감기는 PRD §10의 후속 후보이며 현재 기능으로 표현하지 않는다.
