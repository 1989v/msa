# T04A-1 물체 조작 순수 규칙 · 2026-09-13

사전 등록된 돌/프리즘 하나의 선택·집기·이동·90도 회전·놓기 상태를 구현했다. 확정 배치/운반 pose/배치 예고를 분리하며 실패한 배치는 확정하지 않는다. grab/drop은 현재 사거리·시선·플레이어·물체/벽 범위를 다시 검사한다.

**tests7 / pass7 / fail0**. 허용 목록과 값 검증, 오래된 선택/사거리/벽, 단일 소유권, AABB 접촉 경계, 얇은 벽을 가로지르는 운반, 회전 중 모서리 범위, 현재 frame의 새 벽으로 인한 drop 거부, pause/취소/reset, 예외 원자성과 입력 불변성을 확인했다.

실제 slab/AABB 계산을 사용하며 외부 LOS 콜백만 흉내 내어 통과시킨 검사가 아니다. 빌드 불필요한 독립 ES module이며 기존 렌더/이동 코어는 변경하지 않았다. 이번 단계에는 브라우저 물체 조작 검증이 없다.

## 남은 경계

- 회전 경로는 보수적 범위이므로 가능한 회전을 거부할 수 있다. 정밀 OBB/일반 물리가 아니다.
- cancel/reset은 마지막 확정/초기 배치로 복구하는 재배치다. 플레이어가 그 위치에 들어섰다면 겹칠 수 있어 후속 연결에서 안전 위치 해결 후 재개해야 한다.
- committedSnapshot은 운반 상태를 제외하지만 게임 저장 스키마가 아니다. 미완료 유적 초기화와 완료 받침 복원은 저장/퍼즐 계층의 후속 작업이다.
- 다음 T04A-2a는 실제 프리즘·선택/운반 표시와 입력 연결. 지면 지지·복구 안전성·PC/터치 조작을 작은 단위로 검증한다.
