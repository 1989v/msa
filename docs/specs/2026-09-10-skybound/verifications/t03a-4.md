# T03A-4 활공 손 접촉 · 2026-09-12

횡봉을 실제 팔 길이에 맞춰 낮추고, 실시간 뼈대의 두 관절 길이로 양팔을 계산한다. 손바닥 중심을 횡봉의 공통 목표점에 맞춘다. mixer 평가 전 이전 보정을 복원하고 활공 중에만 재적용해 접기/초기화 뒤 자세가 남지 않게 했다. GLB 재생성은 없다.

## 직접 검증

- traversal 전체 단위 tests13 / pass13 / fail0.
- 실제 원본 양LOD·3yaw·5phase의 변형 손바닥 정점 평균과 목표점 오차5mm 미만, 원래 quaternion 복원 검사 포함.
- build: Built traversal/viewer.bundle.js.
- `check-glider.mjs 9403 <traversal URL>`: 최종 실행 passed19 / failed0 / errors[].
- 실제 로드 GLB에서 네 시점의 양손 접점<3cm, 접기·reset 시 보정 해제, Space 및 터치 점프→돛 전개 확인.
- [JSON](t03a-4-browser.json), [PC](t03a-4-flight.png), [터치](t03a-4-touch.png).

첫 브라우저 실행에서 터치 재누름 검사가 실패했다. 제품 소스 변경 없이 첫 터치/최종 상태 로그를 추가한 재실행은 통과했다. 원인은 확정하지 않았다. 소프트웨어 렌더링과 짧은 공중 시간의 타이밍 가능성이 있으며, 실제 기기·반복 입력에서 재확인한다. 한 번의 성공을 안정성 검증 완료로 확대하지 않는다.

## 시각 검수

화면에서 양손이 횡봉에 닿는 것을 확인했다. 손가락의 감싸기, 전용 하체 자세, 옷 관통, 천 형태·바람 애니메이션은 미완료이며 최종 아트 REVISE 유지. 모바일 좁은 시야에서 날개 끝 일부는 화면 밖이다. 기류와 공중 필수 경로는 다음 T03B에서 구현한다.
