# T01C · 독립 검증

실행 환경: Node 22 / Three.js 0.183.2 / esbuild 0.27.7,
프로젝트 전용 headless Chrome software WebGL. 실기기 성능 측정은 아니다.

```sh
node docs/specs/2026-09-10-skybound/implementation/t01b/build.mjs
node --test docs/specs/2026-09-10-skybound/implementation/t01b/tests/*.test.mjs
node docs/specs/2026-09-10-skybound/verifications/check-camera.mjs 9403 http://127.0.0.1:8768/implementation/t01b/index.html
```

결과: **빌드 성공 / 테스트 9 pass, 0 fail / 브라우저 행동 12 pass, 0 fail**.
전용 Chrome은 `scripts/cdp-chrome.sh start skybound-prop --gl`로 기동했다.

확인: 휠 줌 범위, 드래그 회전 범위, 초기 카메라 복원, 모션 감소 시 물결 정지,
visibility 이벤트의 렌더 중단/재개, 터치 DPR 1.5 상한, 실제 WEBGL_lose_context
손실/복구, 초기 WebGL 생성 실패 시 재시도 버튼. visibility는 합성 이벤트로
검사했으며 실제 모바일/장시간 발열 검증을 대체하지 않는다.

1280×900 / 390×844 / 844×390에서 실제 canvas 크기·sceneReady 확인,
런타임 오류 0, 가로 넘침 없음. 세로 화면에서는 카메라 거리를 조절해
유적과 절벽이 함께 보이는 구도를 유지한다. [원시 행동 결과](t01c-behavior.json),
[화면비 결과](t01c-browser.json), [세로 캡처](t01c-portrait.png)를 보존했다.

중간 캡처의 로딩 시간 초과는 로컬 HTTP 서버가 종료된 상태였기 때문이다.
HTTP 연결 거부를 확인하고 서버 재기동 후 통과했다. 장면 오류로 은폐하거나
기준 시간만 늘리지 않았다. 서버 종료 후에는 먼저 보고서의 서버 명령을 실행한다.

T01C 기술 검증 완료. 최종 원화 품질·게임 카메라 충돌·실기기 성능은 미검증이다.
