# T03B-2a 첫 공중 착지대 · 2026-09-12

기류 오른쪽 (8,30), 중앙 초원 높이+5m에 4m 사각 착지대 하나를 추가했다. 실제 렌더 상판 정점을 충돌 판정에 사용한다. 선택 terrain.supportHeightAt(x,z,previousFeetY)는 발 아래 상판만 지지면 후보로 선택한다. 기본 heightAt은 초원·체크포인트 계약을 유지한다.

## 직접 검증

- traversal19 + 기존 이동/활공 통합18 + 순수 활공8: **tests45 / pass45 / fail0**.
- traversal build: **Built traversal/viewer.bundle.js**.
- `check-platform.mjs 9403 <traversal URL>`: **passed10 / failed0 / errors[]**.
- 실제 초원에서 아래 통행 → 초기화 → 기류 진입/전개 → 발판 위 고도 확보 → 수평 활공 → 착지, 남은 기력>0·리스폰0 확인.
- 실제 발판 위 캐릭터 발 위치 일치, 돛 접힘, 착지 기록, 가장자리 추락과 초기화 재시도 확인.
- 단위 검사에서 위로 통과/내려와 착지, 지지 유지, 물 리스폰 후 진행 보존 확인.
- [브라우저 JSON](t03b-2a-browser.json), [착지 화면](t03b-2a-landing.png).

상판은 위에서만 착지하는 기술 발판이며 측면·밑면 충돌은 없다. 아직 캡슐 충돌이나 실제 석조 구조의 완전한 충돌체가 아니다. 도달 기록 firstAerialLanding은 리스폰에서 보존하고 전체 reset에서 초기화한다. 발판을 자동 체크포인트로 설정하지 않는다. HUD의 terrainHeight 진단 값은 기본 초원 높이이며 실제 지지면은 snapshot 발 위치로 확인했다.
