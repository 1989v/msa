# T02C-2 터치 입력 검증 · 2026-09-11

실제 CDP touchStart/Move/End/Cancel을 사용했다. 동시 이동·시야, 시야 손가락 해제 후 이동 유지, cancel, 달리기 누르기/떼기, 점프와 blur 전체 해제를 확인했다. 세로390×844·가로844×390에서 44px 이상 조작부가 화면 안에 있고 수평 overflow가 없다. JSON 및 두 방향 PNG를 같은 접두사로 저장했다.

초기 검사 실패 원인 두 가지는 QA 코드였다: 이동 위치만 기다리면 시야 이벤트 처리 전에 판정했고, touchEnd 인자에 해제할 시야 대신 이동 손가락을 넣었다. 실제 로그로 확인한 뒤 위치와 yaw 변화 모두 기다리고 해제 ID를 수정했다. 제품 코드를 바꿔 검사를 통과시키지 않았다.

실제 모바일 기기의 성능·발열·브라우저별 호환성은 미검증이다. 소프트웨어 WebGL 기능 검사이며 FPS 통과를 의미하지 않는다. 최종 아트, 카메라·사물 충돌은 미완료. 다음 T03A-1은 순수 활공·기력·기류 규칙부터 작은 단위로 진행한다.
