# R4 독립 구현 리뷰

2026-10-05. Fresh-context `/root/review_duel_r4`가 R4 명세·게임 diff·관련 기준을 읽고 정적으로 검토했다. 구현 이력을 전달하지 않았으며 파일 수정·테스트·브라우저 실행은 하지 않았다. 통합 검증은 구현 담당자가 수행한다.

## 최종 정적 판정: SHIP

20단계/군량/기본 습격 등급·연구 구분, 방어력/관통·병과 역할, 강화/연구/카트/환급 잠금, 공개 정보만 쓰는 AI, 실제 경로 끝까지 이동, projectile impact·대상별 광역·전장 격리, 공유 stats와 입력 상태를 검토했다. 신규 투명9열×4행 파츠 로딩·관절 구성·거리 기반 gait·facing·pause/reduced-motion도 확인했다.

부모가 유지한 P2 발견4건은 모두 수정 후 해당 부분만 재검토하여 종료했다.

1. 창병 타격에서 이동한 적의 실제 사거리/직선 축/폭/앞 방향을 다시 확인하지 않던 문제: impact 시 재확인, 최초 대상 최대3명 유지.
2. 강화 병사를 이동할 때 미리보기 사거리가 Lv1이던 문제: 이동 대상의 실제 레벨을 사용.
3. 창병 role에 고정 ‘관통12’가 남아 강화 수치와 충돌하던 문제: 레벨별 숫자를 공통 stats로 일원화.
4. 작은 캐릭터의 보폭과 phase 계산이 달라 발이 미끄러지던 문제: `footPose`가 실제 PATH의 stance 접촉점을 고정하고, renderer가 몸 이동/facing을 상쇄. swing·몸 높이 비례 보폭·pause 확인.

별도 부모 시각 검토에서 기존 PNG mask의 비어 있는 허벅지 연결부를 기각했다. 새 분리 파츠 원화 적용 후 연결부/발 비율을 수정한 contact sheet를 확인했다. 최종 발 접촉 수정 후 실제 WebM에서 추출한8프레임(6.000~6.469초)의 `r4-actual-footplant-filmstrip.png`, 실제 경로 장면1/3, 강화Lv3 이동 사거리,7종 공격 정보와 좁은 화면을 확인했다. 연결된 다리·교대 발걸음·코너 이동·실제 레벨 정보가 유지되어 부모 시각 검토도 완료했다. 부모는 게임 테스트를 재실행하지 않았다.

정적 SHIP은 실제 모션 품질과 게임 밸런스 확정을 대신하지 않는다. [통합 검증 기록](r4-final-verification.md)을 함께 참조한다.
