## 범위와 진입

- 신규 경로 `portal-fe/public/games/duel-defense/`, 정적 ES modules 게임. 기존 twin-banner-defense는 변경하지 않는다.
- 직접 실행 가능한 index.html과 로컬 실행 도구/README. 현 단계 카탈로그·서버·DB·배포 변경 없음.
- 이름: 대전 디펜스. 모드는 명시적으로 'AI 대전 · 5스테이지'. 사람 대전으로 오인하지 않는다.
- 제목 화면 → 초기 배치 → 단계 1~5 → 패배/승리/동시패배 또는 5단계 검증 결과 → 재시작.
- 독립된 두 성문 각 20 체력. 두 전장의 논리 크기/경로 길이/규칙 동일, 내 전장을 화면에서 더 크게 표시 가능.

## 전장과 원화

양측 5×5, 각 25칸. 길은 타워 영역 바깥에서 시작해 외곽을 돌아 각자의 성문에 도달하는 열린 경로다. 타워는 길 밖 칸에 고정하며 상대 전장 적을 쏘지 않는다. 각 유닛의 투구~발 높이는 화면 한 칸 높이의 약 45~55% 목표, 병기는 한 칸 내에 들어가야 한다. 렌더링은 devicePixelRatio를 고려해 선명하게 한다. 생성 시안 `planning/visuals/02-gameplay-v2.png`의 화풍과 장부·편성 UI를 참고한다. UI는 실제 DOM 텍스트, 게임은 실제 시뮬레이션과 sprite animation이며 통이미지에 버튼만 얹지 않는다.

`twin-banner-defense/assets/`의 infantry/support/siege/enemies 아틀라스와 추출·앵커 방식을 참고하고 필요한 파일을 신규 게임에 복사한다. 원본 파일은 수정하지 않는다. 여섯 수비 병종(궁수/창병/포수/군악수/화차/총통), 네 공격 병종(척후/방패/중갑/군악), 정예 척후·대장군. 공격 군악은 기존 군악수 원화를 적 팀표식·이동 상태와 함께 쓴다. 적 대장군은 기존 boss 원화를 사용한다. 새 병종 원화·임의 도형 캐릭터 대체는 범위 밖이다.

루트 DESIGN.md와 이 폴더 DESIGN.md의 토큰을 사용한다. 신규 색상 hex를 임의로 추가하지 않는다. 최소 44px 입력, reduced motion, canvas 상태의 DOM 대체 요약. 데스크탑 가로 화면 우선, 좁은 화면에서도 컨트롤과 내 배치칸에 접근 가능하게 한다.

## 경제·입력

초기 배치 전용 160 군량을 양측에 지급한다. 사용자는 수비 6종에서 지정 구매/초기 배치하며 출진 준비 버튼으로 완료한다. 초기 미사용 군량은 소멸하고 stage1 지급 100으로 시작한다. 단계 지급은 100/120/140/160/180. 이월은 다음 지급액 20%까지만 허용, 소멸액 표시. 처치 보상·이자 없음.

수비 비용: 궁수40, 창병50, 포수70, 군악수60, 화차120, 총통140. 공격 비용: 척후10, 방패20, 중갑40, 군악20. 단계별 공격 카트와 신규 타워가 하나의 군량을 소비한다. 카트 수량을 줄이면 비용 반환, 초과 구매/25칸 초과 배치/비정상 수량은 거절·무차감. 그 준비에 산 타워 취소는 전액 반환, 이전 단계 타워 철거는 환급 없음. 준비 중 빈 칸 이동 가능. 강화·합성·랜덤 소환 없음.

준비 20초, 출진 확정은 유효 카트 잠금, AI 계획과 함께 동시에 적용. 시간 종료는 현재 카트 자동 확정, 빈 카트도 허용. 전투 중 구매/이동/철거/편성 변경 불가. 일시정지와 재시작 지원, 탭 비활성 시간으로 타이머가 갑자기 흐르지 않도록 고정 스텝/시간상한 처리.

## 단계별 공격과 조합

상대가 산 부대가 내 전장에, 내가 산 부대가 상대 전장에 들어간다. 양측 동일한 기본 습격 척후2/3/4/5/6을 추가한다. 기본 습격은 조합에 포함하지 않는다. 유료 일반 부대 최대24명, 선두 방패→중갑→군악→척후 순서로 간격을 두고 출현하고 특수 부대는 마지막. 군악 이동 버프는 비중첩이다.

선택 가능한 공격 조합은 2개:
- 척후 연격: 척후4 → 척후4 → 방패3. 세 연속 단계 성공 시 정예 척후 3명을 같은 출진에 추가.
- 대장군 진군: 척후4 → 방패3 → 중갑2 → 중갑1+군악2 → 중갑2+방패2. 다섯 연속 단계 성공 시 대장군1, 성문 피해6을 같은 출진에 추가.

현재 요구 편성 이상이면 확정 출진 때 한 칸만 적립한다. 카트 변경/기본 습격/초과 부대는 다른 칸을 추가로 채우지 않는다. 요구 불충족 또는 조합 전환은 진행0, 초기화 이유 표시. 실패 출진을 첫 칸으로 소급 적립하지 않는다. 완성 보상은 한번, 다음 준비부터 다시 첫 칸. 체력 누수 자체는 진행 초기화가 아니며 체력0이면 즉시 경기 종료해 준비된 공격이 경기 후 피해를 주지 않는다.

## 전투와 AI

타워는 가까운 성문 도달 위험 표적부터 자동 공격. 활 단일/창 직선 관통/포수 중갑 관통/화차 범위 일제/총통 강한 단일·좁은 폭발/군악 주변 공격속도 비중첩 지원을 구별한다. 관통 타워가 중갑·대장군 대응이 가능해야 한다. 고정 스텝 시뮬레이션과 공격 준비/발사/재장전 상태를 애니메이션에 연결한다. HP·피해·사거리·이동속도는 위 역할을 지키는 조정 가능한 data 파일 초안 값으로 구현하고 실제 플레이로 확인한다.

AI는 동일 예산·구매·조합·타워 규칙을 쓴다. 최소 수비를 세우고 3단계 또는 5단계 계획을 선택하는 결정적 전략을 제공한다. 모드/난도에 따라 공개 이전 상태로 대응하되 플레이어의 이번 비공개 카트를 읽지 않는다. 이전 정산 타워·체력·조합 진행만 상대에게 공개, 새 준비 편성은 출진 때 공개한다. AI 준비 타워를 플레이어가 미리 볼 수 없게 직전 스냅샷을 사용한다.

전투 최대30초, 살아남은 적은 제한 종료 때 누수 피해. 양측 같은 틱 피해를 합산 후 성문0 결과 결정, 같은 틱 둘 다0이면 무승부. 조기 승패가 없으면 5단계 종료에 '5스테이지 검증 종료'와 양측 체력/공격조합 결과를 보여준다. 20단계 전체 경기 승리처럼 표시하지 않는다.

## 수락 기준과 검증

1. 별도 게임이 로컬 주소에서 실행되고 실제 아틀라스·화풍을 사용한다. 5×5 두 배치장·독립 성문·작은 캐릭터 확인 스크린샷.
2. 초기배치→5단계→결과→재시작을 사용자가 DOM/canvas 입력으로 진행 가능.
3. 공용 경제와 초과 입력·반환·이월·전투 중 거절을 의미 있는 core tests로 확인.
4. 두 조합의 순서/부족/전환/완성1회/기본습격 제외를 tests로 확인.
5. 대장군5단계 출현·출진 전 수비 붕괴 패배·동시 사망을 확인. 필요하면 결정적인 테스트 시뮬레이션을 사용하되 런타임 편법과 일반 플레이를 구분한다.
6. AI 초기배치·일반 대전이 실제로 플레이 가능, console/page errors 없음, 데스크탑/좁은 화면 controls 스크린샷.
7. 적합한 Node tests, asset check, 실제 브라우저 E2E 결과를 `verifications/final-verification.md`에 명령/출력/스크린샷 경로로 기록. 최종 검증은 구현자가 한 번 통합 수행, 부모는 중복 실행하지 않는다.

온라인·매칭·랭킹·DB·운영 배포·카탈로그 추가·20스테이지·신규 영웅·7단계 조합은 후속 단계. 설계 확장 필요 시 부모에 보고하고 승인 범위 내 독립 작업은 계속한다.
