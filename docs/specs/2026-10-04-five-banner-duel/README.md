# 오군진 — 1:1 대전 타워디펜스 기획·시안

상태: **컨셉 검토용 초안 / 구현 미승인**. 2026-10-04.

한 줄: **내 성문을 지키며 다섯 번의 출진을 이어, 상대 성문을 무너뜨릴 진법을 완성한다.**

스타크래프트 개인 타워디펜스의 각자 수비장과, 뿌요뿌요처럼 축적되는 공격의 긴장감을 결합한다. 기존 쌍성 수비대의 한국 무장·병기 원화를 계승한다. 가칭 오군진은 다섯 단계 진법을 뜻하는 창작 명칭이다.

## 컨셉아트

![두 성채의 대결과 척후대·철갑 돌격대·대장군](planning/visuals/01-concept.png)

두 성문은 독립된 승패 목표다. 아래 병종 시트는 아트 검토용이며 실게임 HUD에 들어가지 않는다. 그림 속 다리와 진법 인장은 장식이며 실제 이동 경로·조합 규칙을 정의하지 않는다.

## 전투 화면 시안

![내 수비장·상대 관찰창·진법 장부·공격 편성](planning/visuals/02-gameplay.png)

시안은 준비 단계와 전투 관찰을 함께 보여준다. 생성 이미지의 격자·글자·경로·수치는 구현 계약이 아니다. 정확한 배치는 [DESIGN.md](DESIGN.md), 규칙은 [기획안](planning/game-plan.md)을 따른다.

## 검토할 핵심

- 스테이지 지급 군량을 수비와 공격에 분배하는 안을 기본 제안한다. 사용자의 자원 방식 답변 전까지 확정하지 않는다.
- 매 스테이지 실제로 보낸 부대가 진법 한 단계를 채운다. 5단계 동안 수비가 무너지면 준비한 큰 공격을 쓰지 못하고 패배한다.
- 상대의 진행 단계와 완성 결과는 보이되, 이번 스테이지 편성은 양측 확정 전까지 숨긴다.
- 작은 조합은 3단계, 큰 조합은 5단계. 7단계는 확장 후보다.
