# 요청 원문

1:1 대전 타워 디펜스 게임 개발

0. 기본적으로 스타크래프트 유즈맵의 개인 타워 디펜스 같은 형태
1. 스테이지별로 지정된 자원으로 타워를 생성한다
2. 또한 적 유닛은 상대방이 지정된 자원(스테이지별)에 맞게 조합해서 상태측으로 유닛을 보낸다
3. 뿌요뿌요의 콤보처럼 스테이지별로 특정 유닛조합을 이어서 보내면 특정 조합이 달성되면 강한 유닛이 나온다
4. 3번의 강한 유닛 조합이 나와서 상대를 공략하기까지 5스테이지정도 소모가 필요하다(강도에따라 다름)
5. 4번의 5스테이지가 쌓이기전에 내가 디펜스를 실패하면 지는 하이리스크 하이리턴 요소도 있다
6. 유닛 컨셉은 조선시대 타워 게임형태(이미 구축한 협동 타워디펜스 유닛 참고)

이거 기반으로 컨셉아트+시안+플래닝 먼저 진행해 봐
