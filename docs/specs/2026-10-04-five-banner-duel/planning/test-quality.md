# 후속 검증 계획

현재 단계는 문서·이미지 검토이며 게임 테스트를 실행한 단계가 아니다.

| 검증 층 | 핵심 시나리오 |
|---|---|
| Unit | 지급·이월 상한·비용, 초과 구매 무차감, 진법 순서·수량·연속성·전환 초기화 |
| Integration | stage별 편성 확정→군량 차감→한 칸 적립→특수 부대 1회 생성→상대 전장 배치 |
| Component | 양측 5×5(25칸)와 상대 관찰장, 별도 성문, 다음 진법 조건·부족분·초기화 이유, 전투 중 입력 제한 |
| E2E | 5스테이지 실제 진행 후 대장군 공격, 3/4단계 수비 붕괴로 먼저 패배, 양측 동시 사망 무승부 |
| Online 이후 | 편성 숨김, 확정 중복·지연·재접속, 동시 정산, 양측 결과 일치 |

## Critical path

매 단계 예산 내 편성 → 연속 진법 적립 → 이전 단계 생존 → 다섯 번째 확정 → 대장군 출현 → 이동로 수비에 피격 → 성문 피해 또는 제거. 어느 시점이든 내 성문 체력 0이면 경기 종료가 우선이다.

현재 단계 5칸을 한 번에 적립하는 경우, 기본 습격이 조합에 포함되는 경우, 준비 카트만으로 적립되는 경우, 진법 보상이 반복 생성되는 경우는 반드시 실패해야 한다.

## 첫 플레이에서 확인할 것

- 동일 초기 조건에서 수비 집중, 3단계 압박, 5단계 장기 준비를 비교한다. 승률을 미리 보장하지 않는다.
- 대장군 준비자가 3/4단계에 위험을 느끼는가? 수비를 최소화해도 무조건 살아남으면 위험 설계를 수정한다.
- 짧은 공격은 언제나 우세하거나 대장군은 언제나 우세하지 않은가?
- 관통 타워를 준비한 상대가 대장군을 막을 수 있는가?
- 초기 군량으로 시작 수비가 가능한가? 창병의 유효 칸과 군악수 지원 반경이 읽히는가?
- 진법 초기화 이유와 완성 스테이지를 플레이어가 즉시 설명할 수 있는가?
- 병종·성문·방향을 작은 화면에서 구별하고 두 전장의 피해를 혼동하지 않는가?

경기 로그에는 단계/지급/수비·공격 지출/편성/진법 단계/초기화 이유/누수 피해/승패 틱을 기록한다. 원화 품질 검토와 규칙 검증은 각각 근거를 남긴다.
