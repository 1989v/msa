# 대전 디펜스 — 아트·화면 기준 초안

## 현행 R2 화면 방향

사용자2026-10-05 피드백에 따라 상시 진법 장부·조합 선택·별도 초기 배치·25번호 패드를 제거한다. 정본은 [R2 변경 명세](iterations/02-direct-purchase.md)다. 기존 아래 P1 화면 계약과 이미지는 검토 이력이다.

상단에 양측 성문·단계·시간·**군량 한 잔액**, 중앙에 내5×5/상대 관찰장, 하단에 **수비/공격 탭·병과 카드·선택 정보·출진**. 수비 카드에서 내 타일까지 드래그하며 타일·사거리·반투명 유닛 미리보기. 선택 후 타일 클릭·44px 보조 배치 입력도 제공한다. 보조25칸은 요청할 때만 연다.

수비는 선택 병과의 단발 공격력·공격간격·사거리(칸), 군악수는 지원 효과를 보여준다. 공격은 비용·체력·이동속도(칸/초)·성문 피해를 보여준다. 비싼 대장군도 직접 구매하므로 조합/단계 해금 표시를 하지 않는다. 데이터 표를 여러 군데 반복해 단순화를 무너뜨리지 않는다. 드래그 범위 원은 실제 시뮬레이션 사거리에 맞추고 결과선택/유효칸 표식으로 색상 이외 신호도 제공한다.

상태: 제안. 루트 [DESIGN.md](../../../DESIGN.md)의 한국 전통 팔레트와 기존 [쌍성 수비대 기준](../2026-09-27-twin-banner-defense/DESIGN.md)을 우선 참조했다. 이번 이미지에 사용한 자연물의 색면은 일러스트 표현이다. 향후 UI 코드는 기존 토큰을 사용하며 새 hex를 임의로 넣지 않는다.

[실제 화면](verifications/shots/final-layout-1440.png)과 [검증](verifications/final-verification.md)을 참고한다. 짧은 viewport에서 canvas 타일이 작아져도44px 입력을 제공하는 별도5×5 배치 패드를 추가했다. 내 전장은 가용 너비·높이를 함께 제한하고 상대 관찰장은 약2/3배, 좁은 화면에서 패드를 전장 아래로 배치한다. 시안 장식을 그대로 복사하기보다 실제 경기 정보·입력을 우선했다.

## 시각 언어

제목은 익숙한 영어의 한글 발음 또는 쉬운 한국어를 사용한다. 낯선 한자 조합으로 시대 분위기를 강제하지 않는다. 사용자 확정 이름은 **대전 디펜스**다. 현행 컨셉아트는 `planning/visuals/01-concept-v2.png`이며 최초 이미지는 이력이다.

굵고 절제된 먹선, 한지·석재·목재·직물·청동, 2~3단 명암. 협동 게임의 승인된 인물 화풍을 직접 계승한다. 조선 군용 투구와 드림, 긴 포형 두정갑, 각궁·환도·장창, 목조 화차·낮은 총통을 쓴다. 전신 금장·중국 장수·일본 사무라이·서양 판금은 피한다. 한국 역사에서 영감을 얻은 게임이며 시대 고증작으로 표방하지 않는다.

청색 원형과 홍색 마름모는 진영 표식이다. 내가 좌측 청 진영, 상대가 우측 홍 진영으로 표시되는 개인 관점이다. 적색 자체를 적 판정의 유일한 기준으로 쓰지 않는다. 내가 보낸 부대는 상대 이동로에서 청 표식, 상대 부대는 내 이동로에서 홍 표식. 공격과 수비는 위치·이동·체력 표시로도 구별한다.

## 화면 배치 계약 제안

```text
┌─ 내 성문 16/20 ── 5 스테이지 · 준비 12초 ── 상대 성문 12/20 ┐
│        내 성문             │           상대 성문            │
│ ┌──── 독립 이동로 ──────┐ │ ┌──── 독립 이동로 ────┐       │
│ │   내 5×5 수비장       │ │ │ 상대 5×5 관찰장     │       │
│ └─ 입구 → 외곽 → 성문 ─┘ │ └─ 입구 → 외곽 → 성문 ┘       │
├─ 대장군 진군: ①척후 ✓ ②방패 ✓ ③중갑 ✓ ④군악 ✓ ⑤돌격 예정 ┤
│ 다음 조건: 중갑병 2 + 방패병 2 / 완료 보상: 대장군 1          │
├─ 군량 180 ── 수비 배치 / 공격 편성 ── 수량·총비용 ─ 출진 확정 ┤
└─ 수비 실패 시 패배 · 편성 변경과 준비 완료 상태               ┘
```

내 전장이 전투 영역 폭의 약 60%, 상대 관찰장이 약 40%. 관찰장은 실제 적에게 피해를 주는 별도 전장이며 장식용 미니맵이 아니다. 양측 논리 배치장·경로 길이·수비 조건은 같고 화면 배율만 다르다. 경로는 아래 외곽 입구에서 출발해 배치장을 감싸 성문에 도달하는 열린 경로다. 성문을 무한 반복해 도는 폐회로가 아니다.

사용자 수정(2026-10-04): 양측 배치장을 **5×5, 각 25칸**으로 확대하고 전장 안 캐릭터를 작게 표현한다. 원화의 등신을 바꾸기보다 카메라를 멀리 두고 배치장 대비 크기를 줄인다. 시안 목표는 병사 몸통 전체 높이(투구~발)가 한 타일 높이의 약 45~55%, 병기는 한 칸 폭의 약 70% 이하다. 수치는 부모 세션의 시각 제안이며 실제 읽힘을 보고 조정한다. 부대 편성 아이콘은 읽기 쉬운 크기를 유지한다. 더 높은 native 출력 해상도를 요청하되 생성 결과 픽셀 크기는 실제 파일을 확인해 기록한다.

준비 단계: 타워 배치와 공격 편성 탭, 상시 진법 장부, 이번 비용·잔액·부족분·완성 예상. 상대 전장은 직전 스테이지 스냅샷임을 표시한다.

전투 단계: 구매 UI는 상태 보기로 전환, 내가 보낸 부대·상대 보낸 부대의 이동과 성문 위험 표시, 이번 진법 적립 결과. 새 구매 입력은 비활성 사유를 보여준다.

내 입력 영역만 확대하므로 가로 데스크탑을 우선 제안한다. 모바일은 같은 논리 전장을 내 전장 중심으로 보여주고 상대 관찰을 전환하는 안이 후보다. 모바일 구체 시안·터치 검증은 다음 단계다.

## 토큰·활자·상태

패널은 roof/ink, 글자는 paper, 구조는 structure, 진영은 player/ally를 기존 게임 토큰에서 가져온다. UI 본문은 고운돋움/Pretendard, 제목은 명조, 숫자는 tabular. 기능 문구는 런타임 텍스트로 만들며 생성 이미지의 한글을 실사용 UI로 잘라 쓰지 않는다.

활성 행동은 출진 확정 하나. 비용 부족에는 부족 군량을 표기한다. 진법은 완료/현재/다음/초기화를 인장 모양+번호+문구로 구별한다. 준비 진행은 현재 스테이지 완료로 오해하지 않도록 '예정'을 붙인다. 조합 초기화 시 이유와 다음 조건을 표시한다. 최소 44 CSS px 입력 영역, reduced-motion 지원은 실제 구현에서 검증한다.

## 이미지 검토 한계

01 컨셉은 성채 대결·병종 실루엣의 검토다. 사선 원근과 양측 다리는 키아트 연출이다.
02 최초 시안은 화면 위계·장부·군량 배분의 검토 이력이다. 현행 목표는 5×5와 작은 캐릭터다. 경로 연속성, 한글 문구, 터치 크기, 명암 대비, 실제 전투 성능은 생성 이미지로 검증할 수 없다. 생성 결과와 본 문서가 다르면 본 문서의 규칙을 따른다.
