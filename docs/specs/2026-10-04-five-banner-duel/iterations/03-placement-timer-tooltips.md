결과: 구현·검증 완료. [통합 검증](../verifications/r3-final-verification.md), [독립 리뷰 SHIP](../verifications/r3-review.md). Core13개 통과, 실제45초 자동 출진·다음30초·클릭/터치·6개 화면 확인. 최종 빨간 숫자는 `r3-final-timer-*` 화면이 정본이다.

## 확정 동작

- 병과 카드를 클릭하면 배치 모드가 켜지고 병사가 커서를 따라간다. 내 빈 타일을 클릭하면 한 번 구매·배치하고 배치 모드를 끝낸다. 카드 클릭만으로 차감하지 않는다. 다른 카드를 클릭하면 병과를 교체한다.
- 범위 원과 유효 타일 미리보기, 기존 마우스/터치 드래그·배치된 병사 이동·44px 배치 도움을 유지한다. 드래그 후 click 이벤트가 재구매/재선택을 일으키지 않는다.
- 잘못된 타일 클릭은 무차감이며 다시 배치할 수 있다. Escape, 우클릭, 탭 변경, 도움말, 일시정지, 재시작, 전투 전환은 배치 미리보기를 정리한다. 컨트롤 클릭을 타일 배치로 오인하지 않는다.
- 준비 시간은 **1단계 45초, 이후 단계 30초**. 첫 플레이에 추가 시간을 준다는 부모 설계 선택이며, 사용자 최소 30초 요청을 만족한다. 도움말과 숫자 안내를 동기화한다. 숨김 탭·일시정지·도움말의 기존 시간 보존 규칙을 유지한다.
- 플레이 영역 우측 상단에 크고 선명한 빨간 남은 시간(초)과 **바로 시작** 버튼을 함께 배치한다. 기존 게임 색상 토큰을 사용하고 숫자 대비를 확보한다. 바로 시작과 자동 출진은 동일한 상태 전환을 사용한다. 하단의 중복 주 행동은 제거해 단순함을 유지한다. 좁은 화면에서도 두 요소에 접근 가능해야 한다.
- 병과 카드 hover/focus에서 툴팁을 표시하고 터치·키보드에서도 상세를 읽을 수 있게 한다. 공격력, 초당 연사 횟수와 공격 간격, 칸 단위 사거리, 실제 구현된 특성을 표시한다. native title만 사용하는 것은 불충분하다.
- 연사 속도는 기존 interval의 역수이며 밸런스를 바꾸지 않는다. 군악수는 공격하지 않으므로 연사 대신 주변 공격속도 +30%·비중첩 지원을 표시한다. 지원을 받으면 연사가 빨라지는 사실을 설명하되 기본 연사와 혼동하지 않는다.
- 특성은 실제 코드와 일치: 궁수 단일 표적, 창병 직선 관통·장갑 관통65%, 포수 장갑 관통85%, 화차 범위 공격(90 논리px), 총통 좁은 폭발(45 논리px)·장갑 관통85%, 군악수 지원. 범위는 화면 칸 단위로 환산한다. 공격군의 기존 체력·이동속도·성문 피해를 보존한다.

## 구현과 검증

기존 gpt-6.1-sol 구현자 한 명에게 게임 코드·관련 테스트·R3 검증 기록을 위임한다. 다른 기여자의 수정과 games 서브모듈 포인터를 보존한다. 부모는 설계 문서·보고·독립 리뷰 확인을 맡는다.

- Core: 첫45/이후30, 시간 만료 자동 출진, 조기 시작, 일시정지 보존. 기존 경제와 공격 테스트 유지.
- Browser: 클릭→커서 이동→유효 배치 한 번 차감, 잘못된 칸 무차감, 병과 교체/취소/전투 전환 cleanup, 기존 드래그와 터치 입력, 툴팁 hover/focus/터치 상세, 바로 시작.
- Desktop와 좁은 화면에서 타이머·버튼·툴팁 잘림 여부 확인. 실제 수치/특성을 원본 데이터와 대조한다. 스크린샷과 명령 결과를 R3 기록으로 제공한다.
- 구현 후 별도 fresh-context 정적 리뷰. 통합 검증은 구현자가 수행하고 부모/리뷰어는 반복 실행하지 않는다.
