# R2 — 단순 UI·드래그 배치·직접 유료 공격

2026-10-05 사용자 피드백에 따른 승인 구현 수정. 이 문서는 기존 P1의 조합/초기 배치/장부 UI 계약보다 우선한다. 온라인 범위는 추가하지 않는다.

결과: R2 구현·통합 검증 완료, [독립 리뷰 SHIP](../verifications/r2-review.md). 수비80+대장군160의 실제 공용군량 소비, 마우스·터치 드래그와 일반5단계 경기 확인. 밸런스 수치는 첫 플레이용 초안이다.

## 사용자 요청

1. 인터페이스를 단순하게 한다.
2. 병과별 드래그 드롭 배치, 공격범위·공격력을 식별 가능하게 한다.
3. 히든 커맨드는 보류. 공격 군사의 이동속도·체력을 표시하고, 수비·공격에 같은 돈을 사용해 수비를 아낀 만큼 비싼 공격 유닛으로 승부한다.

## 새 게임 흐름

- 제목 → 1스테이지 준비 → 출진/전투 → 다음 준비 → 5단계 결과. 별도 초기 배치 단계와 전용 초기 군량을 없앤다.
- 첫 단계 지급은 기존 초기160+1단계100을 합친 **260 군량**, 이후120/140/160/180. 양측 같은 예산. 잔액은 기존 다음 지급20% 상한 이월. 처치 보상 없음.
- 하나의 군량 잔액. 수비/공격의 별도 주머니나 따로 지급된 자원처럼 보이는 합계 표시를 만들지 않는다. 구매 개별 가격과 공격 카트 합계는 소비 안내로만 표시한다.
- 히든 조합·진법 선택/장부/요구 순서/단계 적립/보상 부대는 현재 게임·AI·도움말·결과에서 제외한다. 후속 아이디어로 문서 이력만 보존한다.
- 공격4종: 척후10(HP65,speed62), 방패20(125,52), 중갑40(220,46), **대장군160(850,42,성문 피해6)**. 모두 직접 구매 가능한 유료 부대. 대장군은 조합 보상이 아니며 무료 생성 불가. 공격 군악·정예는 R2 활성 상점에서 제외해 선택지를 줄인다.
- 양측 기본 습격과24명 한도·고정 순서·독립 성문·동시 사망·5단계 범위는 유지한다. 일반 paid 편성에 대장군을 포함하고 마지막 출현. 공격 카드 +/−로 카트 구매/반환, 거절은 무차감.
- AI는 같은 예산으로 최소 수비 확보/직접 공격 구매를 결정한다. 조합 계획 선택 UI 제거, 플레이어의 비공개 카트 정보 사용 금지.

## 단순 화면

상단: 내/상대 성문, 현재 단계·준비/전투 시간, 군량 한 잔액. 작은 게임 방법/일시정지/재시작/소리 행동은 묶거나 절제된 위치.
중앙: 내5×5와 상대 관찰장, 작은 기존 캐릭터·독립 이동로.
하단: **수비 / 공격 탭**, 병과 카드, 선택 병과의 간결한 상세, **출진** 하나. 장부를 제거해 전장 공간을 확보한다.
별도 번호25개 패드는 상시 표시하지 않고 **배치 도움** 등44px 버튼으로 여는 선택 보조 UI로 바꾼다. 드래그·타일 클릭의 범위를 늘리는 겹침 투명 버튼은 금지. 접근성 입력 대안과 실제 canvas pointer mapping을 유지한다.

## 수비 드래그·정보

- 병과 카드에서 내 빈 타일까지 Pointer Events 기반 드래그(마우스/터치). 드래그 portrait·유효 칸 강조·해당 칸 사거리 원 미리보기.
- 드롭이 유효할 때만 구매/차감. 밖 드롭, 상대 전장, 이미 찬 칸, 자원 부족, 포인터 취소, 전투 전환 중 드롭은 무차감. 드래그 취소 후 ghost/range cleanup.
- 수비6종 유지. 카드에는 이름·가격, 선택/드래그 상세는 실제 단발 공격력·공격 간격·사거리(칸 단위)와 역할. 군악수는 공격력0 대신 '공격속도 +30% 지원'을 명확히 표시.
- 배치된 병사 선택 시 해당 병과·실제 사거리 원·공격력 상세. 같은 타입 중 누가 선택인지 바닥 표식. 이동은 기존 타일에 있는 유닛에서 빈 타일로 드래그하거나 선택 보조 방식 가능. 철거/취소는 선택 상세의 보조 행동.
- 선택 후 타일 클릭/44px 선택 보조·키보드 입력을 드래그 대안으로 제공한다. 화면 확대로 물리 칸을44px로 꾸며 실제 좌표 매핑을 깨지 않는다.

## 공격 정보

공격 카드에서 비용·체력·이동속도(실제 speed/GRID.cell을 '칸/초'로 표시)·성문 피해를 읽을 수 있어야 한다. 선택 상세에 장갑/역할을 추가할 수 있으나 장황한 표는 피한다. 수비 공격력과 공격 부대의 성문 피해를 같은 '공격력'으로 혼동하지 않는다. 대장군 구매 시160을 하나의 잔액에서 차감한다.

## 검증과 완료

- Core: 공용260 시작·다음 지급/이월·직접 대장군160 구매/반환·무료 보상 없음·부족 무차감·대장군상대 전장 출현·phase lock·AI 같은 예산·동시 패배/5단계 종료.
- Browser: 실제 pointer drag로 카드→빈칸 구매; invalid/outside/occupied/전투 중 drop 무차감; 선택/range overlay와 수치 정보 식별; 공격 대장군 구매/출진; 상시 장부/번호패드/AI 조합 UI 없음; keyboard/touch 대안44px·pause/help 보존.
- Desktop1440×900/1280×800/1200×1000와 좁은390×844/중간900px에서 전장/주요버튼 접근, clipping 없음. 수동 브라우저 입력을 기록하며 스크린샷 제공.
- 기존 art·모델역할·서브모듈의 다른 작업 보존. gpt-6.1-sol 구현자 한 명에게 수정과 scoped verification을 위임. 통합 검증은 한 번, 수정 실패 영역만 재검증. 부모는 fresh-context 리뷰·보고 확인.
