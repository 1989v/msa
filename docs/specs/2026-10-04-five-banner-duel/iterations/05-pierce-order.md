# R5 — 병과 관통 순서

2026-10-06 사용자 요청: **창병 > 화차 > 총통 > 포수 > 궁병**. 기존 게임 명칭 궁수는 유지한다.

기본 관통을 **창병22, 화차18, 총통12, 포수10, 궁수0**으로 변경한다. 강화 관통 추가는 기존 Lv2+4/Lv3+8이므로 같은 레벨의 순서가 항상 유지된다. 군악수는 공격하지 않는다. 공격력·비용·사거리·연사·웨이브·적 방어력은 변경하지 않는다. 포수는 높은 단발 피해로 단일 중갑을 처리하지만 관통 수치 최고 병과는 창병이다.

공통 stats를 사용하는 실제 피해·툴팁·강화 미리보기를 함께 반영한다. 검증은 기존 도메인 테스트의 변경된 피해 기대값, 모든 레벨의 순서, 브라우저 실제 카드/선택 정보 관통과 피해 계산 일치 확인으로 제한한다. 전체20단계 경기/원화 검증은 반복하지 않는다. 기존 구현자 gpt-6.1-sol 한 명에게 게임·관련 테스트·검증/게임README를 위임하고, 다른 작업 및 games root pointer를 보존한다. 정상 훅·정확한 파일 커밋.
