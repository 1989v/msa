# 초기 요청 (원문)

> 내 서비스에 숏컷 링크 기능 도입해 줘. 필요한 이유는 이력서 링크 생성시 공유용 링크가 너무 길어서 이런것 대응용으로 숏컷 링크 기능이 필요해. 이력서 외에도 여러 서비스 모두 공유용 숏컷 대응이 필요함
>
> 예를들어
>
> 이력서면 /r/{여기에 기존 링크에 대응하는 짧은 해시값}
>
> 이런식으로? 장소서비스면 /p/{hash}, 게임이면 /g/{hash} 이렇게? 목록이면 /g/list 이건 모든 서비스 고정. 블로그는 /b/{hash} 등

## 확인 질문 답변 (2026-10-08, 원문)

| 질문 | 답 |
|---|---|
| 도메인 | apex 하나 (`1989v.com/r/…`) |
| 코드 생성 시점 | "이거는 실제 각각 엔드포인트별로 자동으로 식별되어 라우팅되도록, 별도 공유 버튼 없이도. 공유버튼 누르면 해당 단축 url이 보여야 함" |
| 1차 범위 | 이력서 /r, 장소 /p, 게임 /g, 블로그 /b |
| 클릭 기록 | 누적 카운트 + 원장 90일 |
