## 4. 보고할 것 — 수치 밖에서 보인 것

1. **결과 패널 첫 카드를 하단 버튼이 가린다.** 패널 첫 카드 657–788 위에 「목록 보기」 버튼 736–780 이 떠 있고, 앱 셸 하단 탭바(790–844)가 패널 아래쪽을 덮는다. 접힌 상태에서 가리지 않고 보이는 부분은 648–736(88px)이다 → 카드 제목·분류·주소는 보이고 개요 줄은 버튼 뒤에 있다(`screens/hub-listFirst-390-map-light.png`). SR-1.5 의 「접힌 높이는 카드 1장」 기준으로는 카드 1장 높이(131px)가 다 보이지 않는다.
2. **카드 제목이 브라우저 기본 링크색 + 밑줄로 나온다.** 라이트 #0000ee, 다크 #9e9eff 다. 목록·결과 패널이 같다. `.place-card` 는 `<a>` 인데 `color`·`text-decoration` 리셋이 없다(`color: inherit` 는 `button.place-card` 에만 있다). 카드가 `<a>` 가 된 것은 `1b74d94bf` 부터이고, 최근 커밋에서 이 규칙은 바뀌지 않았다 → 기존 상태로 보인다. 대비는 통과하지만 의도한 모양으로 보이지 않는다.
3. 390 → 1440 으로 넓히면 데스크톱 목록이 접힌 상태(`list-collapsed`)로 나온다. 1440 으로 처음 열면 펼쳐져 있다. 데스크톱 배치는 범위 밖이라 값만 적는다.
4. 1440 첫 카드 y 438 > 320: 완료 조건 미충족. 데스크톱은 범위 밖(Q6)이고 배포 전과 같은 값이다. 겹쳐 쌓인 요소는 `pre-measure.md` 의 목록(헤더 20–83, 툴바 99–378 — 검색·분류·속성 칩 줄)을 따른다. 이번에는 세로 배치를 다시 재지 않았고, 첫 카드 y 와 지도 위치(394–1038)가 배포 전과 같다.
