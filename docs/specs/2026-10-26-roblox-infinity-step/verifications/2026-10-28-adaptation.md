# 로블록스 최적화 이식 검증 — 2026-10-28

## 기준

사용자의 최종 정정인 **게임 구성·아이디어 유지 + 로블록스 구성/성능/조작 최적화**를 적용했다. 원작 발판 수·좌표·총 높이 일치는 요구하지 않았다. 원본 추출 작업은 연구 기록이며 최종 기본 월드의 의존이 아니다.

## 독립 리뷰

`/root/roblox_adaptation_review`가 현재 코드와 최신 명세를 읽기 전용으로 검토했다. `/root/adaptation_review_verdict`가 초기3개 발견을 모두 유지했다. 부모가 발견을 임의로 기각하지 않았다.

| 발견 | 수정과 검증 |
|---|---|
| 부활 복구 실패 시 nil 접근으로 busy 고정 | Main이 실제 Recovery.finish를 호출. 실패 후 locked 유지/busy 해제/재시도 성공 경로 검사. |
| 이전 세션의 늦은 높은 진행 저장이 현재 낮은 진행을 덮음 | Progress의 원자 세션 owner/epoch·샘플 sequence fence. 갱신 콜백 재시도·세션/샘플 역순 검사. |
| 모바일 잡기/달리기 입력 부재 | 실제 custom 액션 버튼·전송 이벤트·HudLayout 연결, 작은 화면과 터치 소유권 검사. |
| fence 보완 중 확인된 접속 수명주기 | 접속마다 별도 Progress 핸들과 GUID owner, 퇴장 close, A→B→A/같은 서버 재접속·닫힌 옛 핸들의 늦은 저장/재획득 거부 검사. |

최종 재검토 판정: **SHIP — 해당 소스 수정 경로에서 남은 결함을 발견하지 못함**. 리뷰어는 중복 테스트/UI 실행을 하지 않았다. 부모가 전체 검증 명령을 직접 실행했고 출력은 `../status.md`에 보관했다.

## 원작 자료 평가의 한계

Unity 비대화형 실행은 라이선스 부재로 종료198. 원본 C# 알고리즘을 .NET 수학 어댑터로 평가한 선택적 자료는 남겼으나 Unity 엔진 출력/비트 단위 동등/웹 직접 플레이 증거로 쓰지 않았다. 해당 자료의 개수와 좌표 일치는 이번 결과물의 합격 기준이 아니다.
