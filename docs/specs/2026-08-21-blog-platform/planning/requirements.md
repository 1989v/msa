# 블로그 플랫폼 — Requirements (shaping 결과)

- 일자: 2026-08-21
- 상태: locked (사용자 확인 4문항 반영)

## 1. 원 요구

blog 서브도메인을 추가하고 블로그 포스팅 시스템을 설계·구축한다.

- 어드민에 작성 페이지, 조회수, 공유링크 등 기본 포스팅 요소 전량
- 댓글 · 평점 · 좋아요
- 계층 카테고리로 유형별 모아보기 (`기술 > 서버 > 검색`, `일상 > 취미 > 게임`)
- 작성자별 공간 — 나만 쓰는 곳이 아니라 여러 사람이 쓸 수 있는 규모
- 로그인 기반 + 권한 체크. 작성 권한이 있는 사람만 쓰고, 자기 글만 수정

## 2. 확인된 결정 (사용자 답변)

| 축 | 결정 |
|---|---|
| 작성 권한 | `blog_profile` 등록제. 어드민 승인 → 작성 가능. auth Role enum 무변경 |
| 작성 UI | blog 호스트에 작성자 스튜디오 + **내 글은 기본적으로 어드민에서 작성** |
| 상호작용 인증 | 좋아요·평점 익명 허용(`X-Visitor-Id`), 댓글만 로그인 |
| 공유/SEO | 백엔드가 meta 주입한 HTML 서빙 (발행 즉시 정확한 OG) |

## 3. 코드베이스 증거로 확정 (질문 불요)

- 배치: `code-dictionary:app` 폴드 (`:blog:domain` + `:blog:feature`, `com.kgd.blog`)
  — 근거: OCI 무료 티어 단일 노드 = 신규 상시 파드 0 (ADR-0069 전제), deal/game 선례
- 스키마: code-dictionary 공유, `V14__blog.sql`, `DataSourceConfig.packages()` 에 추가
- 본문 포맷: 마크다운. `marked` + `dompurify` 가 portal-fe 에 이미 있음
- 조회수 중복 방지: 게이트웨이 `VisitorIdFilter` 의 `X-Visitor-Id`
- FE: portal-fe 한 벌 host 인식 라우팅 + `SUBDOMAIN_ORIGIN` 등록 (ADR-0066 체크리스트)

## 4. 범위 밖 (P1 제외 — 근거 포함)

| 항목 | 제외 근거 |
|---|---|
| 이미지 업로드 | 오브젝트 스토리지 클라이언트가 플랫폼에 없음. P1 은 외부 URL 입력 |
| 전문 검색 | 글이 쌓이기 전 색인 파이프라인은 유지비만 든다 |
| 태그 | 카테고리가 "유형별 모아보기" 요구를 이미 충족 (YAGNI) |
| 시리즈/연재 | 요구에 없음 |
| 영문(/en) | place/game 과 달리 요구에 없음. 필요해지면 URL 승격 규칙은 ADR-0062 |
| 뉴스레터·구독 | 요구에 없음 |

## 5. 열린 질문 (구현 중 확정)

- `handle` 예약어 목록 최종본 (`admin`, `api`, `posts`, `authors`, `c`, `studio`, `login`, `new`)
- 저자 신청 폼의 필수 항목 (자기소개 필수 여부)
- 조회 원장 보관 기간 90일 확정 여부 (작성자 통계 요구가 커지면 집계 테이블 분리)
