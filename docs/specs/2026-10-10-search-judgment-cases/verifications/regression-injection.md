# 회귀 주입 — `live-eval.py` 의도별 리포트·형식 검사 (TG4.4)

2026-10-11. 주입은 스크래치패드 사본(`s36b/inj/`)에서만 했다. 레포 파일은 건드리지 않았고 하네스·사본은 커밋하지 않는다.

## 방법

- 하네스 `inj/harness.py` 가 `live-eval.py` 사본을 모듈로 읽고 `encode`·`ids_bm25`·`ids_hybrid`·`ids_live`·`resolve_index`·`ids_keyword` 를 고정 응답으로 바꾼다. 새 질의는 풀링 당일(10-11 10:06) 실제 C top-10 과 totalElements, 기존 질의는 등급 순 합성 순위. 네트워크 없이 같은 입력을 반복한다.
- `real_live` 모드는 **실제 `ids_live`** 를 돌리고 `urlopen` 만 바꿔 `totalElements` 없는 응답을 준다. `real_live_ok` 는 `totalElements` 를 넣은 응답을 준다.
- 코드 주입은 문자열 치환 한 곳(치환 대상이 정확히 1회인지 단언)이고, 사본은 `compile()` 을 통과한 것만 돌렸다 — 구문 오류 빨간불은 증거로 쓰지 않는다.
- 데이터: v3 초안(228 질의 · 9,692쌍). 주입 ② 전 확인 — 등급 1 이 있는 NO_ANSWER 질의 **9개**(13개 중 무의미 입력 4개를 뺀 전부). 그래서 `ndcg()` 가 NO_ANSWER 에서 숫자를 낸다.
