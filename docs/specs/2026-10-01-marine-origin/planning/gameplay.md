# Gameplay / balance v0.1
**모든 아래 숫자는 설계 제안이며 원작의 추출 수치가 아니다.** 소규모 실플레이로 검증 후 조정한다.

## 플레이 사이클
활잡이1로 약한 몬스터 사냥 → 첫 금화100 → 목수1 고용 → 숲/광산 자동 수입 →
추가 활잡이·공방업 → 목수 방어탑 건설 → 병력 일부 주둔/나머지 원정 →
일반3 합성 또는 장궁수 고용 → 주둔지 파괴·던전·중간보스 → 최종 성채.

## 경제
| 항목 | 제안 |
|---|---|
| 시작 | 활잡이1, 목수0, 금화0 |
| 목수 | 100G, 최대8/인 |
| 활잡이 | 180G, 전투 총24/인 |
| 장궁수 | 500G, 직접 고용 |
| 영웅 활잡이 | 일반 활잡이3 소비, 추가 금화0, 직접 구매 불가 |
| 공업 L→L+1 | 30+20L G, 상한50, 각 단계 기본 피해+2 |
| 방업 L→L+1 | 25+25L G, 상한30, 각 단계 방어+1 |
| 목재 | 짐10G, 작업6초+왕복, 기지와240거리·속도80이면 총12초≈50G/분 |
| 광석 | 짐18G, 작업10초+왕복, 기지와360거리면 총19초≈57G/분 |
| 방어탑 | 220G, 작업20초, 목수1 필요 |
| 탑 수리 | 1G로10HP, 초당20HP, HP 상한에서 소비0 |
| 회복 샘 | 본진 반경96, 비전투3초 뒤 초당 최대HP의10%, 무료 |

목재와 광석은 노동 상태·운반 외형이며 별도 소지 통화가 아니다. 금화는 반납 시만 지급.
광맥/숲 작업 슬롯은 노드당3. 자원은 기본판에서 고갈하지 않는다(건설·정체로 경로 변경 가능).
건설 지시 때 운반 중 짐은 본진에 반납 후 작업 전환. 사망하면 미반납 짐은 소실하며 중복 지급 없음.
첫 약한 몬스터10회 처치(10G씩)로 목수 가능. 목표40~90초는 튜닝 기준, 통과 주장 아님.
일꾼1은 자동 부수입; 일꾼3~4의 수입이 초반 사냥 수입에 필적/초과하도록 튜닝한다.
웨이브 보상도 같은 처치 규칙이며 추가 웨이브 완료 골드는 없음.

피해=max(1, 기본피해+2×공업−max(0, 적방어−관통)).
장궁수만 관통4. 다른 숨은 치명타/회피/레벨 시스템 없음. 전투 유닛 모두 공중 적 공격 가능.
HP0 영구 사망, 샘은 부활시키지 않음. 더는 부활/재고용할 수 없는 경제적 소프트락은 패배 처리.
싱글 경제 패배: 전투원0·목수0·금화<100. 100~179G는 목수 고용으로 재건 가능하므로 패배가 아니다.
협동은 한 소유자가 무력화되어도 종료하지 않으며, 등록된 모든 소유자가 위 조건일 때만 경제 패배.
한쪽이 살아 있으면 다른 쪽은 캠프 분배금으로 재건할 수 있다. 본진HP0은 모든 모드의 즉시 패배.
초기 본진 HP4000, 협동6000. 무료 샘은 경제적 재기를 돕되 소프트락 판정을 회피하지 않음.

## 목수 방어탑
- footprint96×96, 완공HP800/방어3, sight300, 최대4기. 입장하려는 병력은 탑96 이내까지 이동 후 슬롯 예약 순서대로 입장.
- 사격은 주둔자 각각의 공격/업그레이드/간격. 사거리만+60; 탑 자체 무기 없음. 장궁수/영웅도 1슬롯.
- 탑 속에서는 시각 개체를 발사구에 표시하고 이동 충돌 개체에서는 제외. 대상 공격은 탑HP가 받음.
- 퇴각 시 탑 근처 첫 유효 보행칸에 배치. 파괴 시 주둔자는 현재HP의25% 피해 후 출구칸에 강제 배치; 안전칸이 없으면 가장 가까운 연결된 walkable칸 검색.
- 적 공격으로 파괴: 환급0. 공사 취소: 소비 금화의 미진행 비율×75%를 내림하여 환급. 완공 철거는 기본판 없음.
- 목수 사망/다른 일로 이동하면 공사 정지, 새 목수로 재개. 완공 이벤트1회. 탑6개/소유자 상한.
- 자원노드·램프·경로 보호 셀과 건물 둘레1셀에 건설 금지. 건설 미리보기에서 이유 표시.
- 기본판에서는 내 탑/내 주둔자만 관리. 동료에게 금화 이전 없음.

보스 일반 공격과 예고 공격 쿨다운은 별도, 기본 예고 패턴8초마다. 광역피해는 같은 공격ID당 대상1회.
처치 보상은 온라인에서 최근10초간 피해를 준 협동 소유자에게 균등 분배(정수 잔여는 작은 campaignOwnerId), 동일 처치에 총 보상 증가 없음.
기여자=최근10초 해당 적 피해를 준 소유자. 없으면 최후 피해 소유자. 타워 사격은 주둔자 소유자로 기록.
최근10초 피해 기여에는 거리·현재 지역 제한이 없다. 적이 죽은 시점에 최근10초 피해 기록만 확인한다.
캠프 일회 보상은 생존/접속과 무관하게 캠페인 등록 소유자 수(solo1/coop2)로 균등 분배한다.
협동 보상 배수는 총 보상에 한 번 적용한 후 분배. fork에서도 원래 소유자별 지갑에 지급하며 합치지 않는다. 보스도 개인 처치 보상에 포함하며 별도 퀘스트 골드 중복 없음.

## 스폰/웨이브
- 각 캠프 본체HP: 외곽1200/1500/1800, 내곽2500/3200/4000. 일회 파괴 보상100/150/200/300/350/400G.
- 사냥터 리젠은 캠프별 20초마다3기(캠프 생존 때). 최대 캠프 주둔16. C1은 시작2기,20초마다2기, 최대8.
- 첫 본진 웨이브180초, 이후120초. n번 웨이브 수=min(8+3n,50), 위협3단계에 따라 기본/고급 비율 변경.
- stage0(C1~C3 이전): zombie70%/ghoul30%; stage1(C3 이후): zombie40/ghoul30/plague20/bat10%;
  stage2(5개 거점 공략 이후): zombie25/ghoul20/plague20/bat15/armored15/vampire5%. 정수 합은 마지막 종류에서 보정.
- 캠프 파괴 역습은 외곽6·내곽10기, 해당 stage 조성. 본체 보상·파괴 트리거는 동일ID1회.
- 협동 고정2인 난이도: 적HP×1.5, 공격×1, 웨이브 인원×1.4(올림), 보상×1.5(내림).
  캠페인 생성 시 확정, 이탈/복귀로 난이도·보상 변경 없음.
- 필드 적 cap180 / 지역 던전 cap40씩 / 전체 cap260, 큐 최대128 예약. 던전 보스·방 필수 스폰을 큐에서 우선하고 리젠은 뒤로 미룸.

## 건설 상태 계약
| 상태 | 처리 |
|---|---|
| accepted | 소유자/금화/footprint/보호셀/정원 검증 후220G 전액 차감, 탑 정원과 지면 예약. 다음 상태 travelling |
| travelling | 짐 먼저 반납, 지정 목수 이동. 아직 구조물 HP/피격체는 없음. 예약 영역은 다른 건설만 막음 |
| building | 도착 시 실제 구조물HP80 생성, 적에게 피격 가능. 목수1명만 작업,20초에 progress1 |
| paused | 목수 이탈·사망 시 진행 중지. 피격 가능. 동일 소유 목수로 재개 |
| completed | progress1에서 정확히 한 번 완공, 주둔 허용 |
| cancelled | 수락 후 미완공에서만 허용. floor(220×(1-progress)×.75) 환급; 도착 전도165G. 예약 해제 |
| destroyed | building/paused에서 HP0, 환급0, 정원 해제. 완료 탑 파괴는 주둔 강제퇴각 규칙 |

구조물 최대HP=80+720×progress. 진행 증가만큼 현재HP도 같이 증가, 피격 손상량은 유지한다. 목수 추가로 가속하지 않는다.
명령은 tick당 수신순서/sequence로 처리 후 공정 갱신. 취소가 먼저 수락되면 이후 완공하지 않음. 이미 완공 후 취소는 거부.
즉시 완공은 피해/취소/주둔 전이와 같은 tick에 중복 발화하지 않도록 terminal state 1개만 기록.

## 원본 지형 통합 조정
장궁수 사거리 560: 4배 확대한 실제 C2 섬 거점은 본토 사격점과 약500 떨어져 있어 이를 공략할 수 있도록 조정했다. 캐릭터 표시 크기는 늘리지 않는다. 초기 목수는 없으며 구매한 목수는 빈 숲 노드에 자동 배치된다.
