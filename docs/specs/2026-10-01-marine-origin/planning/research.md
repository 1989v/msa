# Research and provenance
## 직접 확인
- [사용자 지정 블로그: Marine Special Forces SE](https://blog.naver.com/star7sss/220575847295), 2015-12-22.
  web 도구 접근 불가 후 공개 PostView HTML을 curl로 읽음. 본문은 초기 SE 판 소개이며 상세 고용·합성·경제 수치표는 없다.
  블로그 스크린샷 153147: 시작 지역의 작은 보병들, 자원, 절벽으로 나뉜 시설 구역, 전체 맵에서 매우 작은 현재 시야.
  스크린샷 154255: 좁은 계곡에서 다수 적, 절벽·통로·가려진 외곽. 설명 이상의 트리거/전체 지형은 확인하지 못함.
  블로그 아트/첨부 맵 파일은 제품 에셋으로 복사하지 않음.
- [사용자 지정 영상](https://www.youtube.com/watch?v=FU451SAizrA): 이전 접근 throttled. 영상을 시청·프레임 전체 분석했다고 주장하지 않음. 사용자가 제공한 두 스크린샷은 직접 확인.
- 사용자가 제공한 플레이 루프가 고용/3기 합성/목수/벙커 동작의 최우선 근거.
- 이전 Climax2 조사 가격6000/5500, 일꾼 초반 지급, 유료 영웅 승급 등은 이번 기본판 근거에서 제외.
## 불확실성과 처리
- 전체 오리지널 맵 좌표, 모든 스폰 표와 시나리오, 영상/블로그 판의 동일성은 미확인.
- 따라서 world.md의 맵은 **재구성 초안**이다. 구현 T0에서 참조 전체 맵/플레이 구간 자료로 비교하고 차이를 적는다. 자료가 없으면 사용자에게 지도 근사 허용 범위를 묻는다.
- 실제 던전 구조는 출처에서 검증되지 않았다. 이전 사용자 요구로 유지한 2개 분기 구역이다.
- 초반 채집 속도 관련 문장은 비교 대상이 모호함. 기본 제안은 '목수 고용 후 자동 수입이 사냥에 더해져 전체 경제가 빨라짐'. 사냥보다 목수 한 명이 항상 더 높은 수입이라는 보장은 하지 않는다.
