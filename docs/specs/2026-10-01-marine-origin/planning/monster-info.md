# 몬스터 도감·적 정보·강화 판단

2026-10-04 사용자 요청. 범위는 현재 게임의 정보 표시이며 적·아군 밸런스를 바꾸지 않는다. 구현/배포 상태는 [status.md](../status.md) 최신 기록을 따른다.

## 확인된 문제와 실제 첫 웨이브

도감 최초 도입 때는 기본 zombie 공격4/초반 정찰형 공격2였으나, 후속 치유 거점 밸런스 패치에서 **둘 다 공격11**로 변경했다. 정찰형 HP12(solo)/18(coop), 일반형 기본HP24 차이는 유지한다. 상세 [치유·방어 설계 및 관찰](healer-defense-balance.md).

| 초기 일반 궁수 기준 | 방어0 | 방어1 | 방어9 | 방어10 |
|---|---:|---:|---:|---:|
| 정찰형·일반형 좀비 공격11 | 피해11 | 피해10 | 피해2 | 피해1 |
| 방어0에서 누적 강화비 | 0G | 25G | 1,125G | 1,375G |

최소 피해는1이다. **일반 궁수 방10, 기본방어2인 영웅은 강화8**에서 기본 좀비 피해1에 도달한다. 여러 적의 동시 공격과 보스 스킬 생존을 보장하지 않는다. 이전 ‘첫 웨이브 방1이면 충분’ 안내는 이 패치 이후 유효하지 않다.

초기 궁수 공격12는 정찰형 solo HP12를 일반공격1회, coop HP18을2회로 처치한다. 실제 비교는 현재 강화·적 방어·남은 체력에 따라 계산한다. 정찰형 생성이 끝난 이후의 일반형과 혼동하지 않는다.

## 적 선택 정보

- 현재 지역에서 살아 있고 실제로 보이는 적만 클릭/탭할 수 있다. 별도 표시용 적 선택 ID를 사용해 아군 선택·합성·스킬을 건드리지 않는다. 적을 누른 클릭으로 이동 명령을 보내지 않는다.
- 카드에는 변형을 포함한 적 이름, 현재/최대 체력, 실효 기본 공격, 공격 간격, 방어, 사거리와 지상/비행·근거리/원거리 구분을 표시한다. 보스 특수 패턴 피해는 일반 공격과 다른 정보임을 알린다.
- 적이 죽거나 시야 밖·다른 지역으로 나가면 실시간 카드를 닫는다. 도감으로 숨겨진 적의 현재 체력·좌표를 추적하지 않는다.
- 비교 대상은 선택한 내 살아 있는 전투 유닛 중 고정 ID순1명. 선택이 없으면 내 소유자의 공/방 강화가 적용된 일반 궁수 기본형을 **예시**로 표시한다. 다른 플레이어 병력으로 내 강화 비용을 계산하지 않는다.
- 내 유닛의 종류·현재 공/방 단계, 적에게 받는 기본 피해/회, 내 일반공격 피해/회, 적의 남은 체력 기준 처치 필요 타수를 표시한다. 스킬·회복·여러 아군의 동시 공격을 포함한 예상 전투 결과로 주장하지 않는다.
- 주둔 중 유닛은 탑이 대신 피격된다는 설명을 표시하며, 유닛 방어 비교를 탑 실제 피해로 제시하지 않는다. 본진/탑 고유 방어와 유닛 방어를 합산하지 않는다.

## 방어 목표 계산

기본 피해 = `max(1, 적 실제 공격 - (아군 기본 방어 + 소유자 방어 강화))`.

피해1에 도달할 총 방어 단계 = `max(0, ceil(적 실제 공격 - 아군 기본 방어 - 1))`.

현재 단계부터 목표 직전 단계까지 `25 + 25×L`을 합산해 추가 비용을 표시한다. 이미 목표 이상이면 추가 비용0과 ‘추가 방어 강화로 이 적의 기본 피해는 더 줄지 않음’을 표시한다. 목표가 상한30을 넘으면 도달 불가이며 상한에서의 피해를 표시한다. 목표 단계는 최종 단계와 추가 단계를 구분한다.

아군 일반 공격은 강화(+2/단계)·장궁수 관통4·적 실제 방어를 기존 시뮬레이션과 같은 계산으로 반영한다. 처치 필요 타수는 `ceil(적 현재HP / 일반공격 1회 피해)`이며 최소 피해1을 준수한다.

## 도감

- HUD에 ‘몬스터 도감’ 버튼을 둔다. 기존 몬스터 목록과 정찰형·전초 파수꾼 변형을 구분한다. 새 몬스터나 별도 아트는 추가하지 않는다.
- 도감 값은 종류별 기본값임을 명시한다. 실제 적 선택 정보는 해당 인스턴스 수치이며 협동·변형에 따라 다를 수 있다.
- 목록과 정보 카드는 기존 UI 토큰·스프라이트를 재사용한다. 전체 적 좌표나 미탐색 적 실시간 상태를 제공하지 않는다.

## 구현·검증 범위

실제 scout/guard 공격·체력 변형은 시뮬레이션과 공용 계산을 사용한다. 협동 표시에는 정찰형 식별을 포함해 호스트/게스트가 같은 공격력을 보여야 한다. 기존 표시3072자/4청크·저장 한도를 유지하고 영웅 스킬 상태와 정찰형 혼합 최대 fixture로 확인한다. 필요 시 프로토콜과 릴리스 태그를 함께 갱신한다.

단일 gpt-6.1-sol 구현 담당. 초기 관련 분석을 재사용하며 전체 수정 후 관련 검증1회 및 실패 영향만 재검증한다. 기본/정찰/보스 변형, 협동, 방어0/1/3·상한·누적비용, 선택·시야 이탈·주둔 설명, 도감 기본값, 저장/표시 한도를 검증한다. 새 기능으로 공격·방어·출현 수·가격 자체를 변경하지 않는다.
