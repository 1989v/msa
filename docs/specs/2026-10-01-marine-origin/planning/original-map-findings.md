섹션 구조 대조: [scmJS CHK 문서](https://docs.scmjs.dev/chk/).

## 확인된 구조 단서와 한계
원본 배치에서 건물 type106은 x864, y2608/2704/2800/2896/2992에 있다.
type151의 5개 배치는 (112,96), (1456,384), (176,1600), (2832,1696), (2544,1888)이다.
문자열에는 5개 목표 파괴 후 새 장비 지급, 매복, 증원, 치료, 일꾼 증원과 건설 제한에 관한 안내가 존재한다.
이는 원본 목표/이벤트를 조사할 단서다. 문자열 존재만으로 실제 트리거 조건·진행 순서·클리어 규칙이 확인됐다고 판단하지 않는다.

일부 구역의 이름 string ID가 문자열 테이블 범위를 벗어나므로 이름으로 구역을 자동 연결하면 안 된다.
구역 좌표와 트리거의 location ID를 직접 연결해서 검증해야 한다.
MTXM 타일 번호만 확보했으며 타일 그룹별 높이·통행·램프 의미는 아직 검증하지 않았다.
따라서 전체 지형의 정확한 언덕/경로 지도를 확인했다고 주장하지 않는다.

블로그 파일은 명시적으로 SE 리메이크다. [사용자 지정 영상](https://www.youtube.com/watch?v=FU451SAizrA)의 판본과 동일한지 아직 확인하지 못했다.
사용자의 단일 금화·자동 채집 전환 요구는 그대로 유지하며, SE의 환전 안내를 이유로 수동 환전 시스템을 되살리지 않는다.
