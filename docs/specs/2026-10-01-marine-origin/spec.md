# Specification — 활잡이 원정 기본판
## Goal
활잡이로 사냥해 목수와 병력을 고용하고, 경제·주둔 거점·공방업·3기 합성으로 성장하여 넓은 고저차 맵의 적 주둔지와 보스를 공략하는 2D 부대 RPG.
2026-10-02 사용자가 구현 재개를 명시했다. 이번 진행 그룹은 T3이며, 기능별 구현 상태는 tasks.md와 context/progress.md를 따른다. 이 사양 전체를 구현 완료로 간주하지 않는다.

용어 정의: [피처 사전](planning/glossary.md).

## User Stories
- 플레이어는 전투 수입을 목수에 투자해 사냥하는 동안에도 자원이 들어오길 원한다.
- 플레이어는 탑에 부대를 주둔시켜 귀환·치료·수비의 거점을 만들고 남은 병력으로 진출한다.
- 플레이어는 여러 병력을 운영하고 공방업/증원/3기 합성/상위 유닛 고용 중 투자를 선택한다.
- 친구와 같은 전장에 원정하고, 접속을 끊은 뒤 개인/협동 기록을 이어간다.

## Specific Requirements
### SR-1 시작과 경제
- 새 게임은 플레이어당 활잡이1, 목수0, 금화0. 본진 회복은 무료이고 초반 기본 적으로 첫 목수 비용을 모을 수 있다.
- 살아있는 적의 죽음 1회당 금화 1회 정산. 숨은 환전 포인트 통화 없음.
- 목수 고용 전 노동 수입0. 고용 후 숲/광산까지 이동→작업→운반→본진 반납할 때만 지급.
- 불가능한 경로는 수입을 만들지 않는다. 건설/수리로 전환하면 채집이 중단된다.
- 수치와 경제 목표는 planning/gameplay.md 단일 표를 따른다. 기본판은 금화 한 통화.

### SR-2 병력 성장
- 활잡이 추가 고용 및 장궁수 직접 고용. 전투24/목수8 상한은 플레이어별.
- 공방업은 소유자 전투 병력 전체(주둔 포함)에 적용. 본체 범위 밖의 적 공격 피해도 동일 규칙.
- 동일 소유자의 일반 활잡이3 → 영웅 활잡이1. 재료 선택/소비/결과 생성은 한 명령으로 원자적.
- 주둔 중·서로 다른 지역·시체는 합성 재료 제외. 합성 전 요구량/결과를 보여주고 실패 시 소비0.
- 합성 체력 비율은 재료 3기의 평균, 해당 위치와 명령 그룹 승계. 무료 완전회복 악용 금지.

### SR-3 목수와 주둔 탑
- 목수1명 이상이 지정 위치까지 걸어가 건설해야 완공. 지형/자원/본진 입구/필수 통로 중첩 금지.
- 빈 탑은 공격하지 않는다. 최대4 병력이 실제 이동·입장한 뒤 각자의 사격 주기로 공격.
- 탑 안 유닛은 월드 외부 전투 개체로 중복 공격/피격하지 않으며 주둔 슬롯으로 표현.
- 철수·탑 파괴·목수 사망·공사 중단·잔여 자원 처리까지 gameplay.md 기준.
- 온라인에서 건설/주둔/수리는 소유자만 명령. 협동 상대 탑을 점유하거나 유닛을 소비할 수 없다.

### SR-4 맵과 시야
- world.md 고정 맵, 고도0/1/2, 실제 램프로만 고도 이동. 지형은 눈에 보이는 절벽과 충돌이 일치.
- 숲·절벽이 시야를 차단하며 낮은 지형에서 높은 지형 내부는 램프를 오르거나 아군 고지 시야가 있어야 보인다.
- 미탐색/기억/현재 시야3상태. 숨은 적/이동/죽음/피해 숫자/소리/미니맵 표시가 정보 누출을 만들지 않는다.
- 협동은 두 플레이어의 현재 시야 합집합 공유, 카메라·선택·입력은 개별.
- 화면 크기 검증은 design/DESIGN.md의 실측 픽셀 기준. 모바일에서도 렌더 캐릭터를 크게 만드는 식으로 선택 편의를 해결하지 않는다.

### SR-5 적과 진행
- 기본 적6종, 주둔지6, 던전2(각3방·중간보스1), 최종보스1.
- 필드 사냥 리젠/본진 웨이브/주둔지 파괴 역습/보스 소환은 서로 다른 스폰 큐.
- 스폰 상한에서 적이 못 나왔다고 방 클리어로 인정하지 않는다. 보스 예약은 성공 때만 완료한다.
- 정예·원거리·공중·장갑 역할이 시각뿐 아니라 공격/이동 행동으로 구분된다.
- 적 주둔지 진출 순서와 보스 해금은 world.md. 원작에 없던 새 능력 트리/장비 파밍은 기본판 제외.

### SR-6 싱글·협동·이어하기
- 타이틀은 싱글 시작 / 온라인 협동 / 이어하기. 온라인2인 각각 독립 금화·병력·강화, 본진/시야/목표 공유.
- 공용 GameRelay, GameAuth, PlatformAdapter를 사용. 플랫폼 계약은 planning/platform.md.
- 싱글은 메뉴 일시정지 가능, 온라인에서는 메뉴가 전장을 멈추지 않음.
- 저장 슬롯은 solo/coop 분리, 재시작은 기존 기록 덮어쓰기 확인. 기존 프로토타입 키는 삭제하거나 억지 변환하지 않는다.
- 중단·재접속·호스트 이탈·동기화 손실은 명확한 화면 상태와 복구 절차를 가진다.
- 검증된 완료 스냅샷으로만 이어하기. 온라인 기록은 경쟁 랭킹 제출 제외.

### SR-7 Presentation
- 승인 미술 톤 유지, 2D 스프라이트 애니메이션과 입체감 있는 지형. 정지 일러스트를 전장 배경 한 장으로 붙이는 구현 금지.
- 아군4역할/몬스터9종 컨셉은 design 이미지와 manifest를 따른다.
- 자원/유닛/합성/타워 상태 UI, 무료 본진 회복 안내, 수입 로그, 실패 사유, 저장 상태 표시.
- 키보드/터치 선택·주둔·건설·합성 가능. 조작은 RTS UI 복제 강제가 아닌 부대 RPG 방식.

## Out of Scope
이번 작업은 T3 시뮬레이션 구현까지. 원본 캠페인 지도·화면 통합·서버 변경·배포는 이번 그룹 밖이다. 기본판은 장비/랜덤 룬/PvP/4인/메타 진행/유료경제 제외.
