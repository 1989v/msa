# 에어로 벤데타 (aero-vendetta) — 설계 문서

종스크롤 아케이드 슈팅. 가공의 1949년, 반란 함대 "벤데타"의 단기 항공 반격전.
**랭킹(스코어보드)이 1급 시민** — 점수 시스템이 곧 게임 디자인이다.

## 벤치마크 (이 문서에만 기록 — 서빙 파일 금지)

Strikers 1945 (32비트 세대 버티컬 슈팅 명작). 하한선 6축:
그래픽 밀도 / 애니메이션 / 해상도 활용 / 이펙트 밀도 / 조작감 / 연출.

## 점수 시스템 (랭킹의 실체)

- **메달 체인**: 100→200→400→800→1600→3200→5000→10000. 메달을 화면 밖으로
  놓치면 100으로 리셋. 격추한 소형기 30%가 메달 드랍.
- **편대 보너스**: V편대(5기) 전멸 시 2000 + 파워업 드랍.
- **노미스 보너스**: 스테이지 클리어 시 잔기 무손실이면 20000.
- **스테이지 결산**: 메달 수 ×500.
- **보스 부위 파괴**: 부위당 5000 (본체와 별도).
- **익스텐드**: 500,000 / 1,200,000.
- 로컬 랭킹 top10 (이니셜 3자) + 플랫폼 서버 랭킹(`PlatformAdapter.runEnd`, 통합 시 배선).

## 히든 요소 (3종+)

1. 특정 보급창 파괴 → 메달 소나기 (스테이지당 1개소)
2. 비밀 UFO — 특정 시간대 화면 상단 횡단, 격추 시 10000
3. S2 은닉 구조물 파괴 → 1UP
4. V편대 전멸 보너스 (파워업 확정 드랍)

## 메타 진행 (localStorage)

- `av_best` 최고 점수 · `av_rank` 로컬 top10 · `av_medals_total` 누적 메달(기체 해금 화폐)
- `av_unlock` 해금 기체 · 죽어도 남는다

## 조작 (키 계약 — 씬 공통)

- 이동: 방향키 / WASD · 발사: Z/J (홀드 오토) · 봄: X/K · 저속: C/L
- 확정: Z/J/Enter/Space · 뒤로: X/Esc · 일시정지: Esc/P
- 무배정 키 = 거절음 + 흔들림 (죽은 입력 0 정책)

## 씬 그래프

스플래시 없음(즉시 타이틀) → 타이틀(시작/기체/조작법/랭킹) → 기체 선택 → 플레이
→ (일시정지) → 스테이지 결산 → … → 올클리어/게임오버 → 이름 입력 → 랭킹.
개발 진입 훅: `dev.scene(name)`, `dev.stage(n)`, `dev.boss(n)`, `dev.spawn(type)`, `dev.god()`.

## 기술

순수 정적: index.html + js/(main·audio·sprites·fx·data·game·scenes). 외부 요청 0.
스프라이트 전부 절차 베이크(3톤 명암+외곽선+접지 그림자), BGM/SFX WebAudio 자체 신스.
렌더 루프 rAF try/finally, 조회 실패 조용히 스킵, 타이머 0 초기화.
