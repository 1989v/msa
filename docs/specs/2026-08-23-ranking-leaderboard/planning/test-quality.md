# 테스트 전략 — 랭킹 리더보드

Kotest BehaviorSpec + MockK (`docs/standards/test-rules.md`).
**구조 검증으로 안 잡히는 것**부터 적는다 — 이 서비스는 좌표·시점·외부한도에서 조용히 틀린다.

## 반드시 테스트하는 것

### 1. KATEC(TM128) → WGS84 변환 — 골든 좌표

수집기 테스트. 서울시청·부산시청 등 좌표가 알려진 지점 3~5곳을 KATEC 입력으로 넣어
WGS84 결과가 허용 오차(수 m) 안인지 본다.

> 이게 틀리면 값은 그럴듯한 채로 지도의 핀만 전부 어긋난다. 타입 검사도 빌드도 안 잡는다.

### 2. 순위 등락 계산 — 경계가 전부

| 케이스 | 기대 |
|---|---|
| 신규 진입 (이전 스냅샷에 없음) | delta = null, "NEW" 표기 (0 이 아니다) |
| 이탈 (이번 스냅샷에 없음) | 엔트리가 없어야 한다 — 이전 순위가 유령으로 남지 않는다 |
| 동점 | 순위가 같고, 다음 순위는 건너뛴다 (1,1,3) |
| 첫 스냅샷 | 전부 NEW, 등락 UI 가 비어도 화면이 성립 |

### 3. 전체 동기화 왕복 (round-trip)

주유소 upsert 가 **전체 동기화**면 — 보내지 않은 필드를 null 로 덮는 방식이면 —
`AttractionDtoRoundTripTest` 를 복제한다: "적재할 수 있는 필드는 전부 조회로 되읽을 수 있어야 한다"를
리플렉션으로 강제.

> 실제로 겪은 사고다 — `cat1~3` 은 보낼 목록엔 있었지만 조회 응답에 없어서 **매일 밤 조용히 null 이 됐다.**
> 사람이 세 곳(요청 DTO·엔티티·응답 DTO)을 매번 맞추는 건 실패한다.

### 4. 경로 후보 산출

- 폴리라인 샘플링 간격보다 가까운 두 주유소가 **중복으로 안 나온다**
- 이탈 허용 시간 0 이면 경로에 바로 붙은 것만 나온다 (빈 결과가 정상 응답)
- 출발지 = 도착지 같은 퇴화 입력에서 터지지 않는다

### 5. 외부 한도 방어

- 오피넷 429/한도 초과 응답을 만나면 **그 실행을 즉시 멈춘다** (부분 적재를 남기지 않는다)
- Google Routes 키가 없으면 경로 화면만 비활성, 리더보드는 정상 — 잡이 조용히 건너뛰는
  `google-places` 패턴과 같다

## 도메인 순수성

`ranking:domain` 은 Spring·JPA 를 모른다. 등락 계산·동점 처리·점수 규칙은 전부 여기서
Spring context 없이 테스트된다 (`./gradlew :ranking:domain:test`).
