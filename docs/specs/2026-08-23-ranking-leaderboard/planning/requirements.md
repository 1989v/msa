# 랭킹 리더보드 플랫폼 — Requirements (Shape)

> Shape 단계 산출물. 확정된 것과 열린 것을 구분해 적는다.
> 결정 근거는 `open-questions.yml`, 아키텍처 결정은 ADR-0081 로 넘어간다.

## 1. 무엇을 만드나

**"아무거로나 순위를 매겨 보여주는 곳."** 지역별 주유소 가격, 지역별 빵집 업력,
생필품 가격·인기 — 서로 다른 도메인의 목록을 **같은 모양의 리더보드**로 줄세워 서빙한다.

첫 슬라이스는 **주유소**다. 이유는 세 가지가 겹쳐서다.

1. 원천이 **오늘 열려 있다** — 오피넷 무료 API (키 발급만 하면 됨)
2. 값이 **매일 바뀐다** — 재방문 이유가 데이터 자체에서 나온다
3. **경로상 주유소 찾기**는 오피넷도, 지도 앱도 단독으로는 안 해준다 —
   이 서비스의 존재 이유가 되는 기능

## 2. 확정된 범위 (P1)

### 2.1 리더보드 (공통 엔진)

- 하나의 랭킹 = **보드**. 보드는 "무엇을(대상) 무엇으로(지표) 어느 범위에서(스코프)" 줄세우는지를 안다
- 순위는 **스냅샷**이다. 시점이 남아야 "지난주 대비 ↑3" 이 나온다
- 보드 목록 / 보드 상세(엔트리 페이징) / 등락 표시
- 각 보드는 **출처 표기 문자열**을 갖는다 (공공누리·KOGL 의무 대응)

### 2.2 주유소 도메인 (P1의 유일한 실 데이터)

- 전국 주유소 **일 1회 수집** — 가격·브랜드·셀프여부·좌표·부가서비스
- 자동 생성 보드: 시군구 × 유종(휘발유/경유/LPG) 최저가 리더보드
- 전국·시도 평균가 대비 편차 표시

### 2.3 경로 탐색 (킬러 기능)

```
출발지 · 도착지 · 유종 · 이탈 허용 시간 · (브랜드/셀프 조건)
  → 경로 폴리라인
  → 일정 간격 샘플 포인트
  → 우리 DB 의 주유소 geo 검색
  → 중복 제거 · 이탈 시간 추정 · 절약액 계산
  → "여기 넣으면 L당 N원 싸고 M분 더 걸립니다"
```

**오피넷을 실시간으로 부르지 않는다.** 매일 받아둔 전국 스냅샷을 쓴다 — 무료 API 한도를
사용자 요청 수에 연동시키면 인기가 생기는 순간 서비스가 죽는다.

## 3. 확정된 제약 — 여기서 어긋나면 되돌려야 한다

### 3.1 오피넷 좌표계는 KATEC 이다 (WGS84 아님)

`aroundAll.do` 응답의 `GIS_X_COOR`/`GIS_Y_COOR` 는 **KATEC(TM128)** 이다.
위경도로 착각하고 그대로 저장하면 지도에 전부 엉뚱한 자리에 찍힌다 — 값이 그럴듯해서
(십만 단위) 즉시 안 들킨다. **수집기가 WGS84 로 변환해 적재**하고,
원천 KATEC 값도 함께 남긴다 (데이터 3규칙 ①).

### 3.2 유료·무료 경계

| 기능 | 오피넷 등급 | 우리 대응 |
|---|---|---|
| 반경 내 주유소 검색 | 무료 | 그대로 사용 (전국 격자 순회 수집) |
| 주유소 기본정보(지역별) | 무료 | 〃 |
| 주유소 상세정보(ID) | 무료 | 부가서비스·상표 보강 |
| 전국 평균가격(현재) | 무료 | 편차 기준값 |
| **최저가 Top20** | **유료** | 우리가 수집분으로 직접 집계 — 결과 동등 |
| **시도/시군구 평균가** | **유료** | 〃 |

**유료 API 를 부르지 않는다.** 무료 수집분으로 같은 화면을 만들 수 있다.

### 3.3 길찾기 제공자 — 카카오모빌리티는 막혀 있다

| 후보 | 판정 |
|---|---|
| 카카오모빌리티 Directions | ❌ **제휴 파트너 전용** — 사전 제휴 계약 필요 |
| **Google Routes API** | ✅ **채택** — Essentials 월 10,000 콜 무료, GCP 프로젝트·서버 키 IP 제한 패턴이 이미 있다 (`GOOGLE_PLACES_API_KEY` 와 같은 자리) |
| TMAP | 폴백 — 별도 가입 필요, 무료 한도 확인 필요 |

> Directions API 는 Google 이 legacy 로 지정했다. **Routes API** 를 쓴다.

### 3.4 배포 형태 — 새 파드를 늘리지 않는다

OCI 무료 티어가 최상위 제약이다. `deal`/`blog`/`game` 과 같은 **폴드형**:
`ranking:domain` + `ranking:feature` 라이브러리 → `code-dictionary:app` 에 폴드.
수집기만 별도 CronJob (`place/ingest` 패턴 — 외부 :443 egress 가 열리는 유일한 파드).

> 폴드 시 고칠 곳 세 군데: `scanBasePackages` / EMF `packages` / `EnableJpaRepositories`.
> 빠뜨리면 기동 실패가 아니라 **조용한 404** 다.

## 4. 하지 않는 것 (그리고 왜)

| 안 하는 것 | 이유 |
|---|---|
| 빵집·고기집 **맛/평점** 랭킹 | 네이버·카카오 평점은 공식 API 가 없고 크롤링은 약관 위반. Google Places 는 우리 정책상 `place_id` 외 저장 금지. **합법 경로가 없다** |
| 라면 **판매량** 랭킹 | 실판매량을 공개하는 원천이 없다. 가격·인기트렌드·영양으로 대체 |
| 실시간 가격 조회 | 오피넷 갱신이 일 단위다. 실시간처럼 보이게 만들면 한도만 태우고 값은 같다 |
| 사용자 투표 테이블 | P1 에 표가 없다. 엔진의 지표 축이 이미 확장점이라 **지금 만들 이유가 없다** (P2) |

## 6. 성공 판정

- `rank.1989v.com` 에서 내 시군구 최저가 주유소 Top N 이 **어제 대비 등락과 함께** 보인다
- 출발·도착을 넣으면 경로상 주유소가 **이탈 시간 + 절약액**과 함께 나온다
- 수집 CronJob 이 전국을 무료 한도 안에서 하루 1회 돈다
- 화면에 출처("한국석유공사 오피넷")가 표기된다
