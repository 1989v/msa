# 네이버 `웹게임` 검색 미노출 진단

- 조사일: 2026-10-11, 약 10:08 KST
- 대상: `https://game.1989v.com/`
- 요청: `웹게임` 검색에서 곰곰 Play·OGTO는 노출되는데 내 서비스는 보이지 않는 이유 확인
- 상태: 공개 검색 결과·운영 HTTP 응답 조사 완료. 서치어드바이저 내부 수집·색인 리포트는 미확인.
- 관련 설계: [ADR-0062 — SEO / AEO / 검색 유입 설계](../adr/ADR-0062-seo-and-organic-discovery.md)

## 1. 결론

사이트 전체가 네이버에서 미수집·미색인된 상황은 아니다. 도메인 검색과 브랜드 검색에는
홈페이지 및 여러 게임이 나온다. 조사한 `웹게임`·`무료 웹게임` 통합검색 첫 결과 페이지에서는
사이트가 보이지 않았다. 따라서 현재 문제는 **일반 검색어에서 결과로 선택되는 순위·매칭 문제**로
분류한다. 전체 결과 페이지에서의 부재나 네이버의 정확한 순위 결정 사유까지 확인한 것은 아니다.

확인된 개선 단서는 두 가지다.

1. 홈페이지 검색 설명은 **48종**, 현재 운영 HTML은 **82종**으로 서로 다르다.
2. 여러 게임의 검색 설명에 게임 소개 대신 **내 기록·로그인·평가 안내**가 표시된다.

재수집 지연과 렌더링 후 설명문 선택을 우선 점검한다. 콘텐츠 안내의 깊이와 외부 인용·활성도는
추가 후보지만, 경쟁 사이트와의 차이가 순위의 직접 원인이라는 증거는 확보하지 못했다.

## 2. 조사 범위와 방법

- 네이버 공개 검색 결과 HTML을 GET으로 받아 표시 텍스트와 결과 링크를 확인했다.
- 운영 홈페이지·robots.txt·사이트맵·게임 상세·경쟁 사이트의 초기 HTML과 HTTP 헤더를 확인했다.
- Yeti User-Agent로도 홈페이지에 요청해 일반 요청과 응답 본문을 비교했다.
- 저장소의 프리렌더·메타 생성·nginx 설정·게임 상세 화면 코드를 읽었다.
- 네이버 서치어드바이저 공식 가이드를 확인했다.

Yeti User-Agent 요청 성공은 **실제 네이버 로봇 IP의 접근 성공 증명은 아니다**.
로그인된 서치어드바이저 계정, 실제 Yeti 접근 로그, 경쟁 사이트 트래픽·백링크 데이터는 확인하지 않았다.
검색 결과는 시점·환경·검색어에 따라 달라질 수 있다.

### 홈페이지 설명 불일치

| 위치 | 게임 수 | 설명 |
|---|---|---|
| 네이버 홈페이지 검색 설명 | 48종 | 설치도 가입도 없이 브라우저에서 바로 즐기는 무료 웹게임 48종 |
| 운영 홈페이지 초기 HTML | 82종 | 설치도 가입도 없이 브라우저에서 바로 즐기는 무료 웹게임 82종 |

검색 설명과 현재 초기 HTML 에 차이가 있다는 관찰이다. 마지막 수집 시각·설명 생성 시각이나
이 불일치가 순위에 미친 영향은 공개 검색 결과만으로 확정할 수 없다.

**후속 코드 조사에서 원인을 추가 확인했다.** `GamesPage.tsx`는 `size: 48`로 받은 목록의
`games.length`를 `hubMeta()`에 전달한다. 운영 API
`GET https://api.1989v.com/api/v1/games?sort=trending&page=0&size=48`의 응답은 HTTP 200,
`content.length = 48`, `totalElements = 82`, `totalPages = 2`였다.
따라서 자바스크립트 실행 후 메타가 **전체 82종에서 첫 페이지 48종으로 덮어써지는 코드 결함**이 있다.
48종이라는 검색 설명을 재수집 지연만으로 설명하면 안 된다. 네이버가 해당 실행 결과를
설명 생성에 사용했는지, 그리고 순위에 미친 영향은 여전히 미확인이다.

### 게임 상세 검색 설명

- Rift, Alley Pool, Block Burst, 낱말 다섯, Golden Forge, Minefield 등에는
  `내 기록 · 로그인하면 내 기록이 남습니다.`와 별점·평가 안내가 설명으로 표시된다.
- AMP ARENA와 카드 뒤집기에는 실제 게임 소개가 설명으로 표시된다.
- 현재 [Rift 초기 HTML](https://game.1989v.com/games/rift-front)에는 단일 전선 AoS의 목표·전투 소개가 있다.
- 현재 [AMP ARENA 초기 HTML](https://game.1989v.com/games/arena)에는 인원·전투 방식·방 생성 등 구체적인 소개가 있다.

따라서 소개 데이터가 전부 비어 있다고 판단할 수 없다. 이전 수집 내용이 남았거나,
렌더링된 화면에서 공통 UI 문구가 설명으로 선택됐을 가능성이 있다. 둘 중 어느 쪽인지 미확인이다.

OGTO는 초기 HTML에 이용자가 게임을 고르고 시작하는 데 필요한 안내가 더 풍부하다.
홈페이지 콘텐츠 개선의 참고 대상으로 삼을 수 있다. 곰곰은 설명이 짧아도 노출되므로
본문 길이만으로 순위를 설명할 수는 없다.

소유확인 메타 부재는 미등록의 증거가 아니다. HTML 파일 등의 다른 소유확인 방법이 있으며,
네이버는 서치어드바이저에 등록하지 않은 사이트도 자동 수집·검색 반영한다.
게임 수·구현 규모만으로 검색 순위가 정해진다는 근거도 없다.

## 7. 공식 가이드와 해석 주의

- [사이트 등록 및 소유확인](https://searchadvisor.naver.com/guide/faq-start-register): 등록하지 않아도 자동 수집·반영 가능. 소유확인은 내부 리포트 확인에 유용하다.
- [URL 검사](https://searchadvisor.naver.com/guide/url-inspection): 개별 URL의 수집·색인 상태와 Meta/SEO 정보를 확인한다.
- [수집 현황](https://searchadvisor.naver.com/guide/report-crawl-refine): 수집·정제·색인·랭킹은 구분되는 단계다.
- [자바스크립트 검색 최적화](https://searchadvisor.naver.com/guide/seo-advanced-javascript): 네이버도 SPA의 수집·색인을 지원하며 주요 HTML의 서버 렌더링을 권장한다.
- [검색 제목·설명문 갱신](https://searchadvisor.naver.com/guide/faq-serpedit): 설명은 메타태그 외 페이지 텍스트 등에서도 생성될 수 있다.
- [수집 요청](https://searchadvisor.naver.com/guide/request-crawl): 요청과 수집 성공이 검색 노출을 보장하지 않는다.
- [네이버 사이트 검색 BASIC](https://searchadvisor.naver.com/doc/wmt_guide_ps_websearch.pdf): 검색 의도와 신뢰도·활성도 등을 고려한다고 설명한다.

ADR-0062의 과거 설명 중 “네이버는 JS를 실행하지 않는다”는 단정은 현재 공식 가이드와 달라
2026-10-11 정정했다.
이번 진단에서는 **SPA 자체가 검색에서 배제된다는 가정**을 사용하지 않는다.
최초 진단과 후속 조사 관찰을 구분한다. 보완 작업의 배포·재수집 제출 여부는 작업 기록으로 별도 확인한다.

## 8. 보완 작업 상태 (2026-10-11)

홈페이지 건수 메타 오류·한영 이용 안내·상세 소개 DOM 순서·프리렌더 상세 정보 보완을 구현했다.
관련 테스트 114개와 전체 FE 빌드가 통과했다. 상세 브라우저 배치 8조합도 확인했다.
구체적인 검증 결과와 제한은 [작업 기록](../plans/2026-10-11-naver-webgame-seo-improvements.md#실행-결과-2026-10-11)을 참조한다.

**운영 배포와 네이버 재수집 요청은 아직 실행하지 않았다.** 순위·스니펫 개선 여부는
배포 후 운영 HTML/런타임 메타 확인 및 서치어드바이저 수집·색인 리포트로 추적해야 한다.
