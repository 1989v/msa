CTR·평점·찬성률처럼 비율을 정렬 키로 쓰면 표본이 얇은 항목이 상위를 차지한다. 윌슨 하한이 그 결함을 닫고, 경쟁 기법인 베이지안 shrinkage 와는 적용 조건이 갈린다.

| 항목 | 답 |
|---|---|
| 문제 | 시행 1회 성공 1회 = 비율 100%. 데이터가 적을수록 유리해진다 |
| 해법 | 신뢰구간의 **하한**으로 정렬. 안전마진이 `1/√n` 로 줄어든다 |
| `z` 기본값 | 1.96 (95% 양측). 콜드스타트가 아프면 1.0~1.28 |
| shrinkage 와의 차이 | **기준점** — 윌슨은 0 쪽 단방향, shrinkage 는 평균 μ 쪽 양방향 |
| 선택 기준 | 집단이 동질적이면 shrinkage, 이질적이면 윌슨 |
| ES 대응 함수 | 없음. `decay` 는 감쇠 축이 다르고 `saturation` 은 shrinkage 계열 |
| 구현 위치 | 질의 시점 `script_score` 가 아니라 색인 시점 precompute |

## 비율 정렬은 표본이 얇을수록 유리하다

| 항목 | 시행 | 성공 | 관측 비율 | 비율 정렬 | 윌슨 하한 |
|---|---:|---:|---:|:---:|---:|
| A | 5 | 5 | **100%** | 1등 | 0.566 |
| B | 1,000 | 850 | 85% | 2등 | **0.827** → 1등 |

A 는 5번 노출해 5번 눌렸다. 진짜 100% 짜리인지 운이 좋았는지 가릴 근거가 5개뿐이다.

극단은 시행 1회 성공 1회다. 비율이 100% 라 데이터가 가장 적은 항목이 항상 1위가 된다. 리뷰 평점·CTR·찬반 투표에서 같은 붕괴가 일어난다.

## 공식

```
       p̂ + z²/(2n) − z·√( p̂(1−p̂)/n + z²/(4n²) )
LB = ────────────────────────────────────────────
                    1 + z²/n
```

| 기호 | 의미 |
|---|---|
| `n` | 시행 횟수 |
| `p̂` | `성공 / n` (관측 비율) |
| `z` | 정규분포 분위수. 1.96 = 95% 양측 |

```java
static double wilsonLowerBound(long success, long trials) {
    if (trials == 0) return 0.0;

    final double z = 1.96;
    double n = trials;
    double p = (double) success / n;
    double z2 = z * z;

    double center = p + z2 / (2 * n);
    double margin = z * Math.sqrt(p * (1 - p) / n + z2 / (4 * n * n));

    return (center - margin) / (1 + z2 / n);
}
```

출처는 Wilson score interval (E. B. Wilson, 1927) 이다. 랭킹 적용은 Evan Miller 의 *How Not To Sort By Average Rating* (2009) 으로 알려졌고 Reddit 댓글의 `confidence` 정렬이 같은 식이다.

## 안전마진은 `1/√n` 로 줄어든다

지배항은 `z·√(p̂(1−p̂)/n)` 이다. 시행이 4배 늘면 마진은 절반이 된다.

| `n` (`p̂` = 10% 고정) | 윌슨 하한 | 페널티 |
|---:|---:|---:|
| 100 | 0.055 | 45% |
| 400 | 0.074 | 26% |
| 1,600 | 0.086 | 14% |

`n → ∞` 이면 보정항이 소멸해 `LB → p̂` 로 수렴한다. 표본이 충분한 구간에서는 비율 정렬과 결과가 같다. 저표본만 선택적으로 벌점을 받으므로 표본이 비슷한 항목끼리의 역전은 그대로 살아남는다.

## Wald 구간은 경계에서 무너진다

교과서의 단순 정규근사는 이렇다.

```
LB_wald = p̂ − z·√( p̂(1−p̂)/n )
```

`p̂ = 1` 을 넣으면 `√(1·0/n) = 0` 이라 마진이 0 이고 하한이 100% 가 된다. 5번 눌린 항목의 비율이 100% 로 확정된다. `p̂ = 0` 에서도 같은 방식으로 무너지고 구간이 `[0,1]` 밖으로 나가기도 한다.

윌슨 식의 `z²/2n` · `z²/4n²` · 분모 `1 + z²/n` 은 전부 경계 붕괴를 막는 보정이다. 그 덕에 5/5 가 1.0 이 아니라 0.566 으로 나온다.

## 베이지안 shrinkage 와 갈리는 지점

같은 문제를 푸는 다른 계열이 shrinkage 다. IMDb Top 250 의 가중평점이 대표 사례다.

```
score = (success + m·μ) / (n + m)      # μ = 사전 평균, m = 사전 표본 크기
```

| | 윌슨 하한 | 베이지안 shrinkage |
|---|---|---|
| 저표본이 끌려가는 곳 | **0** | **μ** (전체 평균) |
| 방향 | 단방향. 결과가 항상 `p̂` 이하 | **양방향**. `p̂ < μ` 면 올라간다 |
| 필요한 사전정보 | 없음 (`z` 만) | `μ`, `m` 둘 다 |
| 숨은 전제 | 없음 | **집단이 동질적일 것** |
| 최적화 대상 | 랭킹 보수성 | 점추정 정확도 (MSE) |

양방향이 함정이다. `p̂ < μ` 인 저표본 항목은 shrinkage 가 점수를 **올린다**. 저표본을 걸러내려고 넣은 장치가 반대로 작동한다.

아래는 `μ = 0.20`, `m = 500` 인 설명용 임의값이다.

| | 관측 | 윌슨 하한 | shrinkage |
|---|---:|---:|---:|
| `n` = 105, 성공 12 | 0.114 | **0.067** ↓ | **0.185** ↑ |

`(12 + 500×0.20) / (105 + 500) = 112/605 = 0.185` 이다. 관측 11.4% 짜리가 18.5% 로 승격돼 표본이 20배 두꺼운 항목을 제칠 수 있다.

## 판정 기준은 한 줄이다

> 데이터가 없는 항목이 전체 평균만큼 해줄 거라고 믿어도 되나.

| 답 | 선택 | 조건 |
|---|---|---|
| 믿어도 됨 | shrinkage | 동질적 집단. 같은 카테고리 영화의 평점처럼 "특별할 이유가 없으니 평균 근처" 가 성립 |
| 못 믿음 | 윌슨 | 이질적 집단. 하위 집단마다 비율 수준 자체가 다르다 |

이질적 집단에서 μ 는 표본이 가장 큰 하위집단 쪽으로 끌려간다. 그 μ 로 다른 집단을 끌어올릴 근거가 없다. 서로 다른 카테고리를 한 리스트에 섞어 정렬하는 경우가 여기 해당한다.

## 콜드스타트가 윌슨의 대가다

윌슨은 신규 항목을 바닥에서 시작시킨다. 노출을 못 받으니 `n` 이 안 쌓이고, `n` 이 안 쌓이니 계속 바닥이다. 순위가 스스로를 강화한다.

해법은 shrinkage 로 되돌아가는 것이 아니라 탐색을 따로 넣는 것이다.

| 방식 | 성격 |
|---|---|
| 탐색 슬롯 분리 | 상위 N 중 일부를 신규에 고정 배정. 결정론적 정렬 유지 |
| Thompson sampling | Beta 사후분포에서 표집. 탐색·활용 자동 균형, 대신 결과가 매번 달라진다 |
| `z` 완화 | 1.96 → 1.0. 가장 싸지만 저표본 방어력도 함께 내려간다 |

캐시·재현·건별 디버깅이 필요하면 결정론적 정렬을 포기할 수 없다. 그 경우 윌슨과 탐색 슬롯 조합이 무난하다.

## Elasticsearch 에 넣는 법

윌슨을 점수 감쇠 함수로만 보면 decay function 과 비슷해 보이지만 감쇠의 축이 다르다.

| | `gauss`/`exp`/`linear` | 윌슨 하한 |
|---|---|---|
| 감쇠 입력축 | `origin` 으로부터의 **거리** | **표본 크기 `n`** |
| 의미 | 이상점에서 멀다 | 근거가 얇다 |
| 관측값 자체 | 보지 않는다. 거리 같으면 감쇠 같다 | `p̂` 와 `n` 의 결합 함수 |
| 용도 | 최신성·거리순·가격대 근접 | 비율 랭킹의 저표본 방어 |

`rank_feature` 의 `saturation(x) = x / (x + pivot)` 이 형태상 더 가깝다. 이쪽은 윌슨이 아니라 shrinkage 의 사촌이라 앞 절의 양방향 함정을 그대로 물려받는다.

윌슨에 대응하는 네이티브 함수는 없다. 선택지는 둘이다.

1. `script_score` 로 질의 시점 계산 — 문서마다 `sqrt` 를 돌린다
2. 색인 시점 precompute — `wilson_score` 필드로 저장하고 정렬 키나 `field_value_factor` 로 사용

성공·시행 카운트는 대개 별도 집계 파이프라인으로 들어온다. 2번이 맞다.

## 검증

```python
import math

def wilson(success, trials, z=1.96):
    if trials == 0:
        return 0.0
    n, p, z2 = trials, success / trials, z * z
    center = p + z2 / (2 * n)
    margin = z * math.sqrt(p * (1 - p) / n + z2 / (4 * n * n))
    return (center - margin) / (1 + z2 / n)

for s, t in [(5, 5), (850, 1000), (12, 105), (10, 100), (40, 400), (160, 1600)]:
    print(f"{s}/{t}\t관측 {s/t:.4f}\t윌슨 {wilson(s, t):.4f}")
```

| 입력 | 관측 | 윌슨 하한 |
|---|---:|---:|
| 5 / 5 | 1.0000 | 0.5655 |
| 850 / 1000 | 0.8500 | 0.8265 |
| 12 / 105 | 0.1143 | 0.0666 |
| 10 / 100 | 0.1000 | 0.0552 |
| 40 / 400 | 0.1000 | 0.0743 |
| 160 / 1600 | 0.1000 | 0.0862 |

마지막 세 줄이 `1/√n` 감소를 보여준다. 관측 비율은 10% 로 같은데 하한만 0.055 → 0.074 → 0.086 으로 올라간다.
