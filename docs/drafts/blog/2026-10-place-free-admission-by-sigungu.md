## 무엇을 「입장 무료」로 세나

관광지마다 TourAPI 가 주는 요금 원문 한 칸을 규칙으로 읽는다. 금액 없이 「무료」로 시작하는 원문만 무료로 센다.

| 원문 예 | 판정 | 이유 |
|---|---|---|
| `무료` | <span class="pill p-green">무료</span> | 무료로 시작하고 금액이 없다 |
| `어른 3,000원 / ※ 무료: 6세 이하` | <span class="pill p-amber">유료</span> | 무료로 시작하지 않으면 금액이 이긴다 |
| `무료 (일부 체험 유료)` | <span class="pill">모름</span> | 무료로 시작하지만 유료 표기가 함께 있다 |
| 빈 칸 · `별도 문의` | <span class="pill">모름</span> | 판정할 근거가 없다 |

감면 대상만 무료인 원문이 흔해서, 「무료」라는 낱말이 들어 있다는 것만으로는 무료로 보지 않는다. 규칙은 무료를 넓게 잡기보다 틀리지 않는 쪽으로 판정한다.

> [!NOTE]
> 「모름」 6,254곳은 유료라는 뜻이 아니다. 요금 칸이 비어 있거나 조건이 섞여 있어 규칙이 판정하지 않은 곳이다.

## 집계 방법

국문 볼거리 문서를 시도·시군구 코드로 묶어 셌다. 검색 API 로도 같은 수가 나온다.

```bash
curl -s 'https://api.1989v.com/api/search/attractions?lang=ko&category=nature,history,culture,leisure&sidoCode=11&sigunguCode=110&admission=FREE&size=1' \
  | jq '.data.totalElements'
# 167  (2026-10-11 09:40 KST)
```

| 조건 | 값 |
|---|---|
| 언어 | 국문 (`lang=ko`) |
| 분류 | 자연 · 역사 · 문화 · 레저 (음식·쇼핑·숙박·행사·코스 제외) |
| 시군구 | 법정동 시도·시군구 코드 (시군구 없는 3곳 제외) |
| 무료 판정 | 요금 원문이 「무료」로 시작하고 금액·유료 표기가 없음 |

요금은 운영 기관이 바꿀 수 있다. 방문 전에 각 관광지 상세의 문의처로 확인한다.
