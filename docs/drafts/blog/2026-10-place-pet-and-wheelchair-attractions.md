두 속성 모두 원천이 「된다」는 곳만 알려 준다. 「안 된다」를 따로 적는 값이 없다.

## 집계 방법

```bash
# 울주군 반려동물 전 구역 동반
curl -s 'https://api.1989v.com/api/search/attractions?lang=ko&category=nature,history,culture,leisure&sidoCode=31&sigunguCode=710&pet=ALLOWED&size=1' \
  | jq '.data.totalElements'
# 19  (2026-10-11 09:40 KST)
```

| 조건 | 값 |
|---|---|
| 언어 · 분류 | 국문 · 자연 · 역사 · 문화 · 레저 |
| 반려동물 | TourAPI 반려동물 동반 여행 정보의 동반 유형 (주 1회 수집) |
| 휠체어 | 무장애 여행 정보 상세의 휠체어 항목에 긍정 문장이 있음 |
| 휠체어 부정 판정 | 문장에 `없음` · `없으` · `불가` · `미설치` 가 들어가면 정보 없음 |
| 영문 관광지 | 두 원천 모두 국문만 있어 영문 문서는 전부 정보 없음 |

무장애 상세는 하루 900콜 한도로 받는다. 상세가 아직 들어오지 않은 곳은 정보 없음으로 세어진다.
