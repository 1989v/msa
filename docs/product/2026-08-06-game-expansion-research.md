# 게임 플랫폼 확장 리서치 — 신규 33종 + 플래그십 RPG

- 날짜: 2026-08-06
- 상태: 확정 (데일리 5종 1차 착수)
- 관련: ADR-0059 (게임 플랫폼), `game/CLAUDE.md`

기존 라이브 게임 19종(자체 15 + 퀴즈 4) 이후의 확장 방향. 시장 근거 기반으로 33종을
클러스터링하고, 웹에서 30시간+ 플레이타임이 가능한 플래그십 오픈월드 RPG 1종을 별도
트랙으로 정의한다.

## 3. 플래그십 — 오픈월드 RPG "표류 대륙" (가칭, 30시간+)

기술 선례는 CrossCode(canvas2D, 수백 맵, 30~80h). 관건은 1인+AI 개발로 콘텐츠 30시간을
채우는 전략이며, 답은 손제작 볼륨이 아니라 **시스템 주도 플레이타임**(Terraria/Stardew 모델):

- **손제작 코어**: 메인 스토리 8~10시간 — 거점 마을 3~4곳 + 메인 던전 6~8개
- **절차 생성 스케일아웃**: 시드 기반 오픈월드(Daggerfall 방식), 청크 생성/스트리밍은
  Web Worker, 절차 사이드퀘스트·던전
- **성장 시스템**: 직업 3종 × 스킬트리, 제작/채집, 몬스터 도감(`game:sim` battle 코어 연계
  가능), 낚시/요리 서브루프
- **엔드게임**: 주기 리셋 심연 던전(로그라이트, GameRun 서버 시드) + NG+ — 20h→30h+ 구간
- **세이브**: IndexedDB 자동저장 + 파일 내보내기 (이어하기 코드는 체크포인트 공유용 보조,
  64KB 상한 초과 대비)
- **로드맵**: P1 수직 슬라이스(전투+마을1+던전1, 2h 분량) → P2 성장 시스템 → P3 절차 생성
  확장 → P4 엔드게임. P1 에서 재미 검증 실패 시 피벗. GA 이벤트로 구간별 이탈 측정

리스크: 다른 32종과 규모가 다른 수개월 장기 트랙 — 소품 다작과 병행하는 별도 트랙으로 운영.
