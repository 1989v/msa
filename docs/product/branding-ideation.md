## 2. 방향 후보

### A. `1989v` 유지 + 호명 규약 부여 (저비용)
- 공식 발음을 **"일구팔구"** 로 고정하고 `v` 는 묵음/장식 취급. 태그라인으로 보강.
- 예: **일구팔구 — 만들고, 굴리는 곳.** / eng: *1989v — built & operated by one engineer.*
- 장점: 도메인·색인·인증서 자산 무손실. 단점: 이름 자체의 매력은 낮은 채로 남는다.

### B. 브랜드명 신설 + `1989v.com` 은 인프라 도메인으로 (중비용)
k-heritage 세계관(재료·공간 감각)과 맞는 한국어 이름을 **브랜드**로 세우고, 도메인은 유지한 채
워드마크·GNB·OG 에서만 브랜드명을 노출한다. 도메인 이전이 아니라 **이름 덧씌우기**다.

| 후보 | 결 | 비고 |
|---|---|---|
| **누마루 (Numaru)** | 한옥의 높은 마루 — 전망하는 자리 | "서비스들을 한눈에 내려다보는 마루" = 런처 은유와 정합 |
| **대청 (Daecheong)** | 한옥의 중심 마루방 — 모든 방이 연결 | 포털=대청, 각 서비스=방. 발음 쉬움 |
| **결 (Gyeol)** | 나무 결 — 이미 디자인 토큰(`--kh-grain`) | 짧고 시각 언어와 직결. 영문 전달력 약함 |
| **온돌 (Ondol)** | 바닥 난방 — 보이지 않는 인프라 | "밑에서 데운다" = 백엔드 정체성. 영문 인지도 있음 |
| **낙관 (Nakgwan)** | 작품에 찍는 인장 — `.kh-seal` 이 곧 로고 | "만든 것에 낙관을 찍는다" = 포트폴리오 서사 최강 |

### C. 기술 정체성 영문명 (비추천)
`systemcore`, `1989.dev` 류 — k-heritage 비주얼과 어긋나고 흔하다. 기각 사유만 기록.
