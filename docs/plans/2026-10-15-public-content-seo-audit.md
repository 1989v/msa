# 게임·관광지 검색 발견성 점검 근거

2026-10-15. 개선 전 공개 HTTP 응답과 운영 읽기 전용 점검이다. 브라우저·검색엔진 계정 UI는 사용하지 않았다. 후속 구현 상태는 [실행 계획](2026-10-15-public-content-seo-followup.md)에 기록한다.

## 관광지 언어 연결

- ADR-0062에 따라 2026-10-11 운영 활성화 당시 2,600쌍이었다. 이는 현재 개수와 구분한다.
- 최신 운영 `attraction-reindex-29866890` 로그(2026-10-14 21:30 UTC): `Alternate pairs: 3521 (edges 3545, dropped by uniqueness 24, dropped by overview 0, enabled=true)`.
- 운영 CronJob의 `SEARCH_ALTERNATE_PAIRS_ENABLED=true`를 읽어 확인했다.
- 현재 공개 sitemap 스냅샷에는 5,302개 상세 URL, 즉 검증된 2,651쌍의 언어 링크가 있으며 상호 참조 위반은 0건이다. 배치 이후 정적 sitemap 빌드 시점 차이가 있으므로 새 빌드의 실제 개수를 다시 확인한다.
- 없는 번역에 같은 ID를 붙이거나 매칭 정확도를 낮추는 방식은 사용하지 않는다. 표본 57/63에 hreflang이 없다는 사실만으로 기능 고장이라 판정하지 않는다.

## 이미 작동하는 수집 알림

운영 `place-ingest-indexnow`는 매일 KST 07:30 실행한다. 단순한 Job 성공 상태뿐 아니라 응답 로그를 확인했다.

- 2026-10-14: 변경 URL 36건 — IndexNow 성공.
- 2026-10-15: 변경 URL 33건 — IndexNow 성공.

이는 관광지 본문 변경 URL에 대한 기존 자동화다. 게임 페이지 알림, sitemap 제출, Google 색인 요청을 모두 수행한다는 뜻이 아니다. 이번 코드 편집으로 관광지 원천의 `contentUpdatedAt`이 바뀌지는 않으므로 이번 수정 전체가 이 배치에 자동 포함된다고 주장하지 않는다.

## 수집 로그와 계정 지표의 차이

운영 ClickHouse의 개인정보 없는 집계만 읽었다. 조회 범위 2026-10-08 00:00~2026-10-15 00:00 UTC에서 실제 로그 보유는 10월 11~14일이며, 일부 시간·파드 로그가 부분 수집이다. 아래는 기간 전체의 완전한 로봇 방문 수가 아니라 **보관된 로그의 UA 분류 요청 수 하한**이다. UA만으로 로봇의 IP 진위를 검증한 것도 아니다.

| 호스트 | Googlebot 분류 | 네이버 Yeti 분류 |
| --- | ---: | ---: |
| game.1989v.com | 107 | 110 |
| place.1989v.com | 74 | 7 |

시간 커버리지: 10/11 21시간(partial 행8), 10/12 24시간(partial9), 10/13 24시간(partial4), 10/14 24시간(partial1). 이 값은 검색 노출·색인·평균순위가 아니다.

## 계정이 필요한 미확인 항목

이번 세션에 Search Console·네이버 서치어드바이저용 연결 도구/계정 접근은 없다. 아래 작업을 실제 수행했다고 보고하지 않는다.

1. `game.1989v.com`·`place.1989v.com` 속성의 sitemap 제출 및 처리 상태 확인.
2. 대표 허브·게임 상세·관광지 상세의 URL 검사: 최종 크롤 시점, 색인 여부, 검색엔진 선택 canonical과 제외 사유.
3. 검색어 묶음별 노출·클릭·평균순위: `웹게임/무료 웹게임`, 핀볼·내기 표현, 장소명과 지역+장소명, 영어 기능·장소명. 동일 기간·국가·기기를 비교.
4. 필요한 대표 URL의 재수집 요청. 일반 게임·관광지에 제한된 Google Indexing API를 잘못 적용하지 않는다.

공개 검색에서 한 번 발견되지 않았다는 이유로 전체 미색인·노출 0이라 결론 내리지 않는다. 배포·알림 접수·크롤·색인·노출·클릭은 별도 단계다.
