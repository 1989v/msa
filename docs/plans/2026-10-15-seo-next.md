### 성능 이벤트 계약

이벤트명은 `web_vitals`다. `metric_name`은 `LCP/INP/CLS`, `metric_value`와 `metric_delta`는 공식 모듈의 원래 값이다. LCP·INP는 **밀리초**, CLS는 **단위 없는 비율**이다. `metric_rating`, `page_type`, `page_lang`, `non_interaction`을 함께 보낸다. `page_location`은 호스트와 공개 화면 종류만 남기고, `page_referrer`는 빈 값, `page_title`은 화면 종류로 덮어쓴다. 원문 URL/제목/관광지 ID/게임 이름/초대 코드/지표 ID/DOM attribution은 이 이벤트에 추가하지 않는다. 이는 GA4 자체의 기존 방문 식별 기능까지 제거했다는 뜻이 아니다.

GA4에서 확인할 때는 이벤트 수만으로 지표를 판정하지 않는다. 필드가 보이지 않으면 해당 속성의 맞춤 측정기준(`metric_name`, `metric_rating`, `page_type`, `page_lang`)과 수치 측정항목(`metric_value`, `metric_delta`) 등록·처리 상태를 확인한다. 이번 작업에서는 계정 설정을 변경하지 않는다. 지표 종류마다 단위가 달라 모두 합산하지 않으며 `metric_delta`를 최종 값 분포로 오해하지 않는다. 문서가 SPA 이동을 한 번이라도 하면 복귀해도 측정을 재개하지 않는다.

측정 모듈은 `web-vitals` 6.2.3이다. Vite 출력에서 지연 로딩 collector 3.39kB/gzip 1.75kB, 공식 모듈 8.08kB/gzip 3.10kB를 확인했다. 경로 허용 목록에 게임 안내 본문 전체를 싣지 않도록 작은 slug 전용 목록과 82게임 일치 테스트를 사용했다. 이 용량 측정은 실제 사용자 CWV 점수와 별개다.

외부 발견용 콘텐츠는 실제 동작을 보여주는 구슬 레이스 사용 예시, 각 게임의 검증된 차이, 실제 확인한 관광지 방문 정보처럼 이용자가 참고할 내용을 우선한다. 자동 백링크·대량 키워드 페이지·가짜 후기·미확인 방문 경험을 만들지 않는다. 외부 게시·홍보 전송은 이번 작업에 포함하지 않는다.

이번 주차요금 보완은 기존 원천 필드를 렌더링하는 변경으로, 관광지 원천의 `contentUpdatedAt`을 일괄 갱신하지 않는다. 기존 변경 관광지 IndexNow 배치가 이번 템플릿 수정 전체를 자동 제출한다고 주장하지 않는다. 배포 뒤 대표 URL에서 최신 응답과 마지막 크롤 시점을 확인하고 필요한 재수집 제출은 별도 승인·수행 여부를 기록한다.
