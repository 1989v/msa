# 프로바이더 · procedural — 코드 드로잉 + WebAudio 합성 (기본)

의존성 0, 다운로드 0. 모든 그림은 `ctx` 로 그리고 모든 소리는 `AudioContext` 로 합성한다.
**임시 에셋이 아니다** — 이 방식으로 완성까지 간다. 벡터 드로잉은 해상도 상한이 없고 팔레트를 한 곳에서 바꿀 수 있다.

## 규약

1. **팔레트는 토큰 한 곳** — `palette.js` 에 이름으로. 스프라이트 함수는 hex 를 모른다
2. **스프라이트 = 함수** `draw{Name}(ctx, frame, opts)` — 원점은 발 밑 중앙, 단위는 월드 px. 스케일은 호출자가
3. **오프스크린 캐시** — 매 프레임 그리는 비용이 크면 `OffscreenCanvas`/숨은 canvas 에 클립별로 한 번 베이크. `ctx.filter` 는 베이크할 때만
4. **3톤 명암 + 외곽선 + 접지 그림자** — 작게 봐도 읽히게. 실루엣이 먼저, 디테일은 나중
5. **애니메이션은 리그**로 — 관절 각도를 시간 함수로 두고 그린다(프레임 그림 N장이 아니라). 예고(telegraph)·타격·경직이 각도 하나로 표현된다
6. **배경 3레이어** 패럴랙스 — 원경(하늘·산) · 중경(건물) · 근경(바닥·소품). 스테이지마다 팔레트와 소품이 달라야 게이트의 화면 구별 검사를 통과한다
7. **소리는 이름표** — `SFX = { hit_light: () => …, … }`, `MUSIC = { stage1: () => … }`. `__forge.audio()` 가 이 키를 그대로 낸다
8. 히트 소리는 히트스톱과 같은 프레임에 — 어긋나면 손맛이 죽는다

## 합성 소리 레시피 (출발점)

| 용도 | 방법 |
|---|---|
| 타격 | 사인/삼각 60~120Hz 짧게 + 화이트노이즈 30ms, 지수 감쇠 |
| 베기 | 노이즈 밴드패스 2~4kHz 스윕 다운 80ms |
| 점프 | 사각파 200→600Hz 스윕 업 100ms |
| 피격 | 톱니 150Hz + 노이즈, 120ms, 살짝 디튠 |
| UI | 사인 880Hz 30ms |
| 배경음 | 오실레이터 2~3개, 베이스 8분음 + 멜로디 16분음 시퀀서, 스테이지별 스케일 변경 |
