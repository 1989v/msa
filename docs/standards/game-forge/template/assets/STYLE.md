# STYLE — 스타일 바이블

에셋을 하나씩 프롬프트/코드로 만들지 않는다. **전체 스타일을 한 번 정하고** 에셋마다 바뀌는 것만 바꾼다.
프로바이더가 무엇이든(코드 드로잉·ComfyUI) 이 표가 공통 원본이다. 첫 실행 전에 채운다.

## 게임 전체 (고정 — 에셋마다 바꾸지 않는다)

| 항목 | 값 |
|---|---|
| 시대·무드 | (예: 뇌우 치는 성채, 어둡지만 채도 높은 강조색) |
| 표현 | (예: 굵은 외곽선 + 3톤 명암 + 접지 그림자, 픽셀 아님 / 픽셀 32px 등) |
| 실루엣 | 작게 봐도 읽히는 굵고 단순한 형태 |
| 디테일 | 중간 — 작은 크기에서 뭉개지지 않을 만큼 |
| 카메라·시점 | (예: 사이드뷰 3/4, 캐릭터는 정면 3/4) |
| 조명 | 단순 스튜디오광, 좌상단 |
| 팔레트 | **토큰 한 곳**(`palette.js` 등)에 이름으로: 배경 3단·주인공·적·강조·UI. hex 를 흩뿌리지 않는다 |
| 배경 | 3레이어 이상 패럴랙스(원경·중경·근경) |
| 해상도 목표 | 데스크톱 1440p 급 밀도, 폰에서 캐릭터 40 CSS px 이상 |
| UI 활자 | 한국어. 게임 톤과 맞는 큰 활자, 본문 최소 16 CSS px |

## 캐릭터별 (바뀌는 것만)

| 캐릭터 | 몸 | 머리·눈 | 장비·색 | 성격·자세 | 클립 |
|---|---|---|---|---|---|
| 주인공 | | | | | idle·run·attack1~3·hurt·dead |
| 적 A | | | | | idle·move·attack·hurt·dead |

주인공 4클립(idle·run·attack·hurt)은 최소, 적은 예고 동작(telegraph)을 반드시 갖는다 — 예고 없는 적 공격은 금지.

## 소리 (WebAudio 합성 기준)

| 이름 | 성격 | 길이 |
|---|---|---|
| hit_light | 짧고 둔탁, 저역 | 60ms |
| hit_heavy | 저역 + 노이즈 꼬리, 히트스톱과 동기 | 120ms |
| … | | |

배경음 1곡 이상(루프), 효과음 8종 이상. 소리 이름은 `__forge.audio()` 선언과 같아야 한다.
