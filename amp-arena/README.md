# AMP ARENA

**8인 실시간 3D 아레나 대전 액션**을 브라우저로. 방·악세서리·잡기·다운·링아웃이라는 고전 아레나 격투 문법을 따르고,
캐릭터·UI·이름·아트는 오리지널이다. 기획서는 [`docs/GDD.md`](docs/GDD.md), 시안은 `design/`.

서버 파드가 없다. 정적 클라이언트는 게임 플랫폼(`game.1989v.com`)의 games 서브모듈 `arena/` 로 나가고,
온라인 대전은 플랫폼 릴레이 `/ws/games/arena` 위에서 **방장 클라이언트가 권위 시뮬을 돌린다**.

## 실행

```bash
npm install
npm run check          # 타입 검사(shared · client) + 시뮬·권위 테스트 110개
npm run dev            # 개발 릴레이(8790) + vite(5180, /ws/games 프록시) → http://127.0.0.1:5180
npm run build:games    # client/dist-games — base /games/arena/ (games 레포에 올리는 산출물)
```

`tools/dev-relay.mjs` 는 플랫폼 릴레이의 로컬 대역이다(같은 프로토콜·같은 상한 4KB·40 msg/s). 운영에는 배포되지 않는다.

공중에서도 때린다 — 약공은 점프 궤적을 유지한 발차기(한 번 뛰어 최대 두 번), 강공은 앞아래로 내리꽂는 급강하다.

스타일 5종(파이터·그래플러·스피드스타·헤비·마셜)은 약공·강공 사슬·기술·스탯·외형이 다르고, 직업마다 들 수 있는 악세서리(6종 중 2~3종)가 다르다. 들면 사슬은 악세서리 것이 된다. 약공 사슬 중 강공 = 피니시, 가드로 막은 직후 공격 = 반격기.
맵 4종: 콜로세움(벽) · 스카이독(발판) · 옥상(가장자리 낙사) · 얼음 호수(미끄러움). 콜로세움·스카이독·옥상에는 점프대가, 콜로세움(동서 문루)·스카이독(컨테이너)·옥상(기계실)에는 들어갈 수 있는 방이 있다. 상자는 막히고 위에 올라설 수 있다. 드럼통은 잽 3방이나 던지기로 터진다(반경 3m·25, 옆 드럼통 연쇄). 팀전에서도 아군이 맞는다.

세로로 든 터치 기기에서는 앱을 90° 돌려 가로로 진행한다(기기를 왼쪽으로 눕혀 들면 손가락 방향이 맞는다). 카탈로그 IFRAME 안에서는 시작 버튼이 전체화면을 요청하고 가로 잠금을 시도한다.

## 온라인

- **빠른 대전**: 같은 대기열 자동 매칭. 사람이 8명 모이거나 30초가 지나면 릴레이가 시작시키고 빈 자리는 봇이 채운다.
- **코드 방**: 방을 만들면 6자리 코드. 방장이 시작하고, 판이 끝나면 같은 방에서 다음 판.
- **방장 = 가장 낮은 좌석.** 방장 브라우저의 워커가 60틱 권위 시뮬을 돌리고 스냅샷 10Hz 를 뿌린다. 게스트는 입력 20Hz.
- **지연 균등화**: 방장은 자기 입력을 게스트 왕복 중앙값의 절반만큼 늦게 넣고, 자기 화면도 게스트와 같은 예측·보간 경로로 그린다.
- **승계**: 방장이 나가면 다음 좌석이 마지막 권위 스냅샷(월드 단위 상태 포함)에서 이어서 돌린다. 세대(epoch)가 올라 옛 방장의 늦은 스냅샷은 버린다. 게스트는 아직 반영 안 된 입력을 새 방장에게 다시 보낸다.
- **지연 보상**: 방장은 최근 위치를 기억해 두고, 좌석별 왕복 지연 + 보간 지연만큼 되감은 상대 위치로 근접 타격을 판정한다.
- **관전**: 로비에서 「관전으로 참가」를 켜면 명단에서 빠지고 남을 따라 본다.
- **순위표**: 판이 끝나면 결과(KO 100 · 데미지 1 · 승리 50)를 플랫폼 순위표에 올린다 — 온라인·연습 보드가 따로다.
- **진행**: 점수가 경험치(온라인 ×1.5)와 골드(점수/10 + 승리 20)가 된다. 레벨마다 스탯 포인트 1(6스탯 각 +5 까지, 방장이 상한을 다시 검사), 골드로 상의·머리·머리띠 색을 산다. 12×12 가슴 그림도 그릴 수 있고 온라인 상대에게 보인다. 로컬에 저장되고 플랫폼 세이브로 기기 간 이어진다.

## 구조

```
shared/   시뮬레이션 (의존성 0) — 방장 워커·게스트 예측·테스트가 같은 파일을 실행한다
client/   Vite + Three.js — 프리미티브 리그 · 예측/보간 · DOM HUD · 화면 흐름
  src/net/  relay(릴레이 봉투) · online(대기실·승계) · guestsource(예측·보간) · authority(.worker)(권위 시뮬)
tools/    개발 릴레이 · games 레포 게시(API) · 헤드리스 크롬 E2E
design/   시안 캔버스 소스와 생성기
docs/     기획서 · 이어받기
```

- 프레임 데이터·수치는 `shared/src/moves.ts`·`constants.ts`·`items.ts` 가 단일 원본이고 기획서 표와 같다.
- 릴레이 메시지 규약은 `shared/src/protocol.ts` 한 곳에 있다.
